Free Snowflake SnowPro Specialty: Gen AI (GES-C02) Online Practice Exam

Overview

  1. The SnowPro Specialty: Gen AI (GES-C02) exam tests building generative AI solutions in Snowflake: Cortex AI functions, Cortex Search, Cortex Analyst and Agents, governance and cost, and document processing.
  2. The exam has 55 questions (multiple choice and multiple select) in 85 minutes, delivered by Pearson VUE online or at a test center.
  3. The passing score is 750 on a scaled score of 0–1000, and the fee is US$225.
  4. The four domains are weighted 18%, 38%, 29% and 15%, so this test has 55 questions split 10 / 21 / 16 / 8.
  5. Snowflake Cortex AI Functions documentation is the best place to study the functions.

Domain 1: Snowflake for Gen AI Overview (18%)

A company wants a chatbot that answers questions from thousands of policy PDFs stored in Snowflake. Which Cortex feature provides the retrieval part of this RAG application?

⬜ Cortex Analyst with a semantic view over the PDF table
⬜ Cortex Search
⬜ AI_CLASSIFY run on every question
⬜ A materialized view of the PDF text

Business users want to ask “What was revenue by region last quarter?” in plain English and get answers from sales tables. Which Cortex feature fits best?

⬜ Cortex Search over the sales tables
⬜ AI_SENTIMENT on the question text
⬜ AI_TRANSLATE followed by a stored procedure
⬜ Cortex Analyst

An assistant must answer questions that need both contract text and sales figures. What does a Cortex Agent add?

⬜ It plans the request and routes it to tools such as Cortex Search and Cortex Analyst
⬜ It replaces Cortex Search and Cortex Analyst with one larger, general-purpose model
⬜ It fine-tunes a model on the contracts every night
⬜ It converts the contract PDFs into relational tables

Which interface gives business users a ready-made, conversational way to use Cortex Agents without writing code?

⬜ SnowSQL command-line client
⬜ The Snowpark Python API
⬜ Snowflake Intelligence
⬜ The Cortex REST API called from cURL

A model needed by a team isn’t available in the account’s region. What allows Cortex to process the request in another region?

⬜ Creating a replica of the account in a second region
⬜ Setting the CORTEX_ENABLED_CROSS_REGION account parameter
⬜ Granting CORTEX_USER to the PUBLIC role
⬜ Increasing the warehouse size to 4X-Large

What is a trade-off of enabling cross-region inference?

⬜ Prompts and results are stored permanently in the other region for auditing
⬜ Cortex Search services stop refreshing
⬜ Credits are no longer charged for AI functions
⬜ Requests can have extra latency because they travel to another region

What does Snowflake’s managed Model Context Protocol (MCP) server let a team do?

⬜ Expose Snowflake tools such as Cortex Search and Analyst to external MCP clients
⬜ Train new foundation models inside Snowflake on the account’s own tables and stages
⬜ Replicate semantic views to other accounts
⬜ Encrypt stages with customer-managed keys

Where do Cortex AI functions run the large language models they call?

⬜ On a third-party API that the customer must sign up for
⬜ Only on a Snowpark Container Services compute pool the customer manages
⬜ Inside Snowflake’s security boundary, as a managed service
⬜ On the client machine that submits the query

A team wants to run its own open-source model that Cortex doesn’t offer. What’s the Snowflake option?

⬜ Upload the weights as a Cortex Search service
⬜ Register it in the Model Registry and serve it on Snowpark Container Services
⬜ Upload the weights to a stage and pass the model file to AI_COMPLETE with TO_FILE
⬜ Set CORTEX_ENABLED_CROSS_REGION to ANY_REGION

Which TWO are developer interfaces for calling Cortex AI capabilities? (Select two)

⬜ SQL functions such as AI_COMPLETE
⬜ The Snowflake Marketplace listing editor
⬜ The Cortex REST API
⬜ The Time Travel UNDROP command
⬜ Resource monitors

Domain 2: Snowflake Gen AI Functions (38%)

A pipeline must sort support tickets into “billing”, “technical” and “account”. Which function is the best fit?

⬜ AI_COMPLETE with a long free-form prompt
⬜ AI_SENTIMENT
⬜ AI_SUMMARIZE_AGG
⬜ AI_CLASSIFY

Which function keeps only the rows where “the review mentions a delivery problem” is true?

⬜ AI_FILTER
⬜ AI_SIMILARITY
⬜ AI_EMBED
⬜ AI_TRANSLATE

An analyst needs one answer, “What are the top complaints?”, across 200,000 review rows. Which function is designed for this?

⬜ AI_COMPLETE on each row separately
⬜ AI_CLASSIFY with one category
⬜ AI_AGG
⬜ VECTOR_COSINE_SIMILARITY

Which function converts recorded customer calls stored on a stage into text?

⬜ AI_PARSE_DOCUMENT in LAYOUT mode
⬜ AI_TRANSCRIBE
⬜ AI_EXTRACT with a JSON schema
⬜ AI_SUMMARIZE_AGG

A nightly pipeline calls an LLM on millions of rows. A few bad inputs make the whole query fail. What should be used instead of COMPLETE?

⬜ AI_COUNT_TOKENS
⬜ A larger warehouse
⬜ AI_FILTER in the SELECT list
⬜ TRY_COMPLETE, which returns NULL on error

An application needs AI_COMPLETE to return JSON that always matches a given schema. What should be used?

⬜ The response_format option with a JSON schema (structured output)
⬜ A system prompt that tells the model to “always reply in valid JSON format only”
⬜ AI_PARSE_DOCUMENT in OCR mode
⬜ Setting temperature to 1

Before sending long texts to AI_COMPLETE, a developer wants to know whether they fit the model’s context window. Which helper helps?

⬜ SPLIT_TEXT_MARKDOWN_HEADER
⬜ AI_SIMILARITY
⬜ AI_COUNT_TOKENS
⬜ GET_PRESIGNED_URL

Which helper splits long text into overlapping chunks before indexing it for search?

⬜ AI_SUMMARIZE_AGG
⬜ SPLIT_TEXT_RECURSIVE_CHARACTER
⬜ AI_COUNT_TOKENS
⬜ VECTOR_L2_DISTANCE

Which data type stores embeddings returned by AI_EMBED?

⬜ VARIANT holding a JSON array of strings
⬜ GEOGRAPHY
⬜ BINARY of fixed length
⬜ VECTOR, for example VECTOR(FLOAT, 768)

Which function measures how close two embeddings are, where a higher value means more similar?

⬜ VECTOR_COSINE_SIMILARITY
⬜ VECTOR_L2_DISTANCE
⬜ AI_COUNT_TOKENS
⬜ SPLIT_TEXT_RECURSIVE_CHARACTER

A query must ask a model about an image stored on a stage. What turns the staged image into an input for AI_COMPLETE?

⬜ PARSE_JSON on the file path
⬜ AI_EMBED on the file name
⬜ TO_FILE, which creates a FILE reference
⬜ A COPY INTO statement

A team chooses an LLM for a high-volume, simple extraction task. Which approach is best?

⬜ Always pick the largest model for every task
⬜ Pick the smallest model that meets accuracy, to cut latency and cost
⬜ Pick a model at random for each call
⬜ Use whichever model was released most recently

A small model keeps making domain-specific mistakes, and prompting hasn’t helped. What Cortex option can improve it?

⬜ Raising the warehouse size
⬜ Enabling Time Travel on the input table
⬜ Switching AI_COMPLETE to TRY_COMPLETE
⬜ Cortex Fine-tuning with prompt-and-completion examples

An application needs consistent, guaranteed throughput for Cortex model calls during peak hours. What can it use?

⬜ Provisioned throughput
⬜ Cross-region inference set to DISABLED
⬜ A multi-cluster warehouse in economy mode
⬜ AI_COUNT_TOKENS

When creating a Cortex Search service, what does the ON clause specify?

⬜ The warehouse used to refresh the index
⬜ The role allowed to query the service
⬜ The text column to search
⬜ The model used to answer questions

A Cortex Search service should reflect source table changes within about an hour. Which setting controls this?

⬜ DATA_RETENTION_TIME_IN_DAYS
⬜ TARGET_LAG
⬜ AUTO_SUSPEND
⬜ MAX_CONCURRENCY_LEVEL

How does Cortex Search rank results?

⬜ Only by exact keyword matches, ordered by how often the terms appear
⬜ Only by vector similarity
⬜ By the row’s insertion time
⬜ With hybrid vector and keyword search, then semantic reranking

Cortex Analyst generates wrong SQL for a frequent question about “active customers”. What most directly improves it?

⬜ Adding a verified query for that question to the semantic view
⬜ Adding more rows and more descriptive column comments to the customer table
⬜ Raising the warehouse to X-Large
⬜ Turning on cross-region inference

What does a semantic view give Cortex Analyst?

⬜ A cached copy of the source data in a faster columnar storage format for queries
⬜ Encryption keys for the source tables
⬜ Business meaning: tables, relationships, dimensions, facts and metrics
⬜ A schedule for refreshing search indexes

Users ask about “NYC” but the table stores “New York City”. How can Cortex Analyst match such values?

⬜ Rename every value in the source table
⬜ Link a Cortex Search service to the dimension for literal value search
⬜ Use AI_TRANSLATE on every question
⬜ Lower the TARGET_LAG of the semantic view so new values appear sooner in answers

Which TWO are Cortex AI functions that work on files such as documents or images? (Select two)

⬜ AI_PARSE_DOCUMENT
⬜ VECTOR_INNER_PRODUCT
⬜ AI_EXTRACT
⬜ SPLIT_TEXT_MARKDOWN_HEADER
⬜ AI_COUNT_TOKENS

Domain 3: Snowflake Gen AI Governance (29%)

A role needs to call Cortex AI functions. Which database role grants that access?

⬜ SNOWFLAKE.OBJECT_VIEWER
⬜ SECURITYADMIN
⬜ SNOWFLAKE.USAGE_VIEWER
⬜ SNOWFLAKE.CORTEX_USER

A team should be able to create embeddings but not call other AI functions. Which role fits?

⬜ SNOWFLAKE.CORTEX_EMBED_USER
⬜ SNOWFLAKE.CORTEX_USER
⬜ ACCOUNTADMIN
⬜ SYSADMIN

Security wants only approved models to be callable anywhere in the account. What should be configured?

⬜ A network policy on the Cortex endpoints
⬜ A masking policy on the prompt column
⬜ The account-level CORTEX_MODELS_ALLOWLIST parameter
⬜ A resource monitor on every warehouse

By default, CORTEX_USER is granted to which role, which admins often revoke to limit access?

⬜ ACCOUNTADMIN only
⬜ PUBLIC
⬜ ORGADMIN
⬜ No role at all

A chatbot built on AI_COMPLETE must block harmful or unsafe responses. What should be enabled?

⬜ Cross-region inference
⬜ A higher temperature
⬜ AI_COUNT_TOKENS
⬜ Guardrails (Cortex Guard) on AI_COMPLETE

Customer notes contain names, emails and phone numbers that mustn’t reach downstream AI steps. Which function helps?

⬜ AI_REDACT
⬜ AI_SENTIMENT
⬜ AI_SUMMARIZE_AGG
⬜ AI_EMBED

Which practice best reduces hallucinations in a question-answering app?

⬜ Raising the temperature to get more creative answers
⬜ Removing all instructions from the prompt
⬜ Grounding answers in retrieved company content (RAG)
⬜ Using the largest possible chunk of every document

Before enabling cross-region inference, what should a regulated company check first?

⬜ Whether the warehouse uses economy scaling
⬜ Whether data-residency rules allow processing in other regions
⬜ Whether Time Travel is set to 90 days
⬜ Whether the account uses Snowsight dark mode

What mostly drives the cost of Cortex AI functions such as AI_COMPLETE?

⬜ The number of columns in the table
⬜ The number of users in the account
⬜ The size of the Time Travel retention period
⬜ The number of tokens processed

Which warehouse guidance applies to queries that call Cortex AI functions?

⬜ Use a small warehouse, since larger sizes don’t speed up the model calls
⬜ Use the largest warehouse available so that the model calls run faster and in parallel
⬜ Never use a warehouse; AI functions are serverless
⬜ Always use a multi-cluster warehouse

Which TWO are billed parts of a Cortex Search service? (Select two)

⬜ Serving the indexed data
⬜ Per-user license seats
⬜ Warehouse compute for refreshes
⬜ Each Time Travel query
⬜ Pearson VUE exam fees

How is a custom model served on Snowpark Container Services billed?

⬜ By tokens, like Cortex AI functions
⬜ Per Cortex Search query
⬜ By the compute pool that runs the service
⬜ It’s free

FinOps wants to see daily Cortex Search spend. Where should they look?

⬜ The INFORMATION_SCHEMA.TABLES view filtered on the search service’s source tables
⬜ ACCOUNT_USAGE views such as CORTEX_SEARCH_DAILY_USAGE_HISTORY
⬜ The query profile of one query
⬜ The stage’s directory table

Which TWO are part of AI Observability in Snowflake? (Select two)

⬜ Evaluating apps with metrics such as groundedness and relevance
⬜ Replicating databases across regions
⬜ Tracing app runs and storing them in an event table
⬜ Setting warehouse auto-suspend
⬜ Creating reader accounts

Which SDK is used to instrument and evaluate generative AI apps for Snowflake AI Observability?

⬜ Streamlit
⬜ dbt
⬜ Terraform
⬜ TruLens

A RAG app gives fluent answers that aren’t supported by the retrieved passages. Which evaluation metric detects this?

⬜ Groundedness
⬜ Context relevance
⬜ Token count
⬜ Latency

Domain 4: Snowflake Document Processing (15%)

A team needs text from scanned invoices with tables kept as structure. Which AI_PARSE_DOCUMENT mode should it use?

⬜ OCR
⬜ SUMMARY
⬜ LAYOUT
⬜ VECTOR

A team needs to process each page of long PDFs separately. Which AI_PARSE_DOCUMENT option helps?

⬜ TARGET_LAG
⬜ page_split
⬜ response_format
⬜ temperature

Which function pulls specific fields, such as invoice number and total, from a staged document?

⬜ AI_SENTIMENT
⬜ AI_SUMMARIZE_AGG
⬜ AI_TRANSLATE
⬜ AI_EXTRACT

New documents land on a stage all day. What’s a good way to process them automatically?

⬜ Use a stream on the stage’s directory table and a task that calls the AI functions
⬜ Have an analyst run the extraction query manually each morning on all the staged files
⬜ Create a Cortex Search service on the stage
⬜ Set CORTEX_ENABLED_CROSS_REGION

A user needs to open a processed document from a staged location in a browser. Which function gives a temporary link?

⬜ TO_FILE
⬜ AI_PARSE_DOCUMENT
⬜ GET_PRESIGNED_URL
⬜ BUILD_STAGE_FILE_URL with no privileges

AI_PARSE_DOCUMENT fails on files in an internal stage. What’s a common cause?

⬜ The warehouse is too small
⬜ The stage doesn’t use server-side encryption
⬜ Time Travel is disabled
⬜ The files are newer than one day

Which TWO file types can AI_PARSE_DOCUMENT process? (Select two)

⬜ PDF
⬜ Parquet
⬜ DOCX
⬜ Avro
⬜ ORC

Which practice keeps document processing costs down?

⬜ Reprocess every document in every run
⬜ Use the largest warehouse available
⬜ Always run LAYOUT mode, even when only plain text is needed, to get the richest output
⬜ Process only new or changed files and only the pages you need
