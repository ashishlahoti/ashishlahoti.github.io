Free Splunk Core Certified User (SPLK-1001) Online Practice Exam

Overview

  1. The Splunk Core Certified User is an entry-level certification that shows you can search, use fields, create alerts, use lookups and build basic reports and dashboards in Splunk Enterprise or Splunk Cloud Platform.
  2. The exam has 60 questions (multiple choice and multiple select) in 60 minutes, which includes 3 minutes to review the exam agreement. Multiple-select questions say how many answers to pick.
  3. Splunk doesn’t publish the pass mark in the blueprint, so this practice test uses 70% as the target. There are no prerequisite exams.
  4. Splunk recommends the free Splunk Search Expert learning path (Intro to Splunk, Using Fields, Visualizations, Working with Time, Statistical Processing, Leveraging Lookups and Subsearches, Search Optimization) and hands-on practice in Splunk.
  5. The eight topics are weighted 5%, 22%, 20%, 15%, 15%, 12%, 6% and 5%, so this test has 60 questions split 3 / 13 / 12 / 9 / 9 / 7 / 4 / 3, with 5 multiple-select questions.
  6. Splunk Core Certified User exam blueprint for more details.

What is the difference between status!=200 and NOT status=200?

⬜ There is no difference; Splunk rewrites one into the other
⬜ NOT status=200 also returns events that have no status field
⬜ status!=200 also returns events that have no status field
⬜ NOT is only valid in field searches, != only in keyword searches

⬜ # marks hidden fields and a marks selected fields

What is the difference between the stats functions list() and values()?

⬜ list() returns unique values; values() returns all values
⬜ There is no difference; one is an alias
⬜ values() returns unique values in lexical order; list() keeps duplicates
⬜ list() only works with numeric fields
