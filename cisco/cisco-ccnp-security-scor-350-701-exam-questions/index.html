Free Cisco CCNP Security SCOR (350-701) Online Practice Exam

Overview

  1. Implementing and Operating Cisco Security Core Technologies (SCOR, 350-701) is the core exam for CCNP Security and the qualifying exam for the CCIE Security lab exam.
  2. The exam lasts 120 minutes; Cisco doesn’t publish the number of questions or the pass mark. This practice test has 100 questions and uses 80% as the target.
  3. The six v2.0 domains are weighted 20%, 25%, 15%, 10%, 15% and 15%, so this test has 100 questions split 20 / 25 / 15 / 10 / 15 / 15.
  4. Topics include cryptography and VPNs, zero trust, CVSS, AI and LLM risks, threat intelligence, network infrastructure security, Secure Firewall (FTD) policies and VPNs, AAA, secure management, telemetry, cloud shared responsibility, CASB, DevSecOps, Secure Access (SSE/SASE), Secure Endpoint, Email Threat Defense, ISE, TrustSec, Duo, Cisco XDR and Splunk.
  5. Exam topics for more details.
