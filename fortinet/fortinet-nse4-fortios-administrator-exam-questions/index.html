Free Fortinet NSE 4 - FortiOS 7.6 Administrator Online Practice Exam

Overview

  1. The Fortinet NSE 4 - FortiOS 7.6 Administrator exam (FOS-ADM-7.6) validates the skills to deploy, configure and troubleshoot FortiGate firewalls.
  2. The exam has 50 to 55 questions in 100 minutes, in English and Japanese, based on FortiOS 7.6.0.
  3. Fortinet doesn’t publish the pass mark in the exam description; this practice test uses 70% as the target.
  4. The five topics are weighted 20–25%, 20–25%, 25–30%, 10–15% and 10–15%, so this test has 55 questions split 12 / 12 / 15 / 8 / 8.
  5. Topics include transparent mode, FGCP HA, administrative access, conserve mode and the packet sniffer, policy order, VIPs and IP pools, FSSO, SSL certificate and full inspection, inspection modes, static URL filtering, application control, distance and priority, policy routes, RPF, SD-WAN, IPsec troubleshooting, dial-up VPN and ADVPN.
  6. Exam description for more details.

Domain 1: Deployment and system configuration (20–25%)

A FortiGate must be inserted between the internal network and the router without changing any IP addressing, while still scanning traffic. Which operating mode fits?

⬜ NAT mode with policy routes
⬜ NAT mode with a new subnet for the LAN
⬜ Transparent mode
⬜ A dial-up IPsec VPN

In an active-passive FGCP cluster, existing TCP sessions must continue after a failover. What must be enabled?

⬜ Override
⬜ A higher HA priority on the secondary
⬜ A second heartbeat interface only
⬜ Session pickup

Override is disabled in an HA cluster. The primary reboots, the secondary takes over, and the original unit returns. What happens?

⬜ The returning unit takes over again because it was primary before
⬜ The current primary keeps its role, because the returning unit’s HA uptime was reset
⬜ The unit with the higher serial number always becomes primary
⬜ Both units stay secondary until an admin intervenes

With override enabled, which criterion is checked before HA uptime when the cluster selects its primary?

⬜ Device priority
⬜ Serial number
⬜ Firmware build date
⬜ The amount of free memory

A second FortiGate won’t join an FGCP cluster. Which settings must match on both units?

⬜ Hostname and management IP
⬜ Model, firmware version, HA group name and ID, and HA password
⬜ Admin account passwords
⬜ FortiGuard serial numbers

Two FortiGates in a cluster have different FortiGuard licenses. What happens?

⬜ The higher license applies to both units
⬜ The cluster refuses to form
⬜ Each unit keeps its own license for its own traffic
⬜ The cluster uses the lower license level

An administrator builds a new HA cluster on FortiOS 7.6.1. Which HA setting is now mandatory?

⬜ Session pickup
⬜ Override
⬜ The HA password
⬜ Active-active mode

An administrator may manage the FortiGate only from 198.51.100.5. What restricts which source addresses can log in as that administrator?

⬜ Trusted hosts on the administrator account
⬜ A firewall policy from WAN to the FortiGate
⬜ The admin profile
⬜ A web filter profile

Which administrative access practice does Fortinet recommend?

⬜ Enable all protocols on every interface for convenience
⬜ Use Telnet on internal interfaces because it is faster
⬜ Allow HTTP on the WAN with trusted hosts
⬜ Use HTTPS and SSH, never HTTP or Telnet, and avoid admin access on the internet-facing interface

A FortiGate starts dropping new sessions, and memory use is about 85% of total RAM. What is happening?

⬜ Its FortiGuard license expired
⬜ It has entered conserve mode to protect itself
⬜ The disk is full of logs
⬜ HA has failed over

Which command captures packets on every interface and shows which interface each packet used?

⬜ diagnose sniffer packet any ‘’ 4
⬜ diagnose debug flow trace start 10
⬜ get system interface physical
⬜ execute ping-options source any

In a packet capture, what does setting the count to 0 do?

⬜ It captures one packet
⬜ It disables the capture
⬜ The capture runs until it is stopped with Ctrl+C
⬜ It captures only headers

Domain 2: Firewall policies and authentication (20–25%)

Traffic from the LAN is denied even though an allow policy exists for it. What is the most likely reason?

⬜ The implicit deny is evaluated first
⬜ Every policy defaults to deny
⬜ A policy higher in the list matches the traffic first and denies it
⬜ Policies are evaluated bottom-up

What can an administrator change on the implicit deny policy?

⬜ Its action
⬜ Only whether violating traffic is logged
⬜ Its position in the list
⬜ Its source and destination

Internet users must reach an internal web server 192.168.1.100 through the FortiGate’s public IP 203.0.113.10. What should be configured?

⬜ An IP pool on the LAN-to-WAN policy
⬜ NAT enabled on the LAN-to-WAN policy
⬜ A static route to 192.168.1.100
⬜ A virtual IP with external IP 203.0.113.10 and mapped IP 192.168.1.100, used as the destination of a WAN-to-LAN policy

NAT is enabled on a LAN-to-WAN policy with no IP pool. What source address do packets leave with?

⬜ The IP address of the outgoing interface
⬜ The address of the first IP pool configured
⬜ The original private address
⬜ The FortiGate’s management IP

Outbound traffic must leave with a specific public address 203.0.113.20 instead of the interface IP. What should be added to the policy?

⬜ A virtual IP for 203.0.113.20
⬜ An IP pool containing 203.0.113.20
⬜ A second default route
⬜ A static URL filter

A policy allows LAN to WAN and debug flow shows the traffic is accepted, but users can’t browse. What should be checked next?

⬜ The FortiGuard web filter license
⬜ The FortiGate’s root CA on clients
⬜ The HA heartbeat
⬜ That NAT is enabled so private source addresses are translated

Users must be identified from their Windows domain logons without entering credentials again. Which feature does this?

⬜ Captive portal with local users
⬜ Trusted hosts
⬜ Fortinet Single Sign-On (FSSO)
⬜ An IP pool per department

How does the FSSO DC agent mode differ from polling mode?

⬜ The DC agent reads logons from lsass.exe on the domain controller instead of polling Windows security event logs
⬜ The DC agent runs on the FortiGate
⬜ Polling mode needs software on every workstation
⬜ DC agent mode doesn’t use a collector agent

Several FortiGates connect to one collector agent. How does the collector agent decide which logons each FortiGate receives?

⬜ It sends every logon to every FortiGate
⬜ By the FortiGate’s serial number
⬜ By the order the FortiGates connected
⬜ By the group filter configured for that FortiGate

Which CLI command lists the firewall users table, including users learned through FSSO, with their IPs and groups?

⬜ diagnose firewall auth list
⬜ get system admin list
⬜ diagnose sys session list
⬜ show firewall policy

An administrator wants to see the logons the FortiGate has received from the FSSO collector agent for one user. Which commands fit?

⬜ diagnose sniffer packet any ‘user ’
⬜ get user local
⬜ diagnose debug authd fsso filter user , then diagnose debug authd fsso list
⬜ execute fsso refresh-all

Several VIPs publish servers on the same external interface. How can one firewall policy allow traffic to all of them?

⬜ List the mapped internal IPs as the destination
⬜ Put the VIPs in a VIP group and use the group as the policy’s destination
⬜ Use the WAN interface address as the destination
⬜ Create an IP pool for the servers

Domain 3: Content inspection (25–30%)

Users get certificate warnings on every HTTPS site after full SSL inspection is enabled. What fixes this?

⬜ Switch inspection to flow-based
⬜ Buy a public wildcard certificate for the FortiGate
⬜ Disable web filtering
⬜ Install the FortiGate’s inspection CA certificate as a trusted root on client devices

Which security features can’t work with SSL certificate inspection alone?

⬜ Web filtering
⬜ Application control
⬜ Antivirus, IPS and DLP, which need the full payload
⬜ Logging

With certificate inspection, how does the FortiGate learn which HTTPS site a user is visiting?

⬜ From the SNI in the TLS ClientHello, falling back to the certificate’s Common Name
⬜ By decrypting the HTTP Host header
⬜ From the user’s DNS cache
⬜ From the destination port

With certificate inspection, users see a certificate warning only when an HTTPS site is blocked. Why?

⬜ Blocked sites have expired certificates
⬜ The block page is presented with the FortiGate’s certificate
⬜ Certificate inspection breaks all HTTPS
⬜ The browser cache is corrupt

Banking sites must not be decrypted by full SSL inspection. What should be configured?

⬜ Add the Finance and Banking category to the SSL/SSH inspection profile’s exemption list
⬜ A static URL filter with Block
⬜ Certificate inspection on every policy
⬜ An application override

Where is the SSL inspection exemption list available?

⬜ Only in certificate inspection profiles
⬜ In web filter profiles
⬜ In application control profiles
⬜ Only in profiles set to full SSL inspection

How does proxy-based inspection differ from flow-based inspection?

⬜ Flow-based buffers whole files; proxy-based doesn’t
⬜ Proxy-based buffers traffic and examines it as a whole before acting; flow-based examines it as it passes without buffering
⬜ They behave the same
⬜ Proxy-based inspects only headers

An administrator switches inspection from proxy to flow mode. What happens to proxy-only features such as the web application firewall profile?

⬜ They keep working in flow mode
⬜ They switch to monitor only
⬜ They are removed from the GUI
⬜ They move to the IPS profile

A legitimate site is blocked because it’s Unrated. It must be allowed and skip FortiGuard category filtering. Which static URL filter action fits?

⬜ Allow
⬜ Monitor
⬜ Block
⬜ Exempt

What does the Monitor action in a static URL filter do?

⬜ Blocks and logs it
⬜ Exempts it from all inspection
⬜ Allows the URL and logs it
⬜ Sends a warning page to the user

A URL matches a static URL filter entry with action Block. What happens next?

⬜ Category filtering decides the final action
⬜ The site is blocked and no further web filtering is applied
⬜ Antivirus scans the page first
⬜ The user can override the block

BitTorrent and Tor must be blocked even when they change ports. Which security profile is designed for this?

⬜ Application control
⬜ A static URL filter
⬜ A port-based firewall policy
⬜ An SSL inspection exemption

An application control profile blocks a whole category, but one application in it must be allowed. What should be configured?

⬜ A new firewall policy for the category
⬜ A static URL filter entry
⬜ An IPS sensor
⬜ An application override for that application

Hosts must be stopped from using encrypted messaging apps such as Signal and Telegram. Which approach fits best?

⬜ Address objects of known server IPs
⬜ A DoS policy on common ports
⬜ Application control with those applications blocked
⬜ A web filter category block only

Where are application control results checked after blocking an application?

⬜ Log & Report > Security Events > Application Control
⬜ System > HA
⬜ Network > Routing
⬜ Policy & Objects > Virtual IPs

Domain 4: Routing (10–15%)

Two static default routes have distances 5 and 10. What does the routing table contain?

⬜ Both routes with ECMP
⬜ Only the distance-5 route; the other is inactive
⬜ Only the distance-10 route
⬜ Both routes, using priority to choose

Two static default routes have the same distance but priorities 0 and 10. What happens?

⬜ Only the priority-10 route is installed
⬜ Traffic is load-balanced equally
⬜ Neither is installed
⬜ Both are installed, and the route with priority 0 is preferred

Two static routes to the same destination have the same distance and the same priority. What happens?

⬜ Only the newer route is used
⬜ Both are installed and traffic is load-balanced with ECMP
⬜ Only the route on the lower interface index is used
⬜ Both are rejected

HTTP traffic must leave through port13 even though the routing table prefers another path. What should be configured?

⬜ A policy route for TCP port 80 out port13
⬜ A static route with a higher distance
⬜ A VIP on port13
⬜ A higher priority on the default route

In what order does the FortiGate look up where to send a packet?

⬜ Routing table, then policy routes
⬜ SD-WAN rules, then policy routes, then the routing table
⬜ Policy routes, ISDB routes, SD-WAN rules, then the routing table
⬜ Static routes, then SD-WAN rules, then policy routes

A policy route has the action Stop Policy Routing. What does it do to matching traffic?

⬜ Drops the traffic
⬜ Forwards it out the policy’s interface
⬜ Skips policy routing so the packet is routed by the next lookup tables
⬜ Sends it to SD-WAN only

Packets from a DMZ subnet are silently dropped with ‘reverse path check fail’. What is the likely cause?

⬜ There is no route back to the source subnet through that interface
⬜ The policy is in the wrong order
⬜ The FortiGuard license expired
⬜ Session pickup is disabled

WAN1 is preferred and WAN2 is backup; traffic must fail over when WAN1 stops reaching the internet. What should be configured?

⬜ Two static routes with ECMP
⬜ SD-WAN with both members, a performance SLA that probes remote servers, and a rule listing WAN1 first
⬜ A policy route to WAN1 only
⬜ An IP pool on WAN2

Domain 5: VPNs (10–15%)

Phase 1 of a site-to-site IPsec tunnel is up, but Phase 2 doesn’t come up. What is the most likely cause?

⬜ The pre-shared keys differ
⬜ UDP 500 is blocked
⬜ The FortiGates are in different time zones
⬜ The Phase 2 selectors (local and remote subnets) don’t match on both peers

Users report a tunnel is down. Which command gives a quick per-tunnel view of selectors up and total?

⬜ diagnose sniffer packet any
⬜ get vpn ipsec tunnel summary
⬜ get router info routing-table all
⬜ diagnose firewall auth list

Which command shows whether Phase 1 is established for a specific IPsec gateway?

⬜ get vpn ipsec stats crypto
⬜ diagnose debug flow show
⬜ diagnose vpn ike gateway list name
⬜ execute vpn sslvpn list

In diagnose vpn tunnel list output, sa=0 is shown for a tunnel. What does it suggest?

⬜ A selector mismatch or no traffic, so no matching IPsec SA exists
⬜ The tunnel is fully up with traffic
⬜ Phase 1 uses IKEv2
⬜ The tunnel is in HA standby

Before debugging IKE, what basic check does Fortinet recommend for a tunnel that won’t come up?

⬜ Reboot both FortiGates
⬜ Change the encryption to DES
⬜ Disable the firewall policies
⬜ Confirm the gateways can reach each other and UDP 500 and 4500 aren’t blocked

Remote FortiClient users connect from changing IP addresses. How should the Phase 1 be set up?

⬜ As a static gateway for each user’s current IP
⬜ As a route-based tunnel to 0.0.0.0
⬜ With NAT traversal disabled
⬜ As a dial-up (dynamic) gateway that accepts peers whose IP isn’t known in advance

In a hub-and-spoke IPsec design, spokes should build direct tunnels to each other on demand. Which feature provides this?

⬜ SSL VPN web mode
⬜ ADVPN
⬜ Policy routes
⬜ Session pickup

Which settings enable ADVPN on the hub and the spokes?

⬜ auto-discovery-sender on the hub’s phase 1 and auto-discovery-receiver on each spoke’s phase 1
⬜ auto-discovery-receiver on the hub and sender on the spokes
⬜ net-device enable on the hub only
⬜ dpd disable on all units
