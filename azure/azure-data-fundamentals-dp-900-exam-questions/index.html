Free Azure Data Fundamentals (DP-900) Online Practice Exam

Overview

  1. This is a Fundamentals level certification for people starting to work with data in the cloud. It covers core data concepts and how they’re implemented with Microsoft Azure data services.
  2. Passing DP-900 earns the Microsoft Certified: Azure Data Fundamentals credential. There are no prerequisites. Cost varies by country/region.
  3. Exam duration is 45 minutes, with about 40 to 60 questions (multiple choice, multiple response and other item types).
  4. Passing score is 700 (out of 1000).
  5. The four domains are weighted at 25–30%, 20–25%, 15–20% and 25–30%, so this test has 50 questions split 14 / 12 / 10 / 14, with 4 multiple-select questions.
  6. Fundamentals certifications don’t expire.
  7. Study Guide and certification page for more details.

Domain 1: Describe core data concepts (25–30%)

A table of customers where every row has the same columns (ID, name, email, city) is an example of which type of data?

⬜ Semi-structured data
⬜ Structured data
⬜ Unstructured data
⬜ Streaming data

Order records are stored as JSON documents, and some orders include a ‘giftMessage’ field while others don’t. Which type of data is this?

⬜ Semi-structured data
⬜ Structured data
⬜ Unstructured data
⬜ Binary (BLOB) data files

A company stores scanned contracts, product photos and recorded support calls. What type of data are these?

⬜ Structured data
⬜ Semi-structured data
⬜ Relational data
⬜ Unstructured data

Which file format stores data by column and is optimized for compressed analytical queries over large datasets?

⬜ CSV
⬜ Parquet
⬜ JSON
⬜ XML

Which statement describes a delimited text file such as CSV?

⬜ It’s a binary format that stores data column by column for analytics
⬜ It’s a hierarchical document format that uses nested tags for each field
⬜ One record per line, with fields separated by a delimiter
⬜ It can only store images and other unstructured binary large objects

A banking app must ensure that a transfer either completely debits one account and credits the other, or does neither. Which property of transactional systems guarantees this?

⬜ Eventual consistency
⬜ Atomicity (part of ACID)
⬜ Columnar storage
⬜ Data dispersion

Which workload records high volumes of small, frequent inserts and updates, such as point-of-sale sales?

⬜ Online analytical processing (OLAP) queries
⬜ Batch data warehousing
⬜ Online transaction processing (OLTP)
⬜ Data visualization

Managers want to analyze five years of sales by region and product, using data copied from operational systems and optimized for read-heavy queries. Which workload is this?

⬜ Analytical workload (data warehouse or OLAP)
⬜ Transactional workload (OLTP)
⬜ Real-time telemetry ingestion only from devices
⬜ File sharing with SMB

⬜ Data analyst
⬜ Data engineer
⬜ Business stakeholder or sponsor
⬜ Database administrator

Who designs and builds the pipelines that ingest data from source systems, clean it and load it into an analytical store?

⬜ Database administrator
⬜ Data engineer
⬜ Data analyst
⬜ Help desk technician

Who explores data, builds reports and dashboards, and helps the business make decisions from data?

⬜ Data engineer
⬜ Database administrator
⬜ Data analyst
⬜ Network engineer

A web app must store millions of product images and serve them over HTTP at low cost. Which Azure data store fits?

⬜ Azure SQL Database
⬜ Azure Blob Storage
⬜ Azure Table storage
⬜ Azure Database for MySQL

What is the main difference between a data lake and a data warehouse?

⬜ A lake holds raw files in many formats; a warehouse holds modeled tables
⬜ A data lake can only store relational tables, while a warehouse only stores images
⬜ A data warehouse is always cheaper and never needs any data modeling or design
⬜ There’s no difference; both terms describe an OLTP database for transactions

Which TWO are characteristics of analytical (OLAP) workloads? (Choose two.)

⬜ Many small, concurrent inserts and updates per second
⬜ Each query touches only a single record by its key
⬜ Data is optimized for reading rather than writing
⬜ Strict row locking for every customer transaction
⬜ Queries aggregate large volumes of historical data

Domain 2: Identify considerations for relational data on Azure (20–25%)

In a relational database, what uniquely identifies each row in a table?

⬜ A primary key
⬜ A foreign key
⬜ A view
⬜ An index hint

An Orders table includes a CustomerID column that refers to the CustomerID in the Customers table. What is CustomerID in the Orders table?

⬜ A primary key of Orders
⬜ A stored procedure
⬜ A clustered view
⬜ A foreign key

Why are relational databases normalized?

⬜ To store all data in one wide table so that queries never need any joins
⬜ To convert relational tables into JSON documents for faster web access
⬜ To remove primary keys so that rows can be inserted without validation
⬜ To store each fact once and avoid update anomalies

Which SQL statement category includes CREATE TABLE, ALTER TABLE and DROP TABLE?

⬜ Data Manipulation Language (DML)
⬜ Data Control Language (DCL)
⬜ Data Query Language for reports
⬜ Data Definition Language (DDL)

Which SQL statement changes the email address of an existing customer row?

⬜ UPDATE
⬜ INSERT
⬜ ALTER
⬜ GRANT

Which database object is a virtual table defined by a saved SELECT query?

⬜ A view
⬜ An index
⬜ A stored procedure
⬜ A primary key

Queries that search orders by OrderDate are slow on a very large table. Which database object can speed them up?

⬜ A view on the whole table
⬜ A DROP TABLE statement
⬜ An index on the OrderDate column
⬜ A foreign key on OrderDate

A company wants a fully managed relational database for a new cloud app, with built-in high availability and automatic patching and backups, and no need for instance-level SQL Server features. Which service fits?

⬜ SQL Server on Azure Virtual Machines
⬜ Azure SQL Database
⬜ Azure Table storage
⬜ Azure Files

A company is migrating an on-premises SQL Server that uses SQL Server Agent jobs and cross-database queries, and wants a managed service with near 100% compatibility. Which option fits?

⬜ Azure SQL Database single database
⬜ Azure SQL Managed Instance
⬜ Azure Cosmos DB for NoSQL
⬜ Azure Database for MySQL

A vendor application requires a specific SQL Server version plus third-party software installed on the same server’s operating system. Which option fits?

⬜ Azure SQL Database
⬜ Azure SQL Managed Instance (Business Critical)
⬜ SQL Server on Azure Virtual Machines
⬜ Azure Blob Storage

A team runs an open-source PostgreSQL application and wants a managed Azure service without changing database engines. Which service fits?

⬜ Azure Database for PostgreSQL
⬜ Azure SQL Managed Instance
⬜ Azure Table storage
⬜ Azure SQL Database

Which TWO statements are Data Manipulation Language (DML)? (Choose two.)

⬜ INSERT
⬜ DROP
⬜ DELETE
⬜ GRANT
⬜ CREATE TABLE

Domain 3: Describe considerations for working with non-relational data on Azure (15–20%)

Backup files are kept for compliance, are almost never read, and can tolerate a retrieval delay of several hours. Which Blob Storage access tier is cheapest for storage?

⬜ Hot tier
⬜ Archive tier
⬜ Cool tier
⬜ Cold tier

A big data team wants Blob Storage with a hierarchical namespace of real directories, optimized for analytics engines such as Spark. What should it use?

⬜ Azure Files with SMB shares
⬜ Azure Table storage
⬜ Azure SQL Database
⬜ Azure Data Lake Storage

On-premises Windows servers need a shared folder in Azure that they can mount over SMB, just like a network file share. Which service fits?

⬜ Azure Table storage
⬜ Azure Cosmos DB
⬜ Azure Queue Storage
⬜ Azure Files

Which service stores large numbers of schemaless entities as key-value data, identified by a partition key and a row key?

⬜ Azure Table storage
⬜ Azure Files
⬜ Azure Blob Storage archive tier
⬜ Azure SQL Managed Instance

A globally used mobile game needs single-digit millisecond reads and writes from users in many regions, with automatic scaling and multi-region writes. Which service fits?

⬜ Azure Table storage in one region
⬜ SQL Server on a single Azure VM
⬜ Azure Cosmos DB
⬜ Azure Files Premium

A team has an existing MongoDB application and wants to move it to Azure Cosmos DB with minimal code changes. Which API should it choose?

⬜ Azure Cosmos DB for MongoDB
⬜ Azure Cosmos DB for Apache Gremlin
⬜ Azure Cosmos DB for Table
⬜ Azure Cosmos DB for Apache Cassandra

A social network needs to store people and the relationships between them, and run queries like ‘friends of friends’. Which Cosmos DB API fits?

⬜ Azure Cosmos DB for Table
⬜ Azure Cosmos DB for MongoDB
⬜ Azure Cosmos DB for PostgreSQL
⬜ Azure Cosmos DB for Apache Gremlin (graph)

Which statement about Blob Storage blob types is correct?

⬜ Page blobs are used for log files that only ever have data appended to them
⬜ Append blobs store virtual machine disks with random read and write access
⬜ All blob types are identical, and the choice only affects the blob’s name
⬜ Block blobs for files, append blobs for logs, page blobs for VM disks

Which statement about Azure Cosmos DB for NoSQL is correct?

⬜ It stores data only as CSV files that must be loaded before every query
⬜ It stores JSON documents and supports querying them with SQL-like syntax
⬜ It requires a fixed relational schema with foreign keys between containers
⬜ It can only be deployed in a single Azure region with no replication

Which TWO APIs does Azure Cosmos DB offer? (Choose two.)

⬜ Oracle Database
⬜ MongoDB
⬜ Apache Cassandra
⬜ SQL Server Agent
⬜ Microsoft Access databases

Domain 4: Describe an analytics workload on Azure (25–30%)

Data is extracted from source systems, transformed in a separate processing engine, and then loaded into a data warehouse. Which approach is this?

⬜ ELT (extract, load, transform)
⬜ ETL (extract, transform, load)
⬜ OLTP (online transaction processing)
⬜ CRUD (create, read, update, delete)

Which service lets you build pipelines that copy and orchestrate data movement from many sources into Azure analytical stores, with a visual designer and scheduling?

⬜ Azure Data Factory
⬜ Azure Files
⬜ Azure Table storage
⬜ Power BI Desktop

Which statement describes Microsoft Fabric?

⬜ A relational database engine that replaces Azure SQL Database for transactional apps
⬜ A file share service that lets on-premises servers mount folders using SMB
⬜ A unified SaaS analytics platform built on OneLake
⬜ A graph database API offered by Azure Cosmos DB for social network data

In Microsoft Fabric, what is OneLake?

⬜ A Power BI visual used to display maps of customer locations
⬜ A scheduling tool that triggers pipelines once a day at midnight
⬜ One logical data lake for the whole organization
⬜ A relational database used only for transactional applications

Which analytical store in Microsoft Fabric combines data lake file storage with the ability to query tables using SQL and Spark, storing tables in Delta format?

⬜ An Azure Files share
⬜ A Power BI dashboard
⬜ A lakehouse
⬜ Azure Table storage

A data science team wants a managed Apache Spark platform on Azure for large-scale data engineering, machine learning and collaborative notebooks. Which service fits?

⬜ Azure SQL Managed Instance
⬜ Azure Databricks
⬜ Azure Files
⬜ Azure Table storage

Sales files are loaded into a warehouse every night and reports show yesterday’s results. What type of processing is this?

⬜ Stream processing
⬜ Batch processing
⬜ Transaction processing
⬜ Real-time event processing

Which scenario requires stream processing rather than batch processing?

⬜ Producing a monthly financial report from last month’s ledger entries
⬜ Archiving five-year-old documents to cheaper storage once a quarter
⬜ Rebuilding a sales data warehouse from scratch every Sunday night
⬜ Detecting fraudulent card transactions within seconds of them occurring

Which Azure service runs real-time analytics queries on streaming data from Event Hubs or IoT Hub using a SQL-like language?

⬜ Azure Stream Analytics
⬜ Azure Files
⬜ Azure SQL Managed Instance
⬜ Azure Blob Storage archive tier

In Microsoft Fabric, which workload is designed to ingest, analyze and act on streaming event data, for example with eventstreams and eventhouses queried by KQL?

⬜ Power BI paginated reports
⬜ Data warehouse only
⬜ Real-Time Intelligence
⬜ OneLake shortcuts only

Which statement describes the roles of Power BI Desktop and the Power BI service?

⬜ Desktop is only used for viewing dashboards on mobile phones
⬜ The service is the only place where data models can ever be created
⬜ Both are database engines that store transactional application data
⬜ Desktop builds models and reports; the service shares them

A Power BI model has a Sales fact table linked to Product, Date and Customer dimension tables. What is this model design called?

⬜ A flat file
⬜ A key-value store
⬜ A star schema
⬜ A graph schema

Which visual best shows how monthly revenue has changed over the last three years?

⬜ A line chart
⬜ A card
⬜ A pie chart
⬜ A table only

Which TWO are features of data models in Power BI? (Choose two.)

⬜ Relationships between tables
⬜ SMB file shares for model storage
⬜ Partition keys for Cosmos DB
⬜ Measures calculated with DAX
⬜ Clustered columnstore indexes on VMs
