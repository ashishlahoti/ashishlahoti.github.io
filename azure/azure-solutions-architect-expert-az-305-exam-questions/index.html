Free Azure Solutions Architect Expert (AZ-305) Online Practice Exam

Overview

  1. This is an Expert level certification for Azure solutions architects. It’s for people who advise stakeholders and turn business requirements into secure, scalable and reliable Azure solutions: identity, governance and monitoring, data storage, business continuity, and compute, application, migration and network infrastructure.
  2. To earn the Microsoft Certified: Azure Solutions Architect Expert credential you need to pass AZ-305 and hold the Azure Administrator Associate (AZ-104) certification. Microsoft recommends hands-on Azure administration and development experience and a good grasp of networking, virtualization, identity, security, business continuity and governance.
  3. Exam code is AZ-305 (Designing Microsoft Azure Infrastructure Solutions). Cost varies by country/region. You can retake the exam 24 hours after a first failed attempt, and longer waiting periods apply to later retakes.
  4. Exam duration is 120 minutes. Microsoft doesn’t publish a fixed question count (usually 40 to 60 questions). Question types include multiple choice, multiple response, Yes/No statement series, drag-and-drop and case studies.
  5. Passing score is 700 (out of 1000).
  6. The current skills outline is dated April 17, 2026. Its four domains are weighted at 25–30%, 20–25%, 15–20% and 30–35%.
  7. Like other Microsoft role-based certifications, it is valid for 1 year and can be renewed for free by passing an online assessment on Microsoft Learn before it expires.
  8. Study Guide and certification page for more details.

Case study: Fabrikam, Inc. Read the scenario below, then answer the question at the end.

Overview: Fabrikam, Inc. is an engineering company with offices across Europe: a main office in London and branch offices in Amsterdam, Berlin and Rome.

Existing environment:

  • The network has two Active Directory forests, corp.fabrikam.com and rd.fabrikam.com, with no trust between them. Corp.fabrikam.com is the production forest that holds the identities used for internal user and computer authentication. Rd.fabrikam.com is used only by the research and development (R&D) department, which is restricted to on-premises resources.
  • Every office has at least one corp.fabrikam.com domain controller, and the main office hosts all the rd.fabrikam.com domain controllers. All offices have a high-speed internet connection.
  • WebApp1, which customers use to place and track orders, runs in the London datacenter with an IIS web tier and a SQL Server 2016 database tier on Hyper-V virtual machines. The IT department tests WebApp1 updates in a separate Hyper-V environment.
  • Fabrikam buys all Microsoft licenses through an Enterprise Agreement that includes Software Assurance.
  • WebApp1 usage is unpredictable: users report delays at peak times, while many resources sit underused at other times.

Planned changes: Fabrikam will move most production workloads to Azure over the next few years, including virtual machines that rely on Active Directory for authentication. One of the first projects is a hybrid identity model to support an upcoming Microsoft 365 deployment. All R&D operations stay on-premises, and the production and test instances of WebApp1 will move to Azure.

Technical requirements:

  • Website content must be easy to update from a single point.
  • User input must be minimal when provisioning new web app instances.
  • Existing on-premises licenses must be used whenever possible to reduce cost.
  • Users must always authenticate with their corp.fabrikam.com UPN identity.
  • New Azure deployments must stay available if an Azure region fails.
  • Solutions should use the Standard tier of Azure App Service whenever possible.
  • An email distribution group named IT Support must be notified of any directory synchronization issues.
  • If the link between Azure and the on-premises network fails, Azure virtual machines must still be able to authenticate to Active Directory.
  • Directory synchronization between Microsoft Entra ID and corp.fabrikam.com must not be affected by a link failure between Azure and the on-premises network.

Database requirements:

  • Database metrics for the production instance of WebApp1 must be available so database administrators can tune performance settings.
  • Database downtime during migration must be minimized so customer access isn’t disrupted.
  • Database backups must be kept for at least seven years for compliance.

Security requirements:

  • Company information, including policies, templates and data, must be inaccessible to anyone outside the company.
  • On-premises users must be able to authenticate to corp.fabrikam.com if an internet link fails.
  • Administrators must be able to sign in to the Azure portal with their corp.fabrikam.com credentials.
  • All administrative access to the Azure portal must use multifactor authentication (MFA).
  • Testing of WebApp1 updates must not be visible outside the company.
