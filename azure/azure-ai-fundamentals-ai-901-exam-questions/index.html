Disclaimer: Microsoft Azure is a protected Brand. These exam questions are neither endorsed by nor affiliated with Microsoft. These are not the official Microsoft exam questions/dumps. These questions are created from the web resources of Microsoft Learn. These questions cover all the domains/objectives of the AI-901 official exam, and once you go through these questions and their concepts, you are more than ready to crack the exam in first attempt.

Note: AI-901 replaced AI-900 for the Microsoft Certified: Azure AI Fundamentals credential (AI-900 retired on June 30, 2026). The questions follow the skills outline dated April 15, 2026, which is built around Microsoft Foundry: prompts, models, agents, Azure Language, Azure Speech, vision and image generation, and Azure Content Understanding for information extraction. They use current names (Microsoft Foundry, Foundry Tools) and current models; for example, image generation uses the GPT-image series because DALL-E 3 was retired on March 4, 2026.

Free Azure AI Fundamentals (AI-901) Online Practice Exam

Overview

  1. This is a Fundamentals level certification for people at the start of an AI solution development career. It covers AI concepts and responsible AI, and building simple generative AI apps, agents and AI solutions with Microsoft Foundry.
  2. Passing AI-901 earns the Microsoft Certified: Azure AI Fundamentals credential. Microsoft expects conceptual knowledge of Azure AI solutions, basic Python syntax and familiarity with Azure resources; questions can include REST APIs, SDKs and CLIs.
  3. Exam code is AI-901 (it replaced AI-900). Cost varies by country/region.
  4. Exam duration is 45 minutes, with about 40 to 60 questions (multiple choice, multiple response and other item types).
  5. Passing score is 700 (out of 1000).
  6. The current skills outline is dated April 15, 2026. Its two domains are weighted at 40–45% and 55–60%, so this test has 50 questions split in the same proportion.
  7. Fundamentals certifications don’t expire.
  8. Study Guide and certification page for more details.
