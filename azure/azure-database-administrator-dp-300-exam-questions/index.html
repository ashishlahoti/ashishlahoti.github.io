Free Microsoft Azure Database Administrator (DP-300) Online Practice Exam

Overview

  1. This is an Associate level certification for database administrators who run SQL Server and Azure SQL: Azure SQL Database, Azure SQL Managed Instance, SQL Server on Azure Virtual Machines and hybrid SQL Server.
  2. Passing DP-300 earns the Microsoft Certified: Azure Database Administrator Associate credential. It requires a free online renewal assessment every year. Cost varies by country/region.
  3. Exam duration is 100 minutes, with about 40 to 60 questions, which can include a case study and other item types.
  4. Passing score is 700 (out of 1000).
  5. The five domains are weighted 15–20%, 20–25%, 20–25%, 15–20% and 20–25%, so this test has 50 questions split 9 / 11 / 11 / 8 / 11, with 4 multiple-select questions.
  6. Study Guide and certification page for more details.

Domain 1: Plan and implement data platform resources (15–20%)

A company is moving an on-premises application to Azure. The databases use SQL Server Agent jobs, cross-database queries and CLR assemblies, and the team wants a fully managed PaaS service with near 100% SQL Server compatibility. Which offering should they choose?

⬜ Azure SQL Managed Instance
⬜ Azure SQL Database elastic pool
⬜ Azure Database for PostgreSQL flexible server

An OLTP database on Azure SQL Database is expected to grow to 60 TB. The team needs fast backups and restores regardless of size and the ability to add read replicas quickly. Which service tier fits best?

⬜ General Purpose
⬜ Business Critical
⬜ Hyperscale
⬜ Basic

A development database on Azure SQL Database is used only a few hours a day at unpredictable times. The team wants compute to scale automatically and to pay only for storage when the database is idle. What should they configure?

⬜ A provisioned DTU database in the Standard tier
⬜ The serverless compute tier with auto-pause enabled
⬜ A Business Critical database with a read replica
⬜ A manual scale-down script run by Azure Automation

⬜ Place the databases in an elastic pool
⬜ Move all customers into one Hyperscale database
⬜ Give every database the Business Critical tier
⬜ Create an auto-failover group for each database

⬜ Use the Managed Instance link and fail over at cutover

⬜ ROW compression

⬜ A virtual network service endpoint

⬜ A server-level firewall rule for the office IP

⬜ Always Encrypted on the card number column
⬜ Row-level security on the payments table

⬜ A security policy with a predicate function
⬜ A dynamic data masking rule on the Region column

⬜ Query Store
⬜ SQL Server Profiler
⬜ Database Engine Tuning Advisor
⬜ sp_who2

You want Azure SQL Database to detect plan-choice regressions and switch back to the last known good plan automatically. Which option do you enable?

⬜ AUTO_UPDATE_STATISTICS_ASYNC
⬜ FORCE_LAST_GOOD_PLAN
⬜ DROP_INDEX
⬜ READ_COMMITTED_SNAPSHOT

⬜ sys.dm_exec_requests
⬜ sys.dm_db_index_usage_stats
⬜ sys.dm_db_resource_stats
⬜ sys.dm_db_missing_index_details

⬜ sys.dm_db_missing_index_details
⬜ sys.dm_exec_sessions
⬜ sys.dm_os_wait_stats
⬜ sys.dm_db_partition_stats

A large index on a busy Azure SQL database must be rebuilt during business hours. The rebuild should allow concurrent access and be able to pause and continue later. Which ALTER INDEX option should you use?

⬜ ALTER INDEX … REORGANIZE
⬜ REBUILD WITH (ONLINE = ON, RESUMABLE = ON)
⬜ DBCC SHRINKDATABASE
⬜ DROP INDEX, then CREATE INDEX with the same definition

After a large nightly data load, several queries get poor plans because the optimizer underestimates row counts. Automatic statistics updates are on. What should you add to the load job?

⬜ Run DBCC CHECKDB after the load
⬜ Update statistics on the loaded tables
⬜ Switch the database to the simple recovery model
⬜ Clear the Query Store after the load

⬜ DBCC CHECKDB
⬜ DBCC FREEPROCCACHE
⬜ UPDATE STATISTICS
⬜ sp_recompile

You need a managed monitoring solution that collects detailed performance and configuration data from many Azure SQL databases and managed instances into a central store with dashboards, without installing agents. What should you use?

⬜ Database watcher
⬜ SQL Server Agent alerts
⬜ Azure Advisor
⬜ The Database Experimentation Assistant

You want to capture deadlock graphs and long-running queries in Azure SQL Database with low overhead and keep the output in a file. What should you create?

⬜ An Extended Events session with an event_file target
⬜ A server-side SQL Trace written to the server’s local disk
⬜ A SQL Server Profiler trace on your workstation
⬜ A Windows performance counter log on the server

One database on a SQL managed instance needs a different max degree of parallelism (MAXDOP) from the other databases. How should you set it?

⬜ sp_configure ‘max degree of parallelism’ at the instance

⬜ A query hint added to every query in the app

⬜ Memory grant feedback

⬜ Parameter Sensitive Plan optimization

Domain 5: Plan and configure a high availability and disaster recovery (HA/DR) environment (20–25%)

An Azure SQL database needs a readable secondary in another region, automatic failover, and connection strings that don’t change after failover. What should you configure?

⬜ Active geo-replication only
⬜ A failover group
⬜ Zone redundancy
⬜ Long-term backup retention

A reporting team needs up to four readable copies of one Azure SQL database in different regions, and the DBA will fail over manually. Which feature should you use?

⬜ Active geo-replication
⬜ A failover group
⬜ Read scale-out in the Business Critical tier
⬜ Log shipping

A developer deleted rows from an Azure SQL database two hours ago. You need to get the data back without overwriting current changes. What should you do?

⬜ Restore the database in place from the last full automated backup
⬜ Point-in-time restore to a new database, then copy the rows
⬜ Fail over to the geo-secondary database
⬜ Restore from a long-term retention backup

Regulations require keeping a weekly backup of an Azure SQL database for 10 years. What should you configure?

⬜ A longer point-in-time restore retention period
⬜ A long-term retention (LTR) policy
⬜ A copy-only backup job in SQL Server Agent
⬜ Geo-redundant storage for the database files

SQL Server on an Azure VM must write native backups straight to Azure Blob storage. What do you need?

⬜ BACKUP DATABASE … TO URL with a SAS credential
⬜ An Azure Files share mapped as a drive letter on the VM
⬜ The BACPAC export wizard
⬜ A database snapshot

You need an ad hoc full backup of a production database before a risky change, without affecting the differential backup chain. Which option do you use?

⬜ WITH COPY_ONLY
⬜ WITH DIFFERENTIAL
⬜ WITH NORECOVERY
⬜ WITH CHECKSUM only

A Business Critical Azure SQL database must survive the loss of a whole datacenter within its region without data loss. What should you enable?

⬜ Zone redundancy
⬜ Geo-redundant backup storage
⬜ A read scale-out replica
⬜ Accelerated database recovery

You are deploying an Always On availability group on SQL Server on Azure VMs and want to avoid configuring an Azure Load Balancer or a distributed network name for the listener. How should you deploy the replicas?

⬜ All replicas in one subnet
⬜ Each replica in a different subnet
⬜ All replicas in one availability set and one subnet
⬜ Replicas on VMs with a public IP each

You are building a failover cluster instance (FCI) with SQL Server on Azure VMs. Which TWO options can provide the shared storage? (Choose two.)

⬜ Azure shared disks
⬜ Premium file shares
⬜ An Azure Blob storage container
⬜ The temporary D: drive of each VM

You use log shipping between two SQL Server VMs and want the secondary database readable for reports between restores. How should the restore job restore the logs?

⬜ WITH NORECOVERY
⬜ WITH STANDBY
⬜ WITH REPLACE
⬜ WITH MOVE

You want to run a disaster recovery drill on an Azure SQL failover group and make sure no data is lost. Which action should you take?

⬜ A planned failover
⬜ A forced failover
⬜ Delete the primary database
⬜ Restore the primary from a geo-backup
