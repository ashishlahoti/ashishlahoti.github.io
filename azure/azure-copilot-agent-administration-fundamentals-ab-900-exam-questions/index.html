Free Microsoft AB-900 Copilot and Agent Administration Fundamentals Online Practice Exam

Overview

  1. This is a Fundamentals (beginner) level certification for IT admins and anyone who supports the rollout of Copilot and agents in Microsoft 365.
  2. Passing AB-900 earns the Microsoft 365 Certified: Copilot and Agent Administration Fundamentals credential.
  3. It covers the core Microsoft 365 services (admin centers, licenses, Exchange, SharePoint, Teams), identity and security (Zero Trust, Microsoft Entra ID, Conditional Access, PIM, Defender XDR), data protection and governance with Microsoft Purview and SharePoint Advanced Management, and basic admin tasks for Copilot and agents.
  4. Exam duration is 45 minutes; Microsoft fundamentals exams usually have about 40 to 60 questions. Cost varies by country/region.
  5. Passing score is 700 (out of 1000).
  6. The current skills outline is dated October 14, 2026. Its three domains are weighted at 30–35%, 35–40% and 25–30%, so this test has 50 questions split in the same proportion.
  7. Fundamentals certifications don’t expire.
  8. Study Guide and exam page for more details.

Domain 1: Identify the core features and objects of Microsoft 365 services (30–35%)

Every new employee in the Sales department must automatically receive the same Microsoft 365 licenses, and lose them when they leave the department. New staff are added to the Sales security group by HR. What should the admin do?

⬜ Assign the licenses to the Sales SharePoint site
⬜ Assign the licenses to each user manually when they start
⬜ Assign the licenses to the Sales security group by using group-based licensing
⬜ Create a Teams policy for the Sales department

Contoso has bought the domain contoso.com and wants users’ email addresses to use it. In the Microsoft 365 admin center, how does Microsoft 365 confirm that Contoso owns the domain?

⬜ By checking for a TXT record added at the domain registrar
⬜ By requiring a Teams meeting with Microsoft support
⬜ By sending a code to the Global Administrator’s phone
⬜ By scanning the company’s public website for the domain name

The support team wants a single address, support@contoso.com, that several agents can read and reply from, with replies appearing to come from support@ rather than from each agent. What should the admin create?

⬜ A Microsoft Teams channel named Support
⬜ A distribution list that contains the agents
⬜ A SharePoint document library named Support
⬜ A shared mailbox, with Full Access and Send As permissions for the agents

External auditors need to open and download documents on a project SharePoint site, but must not edit or delete anything. Which default SharePoint group should they be added to?

⬜ Owners, which has the Full Control permission level
⬜ Visitors, which has the Read permission level
⬜ Members, which has the Edit permission level
⬜ Site collection administrators

A user is a member of a group that has the “Managers” Teams meeting policy, and the admin has also assigned the “Restricted” meeting policy directly to that user. Which policy applies?

⬜ Managers, because group assignments always win
⬜ The Global (Org-wide default) policy
⬜ Restricted, because a direct assignment takes precedence over a group assignment of the same policy type
⬜ Both policies are merged

Which three are the guiding principles of Zero Trust? (select three)

⬜ Assume breach
⬜ Protect only the network perimeter
⬜ Trust devices on the corporate network
⬜ Use least privilege access
⬜ Verify explicitly

A security team wants one place where related alerts from Defender for Endpoint, Defender for Office 365 and Defender for Identity are combined into a single incident that shows the whole attack. Which product provides this?

⬜ Microsoft Defender XDR
⬜ Microsoft Purview Compliance Manager
⬜ SharePoint Advanced Management
⬜ Microsoft Copilot Dashboard

Contoso wants users to complete multifactor authentication only when they access Microsoft 365 from outside the company’s trusted office IP ranges. What should the admin configure?

⬜ A retention policy for Exchange Online
⬜ A sensitivity label with encryption
⬜ A Teams meeting policy
⬜ A Microsoft Entra Conditional Access policy that uses location as a condition and requires MFA

A company connects its HR and expense apps to Microsoft Entra ID so employees sign in once with their work account and then open every assigned app without signing in again. What is the main benefit?

⬜ The apps no longer need licenses
⬜ Users manage fewer credentials and admins control app access centrally
⬜ Each app keeps its own separate password database
⬜ Users no longer need any authentication

An admin wants to review sign-ins that Microsoft Entra flagged as possibly compromised, such as sign-ins from anonymous IP addresses or with leaked credentials. Where should the admin look?

⬜ The SharePoint data access governance reports
⬜ The Exchange admin center message trace
⬜ The Risky sign-ins report in Microsoft Entra ID Protection
⬜ The Copilot usage report

A user says she is blocked when signing in from her home laptop. The admin wants to see which Conditional Access policies would apply to her sign-in conditions without asking her to try again. Which tool should the admin use?

⬜ The Conditional Access What If tool
⬜ Identity Secure Score
⬜ The Teams admin center
⬜ Microsoft Purview Compliance Manager

A CISO asks how well the tenant’s identity settings match Microsoft’s security recommendations and which actions would improve them, such as requiring MFA for admin roles. What should the admin show?

⬜ The Microsoft 365 admin center Copilot readiness report
⬜ Microsoft Purview activity explorer
⬜ The SharePoint admin center Active sites list
⬜ Identity Secure Score in Microsoft Entra ID

Auditors want evidence of which admin changed a mailbox’s permissions last week and when. Where can this be investigated?

⬜ The Teams admin center meeting policies page
⬜ Audit log search in the Microsoft Purview portal, with the Audit Logs or View-Only Audit Logs role
⬜ The Microsoft Copilot Dashboard
⬜ Microsoft Purview Data Lifecycle Management

IT staff currently hold the Exchange Administrator role permanently. Security wants them to request the role only when needed, for a limited time, with manager approval. Which service supports this?

⬜ SharePoint restricted access control
⬜ Microsoft Purview Communication Compliance
⬜ Microsoft Entra Privileged Identity Management (PIM)
⬜ Microsoft Entra Conditional Access named locations

A multitenant SaaS app is registered in its vendor’s tenant. When Contoso users consent to it, an object appears in Contoso’s tenant under Enterprise applications. What is that object?

⬜ A service principal — the app’s local representation in Contoso’s tenant
⬜ A guest user account for the vendor
⬜ A distribution group for the app’s users
⬜ The application object — the app’s global definition

A Contoso admin wants Microsoft 365 to require the strongest controls when Microsoft Entra ID Protection rates a sign-in as high risk, for example by blocking access or requiring a secure password reset. What does this require?

⬜ A retention label with a seven-year period
⬜ A SharePoint data access governance report
⬜ A Teams messaging policy
⬜ A risk-based Conditional Access policy, which needs Microsoft Entra ID P2

Domain 2: Understand data protection and governance tasks for Microsoft 365 and Copilot (35–40%)

A legal department needs documents labeled “Highly Confidential” to be encrypted and show a watermark, and the protection must stay with a file even when it is downloaded or emailed outside SharePoint. What should the admin use?

⬜ A Teams meeting policy
⬜ A Microsoft Purview sensitivity label with encryption and content marking
⬜ A SharePoint site permission
⬜ A retention label

Users sometimes email credit card numbers to external recipients by mistake. The company wants Outlook to warn them with a policy tip and block the message unless they give a business justification. What should be configured?

⬜ An Insider Risk Management case
⬜ A Conditional Access policy
⬜ A Microsoft Purview Data Loss Prevention (DLP) policy that blocks with override
⬜ A retention policy for Exchange

Before rolling out Copilot, a company wants to make sure Copilot doesn’t use the contents of files and emails labeled “Highly Confidential” in its responses. What should the admin configure?

⬜ A DLP policy for the Microsoft 365 Copilot and Copilot Chat location, with the sensitivity label as the condition and the action to prevent Copilot from processing the content
⬜ A Conditional Access policy that blocks the Copilot app for everyone
⬜ A retention policy that deletes labeled files
⬜ A Teams meeting policy that turns off transcription

A SharePoint site is covered by a retention policy that keeps content for seven years. A user deletes a document from the site after two years. What happens?

⬜ The user is blocked from signing in
⬜ The document is permanently deleted immediately
⬜ The retention policy is removed from the site
⬜ The document is kept for the rest of the retention period, because retention wins over deletion

Security is worried that employees who have resigned may download large amounts of confidential files before their last day. Which Microsoft Purview solution is designed to detect this?

⬜ Communication Compliance
⬜ Insider Risk Management, using the data theft by departing users policy template
⬜ Data Lifecycle Management
⬜ Compliance Manager

HR wants harassing or threatening language in Teams chats, and in prompts and responses in Copilot, to be detected and sent to designated reviewers. Which Microsoft Purview solution should be used?

⬜ eDiscovery
⬜ Insider Risk Management
⬜ Communication Compliance
⬜ Sensitivity labels

A compliance officer wants a score showing how well the organization meets a regulation such as GDPR, with step-by-step recommended actions to improve it. Which tool provides this?

⬜ Microsoft Purview Compliance Manager
⬜ The Microsoft 365 admin center usage reports
⬜ Microsoft Entra Identity Secure Score
⬜ Microsoft Purview activity explorer

A Compliance Administrator can open the Data explorer page in Microsoft Purview but can’t see the list of files that contain credit card numbers. What is missing?

⬜ The Teams Administrator role
⬜ A Microsoft Copilot license
⬜ A retention label on the files
⬜ Membership in the Data Explorer List viewer role group (and Content viewer to see item contents)

A manager suspects someone removed or downgraded sensitivity labels on several files last week. Which tool shows a history of label changes on content?

⬜ Microsoft Entra sign-in logs
⬜ Microsoft Purview activity explorer
⬜ The Teams admin center
⬜ Microsoft Purview Data explorer

A company wants a central place to see how employees use Copilot and other AI apps, find sensitive data in AI prompts, activate recommended protection policies with one click, and run data risk assessments for oversharing. Which Purview capability fits?

⬜ Data Lifecycle Management
⬜ Compliance Manager
⬜ Data Security Posture Management (DSPM) for AI
⬜ Microsoft Entra PIM

The legal team needs to find all emails, Teams messages and OneDrive files that mention “Project Falcon” for a lawsuit, and export them. Which Microsoft Purview solution should they use?

⬜ eDiscovery, by creating a case and running a search across the relevant data sources
⬜ Insider Risk Management
⬜ Compliance Manager
⬜ Activity explorer

A DLP policy has started raising alerts when files with patient data are shared externally. Where does the compliance team triage these alerts, check the events and mark false positives?

⬜ The Copilot Dashboard in Viva Insights
⬜ The Microsoft 365 admin center Message center
⬜ The SharePoint admin center Active sites page
⬜ The DLP Alerts dashboard in the Microsoft Purview portal

A user without access to the Finance site asks Copilot to summarize the latest budget, which is stored only on that site. Which two statements describe how Copilot handles organizational data in this situation? (select two)

⬜ Copilot ignores sensitivity labels and encryption
⬜ Copilot surfaces only organizational data that the user has at least view permission to
⬜ Copilot copies the tenant’s files into the public web index
⬜ Copilot can read every file in the tenant because it runs as a system account
⬜ Prompts, responses and data accessed through Microsoft Graph aren’t used to train the foundation models

A document is protected by a sensitivity label that applies encryption, and a user has been granted only view rights. How does Copilot behave when that user works with the document?

⬜ Copilot always refuses to open any labeled document
⬜ Copilot honors the usage rights granted to the user by the encryption
⬜ Copilot removes the encryption so it can read the file
⬜ Copilot gives the user full edit rights

Why can Copilot in Teams give a sales manager a useful answer to “What did the customer agree to in last week’s meetings and emails?”

⬜ Copilot searches the public web for the company’s meetings
⬜ The foundation model was trained on the company’s emails
⬜ Copilot grounds the prompt in the user’s work data through Microsoft Graph, such as emails, meetings, chats and files the user can access
⬜ The manager’s mailbox is copied into Copilot’s model each night

Before rolling out an AI assistant, a company publishes a page explaining what the assistant can and can’t do, and which data it uses. Which Microsoft responsible AI principle does this support most directly?

⬜ Transparency
⬜ Reliability and safety
⬜ Inclusiveness
⬜ Fairness

Before enabling Copilot, a SharePoint admin wants to find which sites are shared with very large audiences, such as “Everyone except external users”, so they can be cleaned up. What should the admin run?

⬜ An Exchange message trace
⬜ A Microsoft Entra sign-in log export
⬜ A Teams usage report
⬜ A data access governance report from the SharePoint admin center

Over the years, the Mergers site has been shared with many people through direct permissions and links. The company now wants only members of the M&A security group to be able to open it, even people who already have links, without fixing every permission. What should the admin use?

⬜ A distribution list for the M&A team
⬜ Restricted access control in SharePoint Advanced Management
⬜ A retention policy on the site
⬜ A Conditional Access policy for SharePoint

A high-risk HR site should stay available to its current members, but its content must not surface in Copilot and agent responses across the organization while permissions are reviewed. Which SharePoint Advanced Management feature fits?

⬜ Inactive site detection
⬜ Site access reviews
⬜ Restricted content discovery
⬜ Sharing links activity report

Domain 3: Perform basic administrative tasks for Copilot and agents (25–30%)

A company has bought Microsoft Copilot licenses for its leadership team. Where in the Microsoft 365 admin center does the admin assign them?

⬜ Billing > Licenses, then select Microsoft Copilot and assign it to the users or groups
⬜ Teams admin center > Meeting policies
⬜ Settings > Domains
⬜ Purview portal > Compliance Manager

A company wants employees without Copilot licenses to try SharePoint agents and pay only for what they use, with costs charged to the IT department’s budget. What must the admin set up?

⬜ A Teams messaging policy
⬜ A retention policy on SharePoint
⬜ A Microsoft Copilot license for every employee
⬜ A pay-as-you-go billing policy that links an Azure subscription to a set of users, and connect it to the SharePoint agents service

A company’s use of agents varies a lot from month to month, and it isn’t sure who will use them regularly. Why might pay-as-you-go be a better starting point than buying monthly Copilot licenses for everyone?

⬜ It needs no Azure subscription
⬜ It charges only for actual usage and helps establish usage patterns before committing to prepaid licenses
⬜ It gives users every feature of the full Copilot license
⬜ It’s always cheaper than a license for heavy daily users

Regulators require that Copilot in a bank’s tenant doesn’t use web search to answer prompts. Users must not be able to turn it back on themselves. What should the admin configure?

⬜ A Teams meeting policy
⬜ A SharePoint restricted access control policy
⬜ The “Allow web search in Copilot” policy in Cloud Policy, set to disabled
⬜ A DLP policy on the Exchange location

A strategy consultant needs a structured, source-cited report that pulls together market information from the web with the company’s own files, emails and meeting notes, and is willing to wait a few minutes for it. Which Copilot agent fits best?

⬜ Researcher
⬜ Analyst
⬜ A SharePoint agent scoped to one site
⬜ Copilot Chat with web search turned off

A sales operations lead has several Excel and CSV files of regional sales and wants to ask in plain language which products are trending and where the outliers are, getting back charts and insights. Which Copilot agent fits best?

⬜ Scheduled prompts
⬜ Prompt Gallery
⬜ Researcher
⬜ Analyst

A team built an HR policy agent in Agent Builder (Copilot Studio Lite), grounded on a SharePoint site. They now need it to create tickets in an external HR system through a connector. What should they do?

⬜ Ask users to schedule a prompt that creates tickets
⬜ Copy the agent to Microsoft Copilot Studio and add the action there
⬜ Add the external system as a Web content source in Agent Builder
⬜ Share the agent with the whole organization

An admin needs to report how many users accessed Copilot over the last month, which Microsoft 365 apps they used it in, and the most used agents. Where is this report, and which least-privileged role can open it?

⬜ Identity Secure Score in Entra, with the Security Reader role
⬜ The SharePoint admin center, with the SharePoint Administrator role
⬜ Reports > Usage > Microsoft Copilot in the Microsoft 365 admin center, with the AI Administrator role
⬜ Compliance Manager in the Purview portal, with the Compliance Administrator role

Business leaders want deeper insight into Copilot’s productivity impact and ROI across departments, beyond the basic admin center usage numbers. What should the AI Administrator enable?

⬜ The Copilot Dashboard in Viva Insights (Copilot Analytics), with access delegated to the leaders
⬜ Microsoft Purview activity explorer
⬜ The Exchange admin center message trace
⬜ The Copilot readiness report only

A team lead wrote a prompt that produces a great weekly project status summary and wants everyone on the team to be able to reuse it. What is the simplest way?

⬜ Email the prompt as a Word attachment to each person
⬜ Build a new Copilot Studio agent for the prompt
⬜ Create a retention label containing the prompt
⬜ Save the prompt and share it with the team in Prompt Gallery

A company must stop users from creating scheduled prompts in Copilot across the organization. What is the documented way for the admin to do this?

⬜ Turn off web search in Copilot
⬜ Set “Allow the use of connected experiences in Office” to Disabled in Cloud Policy
⬜ Delete the users’ OneDrive accounts
⬜ Remove the Prompt Gallery app from Teams

During a pilot, only members of the “Agent Pilot” group should be able to use agents in Copilot. Where does the admin set this, and what is the default?

⬜ SharePoint admin center > Active sites; the default is site owners only
⬜ Teams admin center > Meeting policies; the default is No users
⬜ Agents > Settings > User access in the Microsoft 365 admin center, choosing Specific users/groups; the default is All users
⬜ Purview portal > DLP; the default is Specific users

A security policy says users may only install agents built by Microsoft or by the company itself, not by external publishers. What should the admin do?

⬜ In Agents > Settings > Allowed agent types, turn off apps and agents built by external publishers
⬜ Delete the Agent Registry
⬜ Block every user from Copilot with Conditional Access
⬜ Turn off web search in Copilot

A department has submitted an agent to be published to the whole organization, and it appears under Requests in the Agent Registry. Which two roles can approve the request? (select two)

⬜ Global Reader
⬜ Reports Reader
⬜ Global Administrator
⬜ Teams Communications Support Specialist
⬜ AI Administrator

A Power Platform admin wants to check the operational health of conversational and autonomous agents built in Copilot Studio, such as how often sessions are resolved successfully. Where should the admin look?

⬜ The Exchange admin center
⬜ Settings > Domains in the Microsoft 365 admin center
⬜ The Purview Data explorer
⬜ Monitor > Copilot Studio in the Power Platform admin center
