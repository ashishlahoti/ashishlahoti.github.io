Free Azure Administrator (AZ-104) Online Practice Exam

Overview

  1. This is an Associate level certification for Azure administrators. It’s for people who implement, manage and monitor an organization’s Azure environment: identities and governance, storage, compute, virtual networks, and monitoring, backup and recovery.
  2. Passing AZ-104 earns the Microsoft Certified: Azure Administrator Associate credential. It’s also the prerequisite for the Azure Solutions Architect Expert (AZ-305) certification. Microsoft recommends hands-on experience with Azure administration, including the Azure portal, PowerShell, the Azure CLI and ARM/Bicep templates.
  3. Exam code is AZ-104 (Microsoft Azure Administrator). Cost varies by country/region. You can retake the exam 24 hours after a first failed attempt, and longer waiting periods apply to later retakes.
  4. Exam duration is 100 minutes. Microsoft doesn’t publish a fixed question count (usually 40 to 60 questions). Question types include multiple choice, multiple response, Yes/No statement series, drag-and-drop, exhibits and case studies.
  5. Passing score is 700 (out of 1000).
  6. The current skills outline is dated April 17, 2026. Its five domains are weighted at 20–25%, 15–20%, 20–25%, 15–20% and 10–15%.
  7. Like other Microsoft role-based certifications, it is valid for 1 year and can be renewed for free by passing an online assessment on Microsoft Learn before it expires.
  8. Study Guide and certification page for more details.
