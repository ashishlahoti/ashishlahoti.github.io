Disclaimer: Databricks is a protected Brand. These exam questions are neither endorsed by nor affiliated with Databricks. These are not the official Databricks exam questions/dumps. These questions are created from the exam guide, the Databricks documentation, MLflow and Apache Spark documentation, and standard ML references such as scikit-learn. Once you go through these questions and their concepts, you are more than ready to crack the exam in first attempt.

Note: The exam guide still lists Hyperopt, but Databricks no longer includes it in Databricks Runtime ML after 16.4 LTS and now recommends Optuna or Ray Tune. Questions cover Hyperopt as the exam does, and the explanations point out the change.

Free Databricks Machine Learning Associate Online Practice Exam

Overview

  1. This is an Associate level certification that validates using Databricks to perform basic machine learning tasks: AutoML, Feature Store, MLflow and Unity Catalog model management, data processing, model development and deployment.
  2. The exam has 48 scored multiple-choice and multiple-selection questions in 90 minutes; up to 10 unscored items may appear, with extra time built in.
  3. The exam fee is US$200 plus taxes, delivered online proctored or at a test center, in English, Japanese, Brazilian Portuguese and Korean. No test aids are allowed.
  4. There are no prerequisites; Databricks recommends about 6 months of hands-on experience with the Databricks Platform.
  5. Databricks doesn’t publish the pass mark on the exam page; this practice test uses 70% as the target.
  6. The four sections are weighted 38%, 19%, 31% and 12%, so the full-length test has 48 questions split 18 / 9 / 15 / 6.
  7. The certification is valid for 2 years; recertify by taking the current exam.
  8. Exam page and exam guide for more details.

Domain 1: Databricks Machine Learning (38%)

A team wants a quick baseline for a classification problem. They need the tool to prepare data, train and tune several algorithms, and hand back editable notebooks with the source code. Which Databricks feature does this?

⬜ AutoML
⬜ Model Serving
⬜ Databricks SQL dashboards
⬜ Unity Catalog volumes

Which problem types does Databricks AutoML support?

⬜ Only large language model fine-tuning
⬜ Only clustering and anomaly detection
⬜ Only image classification
⬜ Classification, regression and forecasting

After an AutoML classification experiment, where can a data scientist find the code for a trial that wasn’t the best one?

⬜ In the cluster’s init scripts
⬜ In that trial’s MLflow run, under Artifacts, where the generated notebook is saved
⬜ In the Spark UI event log
⬜ Nowhere — only the best trial’s code is ever kept

An AutoML notebook doesn’t show SHAP feature importance. Why, and how do you get it?

⬜ SHAP isn’t available for classification models
⬜ SHAP needs a GPU cluster and can’t be turned on otherwise
⬜ SHAP calculations are off by default because they’re memory-intensive; set shap_enabled = True in the notebook and run it again
⬜ SHAP only appears in Model Serving logs

What’s a main advantage of running ML work on Databricks Runtime for Machine Learning instead of the standard runtime?

⬜ It only supports R notebooks
⬜ It disables MLflow tracking to save cost
⬜ It comes with pre-built ML and deep learning infrastructure and popular ML libraries already installed, with tested updates and optimizations
⬜ It removes the need for any cluster

What makes a Delta table usable as a feature table in Unity Catalog?

⬜ A primary key constraint
⬜ A Z-order index
⬜ Being stored in DBFS root
⬜ A foreign key to the model registry

Why does Databricks favor feature tables in Unity Catalog over workspace-level feature tables?

⬜ Workspace-level tables give better cross-workspace governance
⬜ Unity Catalog feature tables are governed like other data assets and are visible to every workspace attached to the same metastore
⬜ Unity Catalog feature tables can only be read by one notebook
⬜ Unity Catalog removes the need for primary keys

A nightly job recomputes features for some customers and must update only those rows in an existing feature table. Which call is appropriate?

⬜ fe.create_table(…) every night
⬜ fe.drop_table(…) then rewrite everything
⬜ spark.sql(‘TRUNCATE TABLE …’) before each write
⬜ fe.write_table(name=…, df=updates_df, mode=‘merge’)

A model is trained with FeatureLookup and create_training_set and logged with the Feature Engineering client. What happens at batch inference with score_batch?

⬜ score_batch retrains the model on new data
⬜ It automatically looks up the required features from the feature tables using the lookup keys before scoring
⬜ score_batch only works for real-time endpoints
⬜ You must join every feature manually before calling score_batch

At scoring time, a team wants to override one feature value with fresher data while letting the others be looked up as usual. How?

⬜ Include a column with that feature’s name in the DataFrame passed to score_batch
⬜ It’s impossible to override a looked-up feature
⬜ Edit the feature table by hand before every call
⬜ Retrain the model without that feature

What’s the difference between offline and online feature tables on Databricks?

⬜ Online tables are used for training and offline tables only for serving
⬜ Offline tables can’t have primary keys
⬜ They’re identical, with different names
⬜ Offline tables are the source feature data; online tables are synced copies in an online store for low-latency access from real-time apps and serving endpoints

A team logs its own evaluation chart and a custom metric inside an MLflow run. Where do these show up in Databricks?

⬜ Only in the driver’s stdout
⬜ Only in the cluster event log
⬜ In the run’s details in the MLflow UI, with metrics and artifacts that can be compared across runs in the experiment
⬜ Nowhere — custom items can’t be logged

Which MLflow registry setting does a team use to register models in Unity Catalog?

⬜ mlflow.set_registry_uri(“workspace”) with a single-word name
⬜ mlflow.set_registry_uri(“databricks-uc”), with model names in the form catalog.schema.model
⬜ mlflow.set_experiment(“uc”)
⬜ No setting — models can’t go in Unity Catalog

What benefits do Models in Unity Catalog offer over the legacy Workspace Model Registry?

⬜ Webhooks on every model event
⬜ No need for model signatures
⬜ Support for model stages such as Staging and Production
⬜ Centralized access control, auditing, lineage and model discovery across workspaces

A new model version has beaten the current production model. How do you promote it in Unity Catalog without changing the workloads that load the model?

⬜ Move the version to the “Production” stage
⬜ Create a new registered model with the same name
⬜ Reassign the “Champion” alias to the new version
⬜ Delete the old version and rename the new one

A team wants to mark a model version as approved after validation. What should they use?

⬜ A model version tag, such as validation_status:approved, set with set_model_version_tag()
⬜ A cluster tag
⬜ A stage transition to Approved
⬜ A notebook comment

An organization restricts development access to production data and wants safe automated retraining. Which deployment pattern does Databricks recommend?

⬜ Email the model file to the operations team
⬜ Deploy models: train once in dev and copy the artifact to prod
⬜ Train directly in production notebooks with no review
⬜ Deploy code: move the training code through dev, staging and prod, and train the model in each environment

When might the deploy models pattern be preferred over deploy code?

⬜ Never — it’s not a valid pattern
⬜ When training is very expensive or hard to reproduce, everything is in a single workspace, and no external repos or CI/CD are used
⬜ Whenever automated retraining is required
⬜ Whenever production data access is restricted

An engineer wants MLflow to log a scikit-learn model with its parameters and metrics without writing log_param and log_metric calls. Which call does this?

⬜ mlflow.autolog() (or mlflow.sklearn.autolog())
⬜ mlflow.set_tracking_uri(‘databricks’)
⬜ mlflow.register_model()
⬜ mlflow.set_experiment(’/Shared/exp’)

A training set has customer_id and event_ts, and features change over time. How should features be joined without leaking values from after each event?

⬜ Join on customer_id, then filter by timestamp
⬜ Add customer_id and event_ts to a VectorAssembler
⬜ Use a 30-day window function on the label query
⬜ Use a time series feature table and a FeatureLookup with timestamp_lookup_key=‘event_ts’ in create_training_set

A data scientist wants the top 5 runs of an experiment by validation AUC, only for runs with model_type xgboost, as a pandas DataFrame in Python. Which API fits?

⬜ mlflow.register_model
⬜ mlflow ui –top 5
⬜ mlflow.search_runs with filter_string, order_by and max_results
⬜ mlflow.autolog

Domain 2: Data Processing (19%)

A data scientist wants quick summary statistics and approximate distributions for a Spark DataFrame in a Databricks notebook. Which command fits, and how can they get more precise statistics?

⬜ dbutils.data.summarize(df); set precise=True for higher-precision statistics
⬜ dbutils.fs.ls(df)
⬜ spark.catalog.listTables()
⬜ df.collect() and compute statistics by hand

Using the IQR method, which values count as mild outliers?

⬜ Any value above the median
⬜ Values between Q1 and Q3
⬜ Values below Q1 − 1.5×IQR or above Q3 + 1.5×IQR
⬜ Values within one standard deviation of the mean

A numeric feature has missing values and a few extreme outliers. Which imputation statistic is usually the safer choice, and why?

⬜ Zero, because it’s neutral
⬜ The mean, because it ignores outliers
⬜ The maximum, to avoid underestimating
⬜ The median, because it isn’t pulled toward extreme values the way the mean is

A categorical column such as payment_method has missing values. Which imputation strategy fits?

⬜ Drop the whole column automatically
⬜ The median
⬜ The mode (most frequent value), after indexing, because mean and median aren’t meaningful for categories
⬜ The mean

Which statement about Spark ML’s Imputer is correct?

⬜ It imputes using the maximum value by default
⬜ Input columns must be numeric, and all null values in the input columns are treated as missing and imputed
⬜ It only works on string columns
⬜ It can’t handle null values

In Spark ML, what does OneHotEncoder take as input and produce as output?

⬜ A categorical label index (often from StringIndexer) mapped to a binary vector with at most one 1
⬜ Raw strings mapped to integers
⬜ Text split into words
⬜ Continuous values scaled to 0–1

Several one-hot encoded columns and numeric columns must be combined into one features column for a Spark ML model. What should be used?

⬜ CrossValidator
⬜ VectorAssembler
⬜ StringIndexer
⬜ Imputer

A regression target such as house price is highly right-skewed. Which transformation is commonly applied, and what must be remembered afterward?

⬜ Train on log(price), then exponentiate predictions back to the original scale before interpreting them or computing metrics
⬜ Remove all high prices
⬜ One-hot encode the price
⬜ Take the log and report the log values to users as prices

A team computes RMSE directly on predictions from a model trained on log-transformed prices and reports it in dollars. What’s wrong?

⬜ Nothing; log RMSE equals dollar RMSE
⬜ They should have used accuracy instead
⬜ The predictions are in log scale; they must be exponentiated before computing an RMSE in dollars
⬜ RMSE can’t be used for regression

A scikit-learn scoring function must run over 500 million rows in a Spark DataFrame efficiently, receiving batches as pandas Series. Which construct fits?

⬜ A plain row-at-a-time Python UDF
⬜ A pandas_udf (vectorized UDF)
⬜ df.collect() and scoring on the driver
⬜ A Scala aggregate function

Domain 3: Model Development (31%)

A team must predict a customer’s monthly spend in dollars. Which type of model is appropriate?

⬜ A classification model
⬜ A dimensionality reduction model
⬜ A clustering model
⬜ A regression model

Only 2% of transactions in a training set are fraud. Which approach helps mitigate the imbalance?

⬜ Weight classes inversely to their frequency, for example class_weight=‘balanced’
⬜ Remove all fraud examples
⬜ Evaluate only with accuracy
⬜ Duplicate the majority class

In Spark ML, what’s the difference between an Estimator and a Transformer?

⬜ A Transformer is fit on data to produce an Estimator
⬜ They’re the same thing
⬜ Estimators only work on images
⬜ An Estimator is fit on a DataFrame to produce a Transformer; a Transformer converts one DataFrame into another with transform()

A Spark ML Pipeline contains a StringIndexer, a VectorAssembler and a LogisticRegression. What does pipeline.fit(train) return?

⬜ A CrossValidator
⬜ An Estimator that must be fit again
⬜ A PipelineModel, a Transformer in which each Estimator stage has been replaced by its fitted model
⬜ A list of predictions

A CrossValidator uses a parameter grid of 3 × 2 values and 2 folds. How many models are trained during tuning, before the final refit?

⬜ 2
⬜ 12
⬜ 5
⬜ 6

What’s the main trade-off of cross-validation compared with a single train-validation split?

⬜ They cost exactly the same
⬜ Cross-validation is cheaper and less reliable
⬜ A train-validation split is always more reliable
⬜ Cross-validation is more reliable, especially on smaller data, but it costs more because each setting is evaluated k times

Which statement about Hyperopt on Databricks is correct today?

⬜ Hyperopt is required for AutoML
⬜ Hyperopt is no longer maintained and isn’t included after Databricks Runtime 16.4 LTS ML; Databricks recommends Optuna for single-node tuning and Ray Tune for distributed tuning
⬜ Hyperopt replaces MLflow
⬜ Hyperopt is the recommended tuning library for new projects

In Hyperopt’s fmin(), what does the objective function return, and how is the search algorithm chosen?

⬜ It returns nothing; algo is always grid search
⬜ It returns the best model; algo sets the number of folds
⬜ It returns a loss value; algo selects the search, such as hyperopt.tpe.suggest (TPE) or hyperopt.rand.suggest (random)
⬜ It returns accuracy to maximize; algo picks the cluster size

A team tunes a single-node scikit-learn model with Hyperopt and wants trials to run in parallel across the cluster. Which Trials class fits, and when should it NOT be used?

⬜ SparkTrials; don’t use it with distributed algorithms such as MLlib or Horovod, which should use the default Trials class
⬜ SparkTrials; it’s required for MLlib models
⬜ MongoTrials; it’s the only parallel option on Databricks
⬜ Trials; never use SparkTrials

Which metric is most appropriate when a classifier must balance precision and recall equally?

⬜ RMSE
⬜ MAE
⬜ F1 score
⬜ R-squared

A team needs a classification metric that evaluates ranking quality across all thresholds using predicted scores. Which one fits?

⬜ MAE
⬜ ROC AUC
⬜ Accuracy at a 0.5 threshold
⬜ R-squared

Which metric uses predicted probabilities and heavily penalizes confident wrong predictions?

⬜ Precision
⬜ MAE
⬜ Accuracy
⬜ Log loss

A fraud model must catch as many fraud cases as possible; a few false alarms are acceptable. Which metric should guide model choice?

⬜ Recall
⬜ R-squared
⬜ Training time
⬜ Precision

Making a model more complex lowers its training error but raises its validation error. What’s happening?

⬜ The data has drifted
⬜ Bias is rising: the model is underfitting
⬜ Variance is rising: the model is starting to overfit
⬜ Nothing; lower training error is always better

Which regression metric gives the share of variance explained, with 1.0 as a perfect fit?

⬜ MAE
⬜ F1
⬜ Log loss
⬜ R-squared (coefficient of determination)

A team needs train, validation and test splits that come out the same every time the code reruns. Which Spark API supports this?

⬜ df.sample(0.7) three times without a seed
⬜ df.repartition(3), using each partition as a split
⬜ df.orderBy(rand()).limit(n)
⬜ df.randomSplit([0.7, 0.15, 0.15], seed=42)

Domain 4: Model Deployment (12%)

A retailer scores all customers overnight and writes the results to a table for next-day campaigns. Which serving approach fits?

⬜ Batch inference
⬜ Real-time Model Serving endpoint
⬜ Streaming inference on every click
⬜ Manual scoring in a notebook each morning

A checkout page needs a fraud score within milliseconds for each transaction. Which Databricks approach fits?

⬜ Nightly batch scoring
⬜ Deploy the model to a Model Serving endpoint and query its REST API in real time
⬜ Export predictions to a CSV file
⬜ Weekly retraining only

A team wants to apply a registered MLflow model to a large Spark DataFrame for batch scoring. Which MLflow function wraps the model for this?

⬜ mlflow.log_metric
⬜ mlflow.set_experiment
⬜ mlflow.autolog
⬜ mlflow.pyfunc.spark_udf

A data scientist wants to score a small pandas DataFrame with a registered MLflow model in a notebook. What works?

⬜ Load it with mlflow.pyfunc.load_model and call predict() on the pandas DataFrame
⬜ Deploy a Model Serving endpoint first; pandas can’t be used
⬜ Retrain the model on the pandas data
⬜ Convert the model to SQL

A team wants to A/B test a new model version against the current one on the same Model Serving endpoint. What should they configure?

⬜ Create two separate workspaces
⬜ Serve both models on the endpoint and set a traffic split in traffic_config, for example 90/10
⬜ Replace the old model and compare later
⬜ Mix a custom model with an external model on the same endpoint

New events arrive continuously and the business wants predictions updated incrementally without rescoring everything. Which approach fits best?

⬜ Manual notebook runs
⬜ Only real-time REST calls from a dashboard
