Overview

  1. PAL I (Professional Agile Leadership) is Scrum.org’s certification for managers, executives and other leaders who support agile teams and organizations. There are no prerequisites, and a course is recommended but not required.
  2. The PAL I assessment has 36 questions in 60 minutes (multiple choice, multiple answer and true/false), and you need 85% to pass. The fee is US$200 per attempt, and the certification is for life with no renewal fee.
  3. Questions come from the Professional Scrum Competencies: understanding and applying the Scrum framework, developing people and teams, managing products with agility, developing and delivering products professionally, and evolving the agile organization.
  4. Scrum.org doesn’t publish weights, so this bank has 72 questions split 18 / 18 / 14 / 8 / 14, with 8 multiple-answer questions. The online version runs them as two practice tests of 36 questions in 60 minutes, each mixing all five areas, like the real assessment.

Focus Area 5: Evolving the Agile Organization

Which framework helps leaders measure and improve an organization’s ability to deliver value with evidence?

⬜ Earned Value Management
⬜ A traditional balanced scorecard of output
⬜ Evidence-Based Management (EBM)
⬜ Individual performance rankings

Which EBM Key Value Area describes the value that customers experience today?

⬜ Unrealized Value
⬜ Time-to-Market
⬜ Current Value
⬜ Ability to Innovate

Which EBM Key Value Area reflects the satisfaction gap between customers’ desired outcomes and their current experience?

⬜ Current Value
⬜ Unrealized Value
⬜ Time-to-Market
⬜ Ability to Innovate

Lead time from idea to release keeps growing. Which EBM Key Value Area does this affect?

⬜ Current Value
⬜ Time-to-Market
⬜ Unrealized Value
⬜ Ability to Innovate

Technical debt and maintenance work take most of the team’s capacity. Which EBM Key Value Area suffers?

⬜ Ability to Innovate
⬜ Current Value
⬜ Unrealized Value
⬜ Time-to-Market

In EBM, which goals sit between a long-term Strategic Goal and the near-term goals a team works on now?

⬜ Immediate Tactical Goals
⬜ Sprint Goals only
⬜ Annual budgets
⬜ Intermediate Goals

How does EBM suggest organizations move toward their goals under uncertainty?

⬜ Experiment, inspect and adapt
⬜ Create a detailed multi-year plan
⬜ Avoid change until certain
⬜ Copy competitors’ plans

A leader wants to compare velocity across Scrum Teams to judge which is best. Why is this a poor measure?

⬜ Velocity is always identical across teams
⬜ Velocity is a Scrum artifact
⬜ It’s team-specific and not about value
⬜ Comparing velocity improves collaboration

What does Organizational Design and Culture focus on in agile organizations?

⬜ Only the office layout
⬜ Writing longer job descriptions
⬜ How structures and culture help or hinder delivering value
⬜ Creating more approval layers

How should an organization approach changing toward greater agility?

⬜ Iteratively and incrementally
⬜ One big-bang reorganization
⬜ By mandating new tools only
⬜ By renaming roles without other changes

Teams are organized by component, causing many handoffs. What should leaders consider?

⬜ Adding more coordination meetings
⬜ Splitting teams into smaller components
⬜ Hiring more project managers
⬜ Organizing around product value

Which leadership behavior best helps an agile culture grow?

⬜ Hiding bad news from executives
⬜ Modeling transparency and acting on evidence
⬜ Making all decisions centrally
⬜ Rewarding output over outcomes

Which TWO are EBM Key Value Areas? (Choose two.)

⬜ Resource utilization of each person
⬜ Time-to-Market
⬜ Number of hours logged per team
⬜ Ability to Innovate

Which TWO practices support evolving an agile organization? (Choose two.)

⬜ Changing the organization step by step
⬜ Using evidence to guide decisions
⬜ Rolling out a fixed transformation plan unchanged
⬜ Measuring success by adoption of ceremonies
