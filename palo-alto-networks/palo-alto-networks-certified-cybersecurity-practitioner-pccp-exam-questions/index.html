Free Palo Alto Networks Certified Cybersecurity Practitioner (PCCP) Online Practice Exam

Overview

  1. The Palo Alto Networks Certified Cybersecurity Practitioner (PCCP) validates foundational knowledge of cybersecurity, network security, secure access (SASE), cloud security, endpoint security, security operations and identity security, and of the Palo Alto Networks products in each area.
  2. The exam is 90 minutes of multiple-choice questions, delivered by Pearson VUE, and costs USD 150. The datasheet doesn’t publish the question count; candidates report about 75 questions.
  3. Palo Alto Networks doesn’t publish the PCCP pass mark. This practice test uses 70% as the target.
  4. The datasheet weights seven domains; this full-length test’s 75 questions are split 15 / 11 / 10 / 15 / 10 / 7 / 7, with 7 questions that ask you to choose two answers.
  5. Topics include AAA, MITRE ATT&CK, APTs, MFA, MDM and MAM, email security, ZTNA, IPS, DNS Security, TLS decryption, CDSS, Precision AI, SASE and SSE, CASB, DLP, RBI, Prisma Access, Prisma SD-WAN, Prisma Browser, AI Access Security, shared responsibility, CSPM, CWPP, CNAPP, CDR, Cortex Cloud, Prisma AIRS, UEBA, EDR, XDR, host controls, threat hunting, incident response, SIEM, SOAR, ASM, XSIAM, Unit 42, PAM, JIT, ITDR, lifecycle management, IGA and Idira.
  6. PCCP exam page and datasheet for more details.

Domain 1: Cybersecurity (20%)

In the AAA security framework, which function records what an authenticated user did during a session, such as the commands run and when the session started and stopped?

⬜ Authentication
⬜ Accounting
⬜ Authorization
⬜ Attestation

A help desk asks, “Who are you?” before resetting a password, then checks whether the caller’s role allows the reset. Which pair of controls is being applied, in order?

⬜ Authentication, then authorization
⬜ Authorization, then accounting
⬜ Accounting, then authentication
⬜ Authorization, then authentication

A threat report lists Initial Access, Persistence and Exfiltration as the columns of an attack map. In MITRE ATT&CK terms, what does each column describe?

⬜ A specific way the adversary carries out an action
⬜ A named threat group and its known tooling
⬜ A recommended control that blocks a technique
⬜ The adversary’s objective at a stage of the attack

An analyst maps “credential dumping from LSASS memory” to MITRE ATT&CK. Which ATT&CK element is this most specific behavior?

⬜ A mitigation listed under Credential Access
⬜ A data source used to detect the attack
⬜ A separate top-level tactic named Credential Dumping in the matrix
⬜ A technique or sub-technique under the Credential Access tactic

Which characteristics distinguish an advanced persistent threat (APT) from opportunistic attacks? (Choose two.)

⬜ It is a long-term campaign that tries to stay undetected
⬜ It is often run by well-resourced or nation-state groups
⬜ It encrypts every reachable file within minutes of entry
⬜ It relies only on mass phishing sent to random addresses

A VPN login asks for a PIN and then a one-time code from a hardware token on the user’s keyring. Which MFA factor categories are combined?

⬜ Something you know and something you are
⬜ Something you have used twice over
⬜ Something you know and something you have
⬜ Something you are and somewhere you are

Which statement best describes the role of an identity provider (IdP) in single sign-on?

⬜ It inspects each application session for malware in transit
⬜ It grants every authenticated user administrator rights in each app
⬜ It verifies the user once and passes signed assertions to apps
⬜ It stores a separate password for every application the user opens

An attacker who has phished one password still cannot sign in because the account requires a hardware security key. Which control stopped the attack?

⬜ Single sign-on
⬜ Accounting logs on the TACACS+ server
⬜ Role-based access control
⬜ Multi-factor authentication

A company wants to enforce passcodes, push approved apps and remotely wipe lost corporate phones. Which technology fits?

⬜ A secure email gateway in front of the mail server
⬜ A cloud access security broker in API mode
⬜ Mobile application management limited to one app container
⬜ Mobile device management (MDM)

Employees refuse to enroll personal phones in device management. Which approach protects corporate data in work apps without controlling the whole device?

⬜ Full MDM enrollment with device-wide remote wipe
⬜ Mobile application management (MAM) of the corporate apps
⬜ Disk encryption policies pushed from the EDR console
⬜ A host-based firewall on each personal phone

What is the main limitation of a secure email gateway (SEG) that integrated cloud email security (ICES) addresses?

⬜ A SEG must be installed as an agent on every mailbox user’s laptop
⬜ A SEG cannot scan attachments for malware or sandbox them in any way
⬜ A SEG at the mail boundary misses internal and post-delivery mail
⬜ A SEG works only for on-premises web traffic

Which statement correctly contrasts a secure web gateway with a secure email gateway?

⬜ A SWG filters web traffic; a SEG filters inbound and outbound email
⬜ A SWG blocks phishing email only after users report it to the SOC team
⬜ A SWG filters email; a SEG filters web browsing
⬜ Both are identical names for one product category

Which principle states that users and services should receive only the access they need for their task?

⬜ Implicit trust
⬜ Defense in depth
⬜ Least privilege
⬜ Separation of duties

Access is granted based on attributes such as the user’s location, device type and time of day. Which access control model is this?

⬜ Mandatory access control (MAC)
⬜ Attribute-based access control (ABAC)
⬜ Role-based access control (RBAC)
⬜ Discretionary access control (DAC)

In MITRE ATT&CK, which tactic covers an attacker sending stolen data out of the network, for example over DNS?

⬜ Command and Control
⬜ Collection
⬜ Impact
⬜ Exfiltration

Domain 2: Network Security (14%)

How does Zero Trust Network Access (ZTNA) differ from a traditional remote access VPN?

⬜ ZTNA only works for on-premises applications
⬜ ZTNA trusts any device that connects from a corporate IP range
⬜ ZTNA grants per-app access after verifying user and device
⬜ ZTNA places the user on the whole internal network once the tunnel is up

What is the key difference between an intrusion prevention system (IPS) and an intrusion detection system (IDS)?

⬜ An IPS replaces the firewall’s rule base entirely
⬜ An IPS only works on endpoints, while an IDS only works on network links
⬜ An IPS sits inline and can block traffic; an IDS monitors and alerts
⬜ An IDS drops malicious packets; an IPS only writes logs

What is DNS tunneling?

⬜ Flooding a DNS server with requests to take it offline
⬜ Encrypting DNS traffic between a client and its resolver
⬜ Hiding other data or commands inside DNS queries and responses
⬜ Redirecting users to a fake site by altering DNS records

How does Advanced DNS Security detect DNS tunneling?

⬜ Comparing each domain to a static list updated once a month
⬜ Real-time analysis of DNS query patterns with machine learning
⬜ Blocking all DNS queries that leave the corporate network
⬜ Decrypting HTTPS sessions to read embedded DNS payloads

Why do organizations decrypt SSL/TLS traffic at the firewall?

⬜ To speed up encrypted sessions by removing the TLS handshake step
⬜ To make traffic unreadable to the security team
⬜ To replace the need for server certificates on websites
⬜ To inspect plaintext for threats hidden by encryption

Which decryption type inspects traffic from internal users to websites on the internet?

⬜ SSL Inbound Inspection
⬜ SSL Forward Proxy
⬜ Passive port mirroring
⬜ SSH Proxy

Why does signature-based protection alone fail against zero-day malware?

⬜ Signatures require too much memory to run on firewalls
⬜ Signatures work only on encrypted traffic
⬜ Signatures block too much legitimate business traffic to be usable
⬜ Signatures match only threats that were already seen

Which Cloud-Delivered Security Services (CDSS) subscription is the inline intrusion prevention service that blocks exploits and command-and-control traffic?

⬜ Advanced WildFire
⬜ Advanced URL Filtering
⬜ Advanced Threat Prevention
⬜ Enterprise DLP

Which CDSS subscriptions are part of the Palo Alto Networks network security services? (Choose two.)

⬜ Advanced WildFire
⬜ Prisma SD-WAN
⬜ Cortex XSOAR
⬜ Advanced URL Filtering

What is Precision AI in Palo Alto Networks products?

⬜ A third-party chatbot used only for customer support
⬜ A rule engine that blocks by static file hash lists
⬜ Proprietary AI combining ML, deep learning and GenAI
⬜ A hardware accelerator card sold for PA-Series firewalls

A URL filtering policy blocks the category “malware” and “phishing”. What does this control prevent?

⬜ Users reaching web destinations classified as malicious
⬜ Attackers dumping credentials from memory
⬜ Malicious files arriving by email attachment
⬜ Lateral movement between internal servers over SMB

⬜ Nothing changed, because SSE and SASE are the same thing
⬜ It has replaced its security services with networking
⬜ It has moved from SASE down to SSE only
⬜ It has moved from SSE to full SASE

Which services are core components of security service edge (SSE)? (Choose two.)

⬜ Secure web gateway
⬜ Zero Trust network access
⬜ SD-WAN
⬜ MPLS circuits

What does a cloud access security broker (CASB) primarily provide?

⬜ Visibility and policy control over cloud app use and data
⬜ Signature updates for endpoint antivirus engines
⬜ Physical security for the provider’s data centers
⬜ Routing of branch office traffic over the best available WAN link

A CASB connects to a sanctioned SaaS app through the vendor’s API. What can it do in this mode?

⬜ Route the app’s traffic over the SD-WAN fabric
⬜ Scan data already stored in the app and review sharing settings
⬜ Replace the SaaS provider’s own authentication
⬜ Block an upload in real time before it leaves the browser

Data loss prevention (DLP) is designed to protect data in which states? (Choose two.)

⬜ Only after it has been deleted
⬜ In motion across networks
⬜ Only inside encrypted backups
⬜ At rest in storage

How does remote browser isolation (RBI) protect users?

⬜ It encrypts the browser cache and cookies stored on the user’s laptop
⬜ It blocks all websites that are not on an allow list
⬜ It forces users to sign in to every website with MFA
⬜ Web code runs remotely and only safe rendering reaches the user

A company needs contractors on personal laptops to reach SaaS and private web apps securely, without installing an agent on the device. Which Prisma SASE component fits?

⬜ Prisma SD-WAN
⬜ Prisma AIRS
⬜ Cortex XDR agent
⬜ Prisma Browser

In Prisma Access, what does a service connection provide?

⬜ Internet access for mobile users without any other networking setup at all
⬜ Access from users and branches to HQ or data center resources
⬜ A GlobalProtect client for unmanaged devices
⬜ Branch WAN path selection by application

What does Prisma SD-WAN provide?

⬜ App-defined, autonomous SD-WAN for branches and data centers
⬜ Agentless scanning of cloud workloads for misconfigurations and vulnerabilities
⬜ Detection of compromised identities after sign-in
⬜ A secure browser for unmanaged contractor laptops

Employees use many generative AI apps that IT never approved. Which Prisma SASE capability gives visibility into this shadow AI and controls the data sent to it?

⬜ Prisma SD-WAN
⬜ Advanced DNS Security
⬜ AI Access Security
⬜ Prisma AIRS

Domain 4: Cloud Security (20%)

After a breach, a company tells auditors that its cloud provider was responsible for a misconfigured access policy on the company’s own storage. Which shared responsibility principle shows why this is wrong?

⬜ The provider is responsible for the customer’s data classification
⬜ Responsibility is split identically in IaaS, PaaS and SaaS service models
⬜ The provider secures the cloud; the customer secures what it puts in it
⬜ The customer patches the provider’s physical hypervisors

In an IaaS deployment, which items does the customer manage? (Choose two.)

⬜ Physical data center access
⬜ Applications and data
⬜ The virtualization layer
⬜ The guest operating system

In a SaaS application, what remains the customer’s responsibility?

⬜ Hardening the provider’s servers and hypervisors
⬜ Scaling the database cluster
⬜ Patching the application’s code
⬜ Managing user access and its own data

Which cloud service model gives developers a managed runtime where they deploy code without managing the operating system?

⬜ Infrastructure as a service (IaaS)
⬜ Software as a service (SaaS)
⬜ Platform as a service (PaaS)
⬜ On-premises virtualization

A storage bucket holding customer records is accidentally made public. Which tool category is designed to find this kind of issue?

⬜ Cloud security posture management (CSPM)
⬜ Secure web gateway (SWG)
⬜ Intrusion prevention system (IPS)
⬜ Endpoint detection and response (EDR)

Which capabilities does a cloud workload protection platform (CWPP) focus on? (Choose two.)

⬜ Routing branch office traffic to SaaS apps
⬜ Vulnerability scanning of hosts, containers and serverless functions
⬜ Runtime protection of running workloads
⬜ Discovery of misconfigured cloud accounts and IAM policies

What does a cloud-native application protection platform (CNAPP) combine?

⬜ SD-WAN and SWG for branch users
⬜ Posture, workload and code security in one platform
⬜ Endpoint antivirus and host firewalls for employee laptops
⬜ Only firewall rules for the cloud provider’s network

Which cloud security challenge does application security (AppSec) address in the code-to-cloud lifecycle?

⬜ Signal interference on branch Wi-Fi networks
⬜ Users browsing to phishing sites from the office network or home
⬜ Flaws and secrets in code and IaC before deployment
⬜ Physical theft of servers from the provider’s facility

What does cloud detection and response (CDR) add beyond posture management?

⬜ A report of misconfigured cloud resource settings produced every week
⬜ Faster SD-WAN failover between cloud regions
⬜ Cheaper storage tiers for cloud audit logs
⬜ Real-time response to active threats in cloud workloads

What is Cortex Cloud?

⬜ A managed incident response retainer
⬜ The next version of Prisma Cloud, adding CDR to CNAPP
⬜ A SASE service that connects branch offices to SaaS and data centers
⬜ A browser that secures contractor access

Why do cloud runtime security programs combine agentless scanning with an agent on workloads?

⬜ Agents remove the need for any posture management
⬜ Agents cannot detect anything at all that agentless scanning would miss
⬜ Agentless gives visibility; an agent blocks attacks live
⬜ Agentless scanning is needed only for on-premises servers

Which type of risk is described as “cloud posture”?

⬜ Malware executing inside a container right now
⬜ Misconfigurations and excess permissions in cloud resources
⬜ Phishing emails reaching employee mailboxes
⬜ Bugs in application code that has not yet been deployed to production

What does Prisma AIRS protect?

⬜ AI apps, agents, models and data, e.g. from prompt injection
⬜ Branch routers against link failures
⬜ Privileged account passwords stored in a credential vault for rotation
⬜ Employee laptops against USB malware

Which statement about multicloud environments is accurate from a security point of view?

⬜ Shared responsibility no longer applies in multicloud
⬜ All providers share one identical security console
⬜ Misconfigurations cannot occur when workloads are spread across two providers
⬜ Each provider has its own controls, so consistent policy is harder

A container image contains a critical vulnerability. Where is the most effective point to stop it?

⬜ Wait for the CDR agent to alert after exploitation
⬜ Scan the image in the CI/CD pipeline and block it before deployment
⬜ Rely on the cloud provider to patch customer images
⬜ Add a URL filtering rule for the registry

Domain 5: Endpoint Security (13%)

What does user and entity behavior analytics (UEBA) do?

⬜ Encrypts endpoint disks with BitLocker or FileVault
⬜ Blocks files by matching them against a list of known malware hashes
⬜ Filters web traffic by URL category
⬜ Builds a baseline of normal behavior and flags deviations

How does EDR differ from traditional antivirus?

⬜ EDR protects only network devices, not endpoints
⬜ EDR relies only on signature files that are updated once each day
⬜ EDR replaces all need for patch management
⬜ EDR records endpoint activity to detect and respond to threats

What does XDR add compared with EDR?

⬜ It works only for mobile devices
⬜ It removes the need for any endpoint agent
⬜ It correlates endpoint, network, cloud and identity data
⬜ It only analyzes email attachments sent to the company domain

What does Cortex XDR Behavioral Threat Protection monitor to stop attacks that use built-in OS tools?

⬜ Only inbound network ports on the endpoint
⬜ Only the URL category of visited sites
⬜ Chains of related events, known as causality chains
⬜ Only the file hash of each executable

A security policy must block USB storage on finance laptops but allow one approved vendor’s encrypted drives. Which endpoint capability does this?

⬜ Application control
⬜ Disk encryption profiles
⬜ Device control with a vendor allow list
⬜ Host firewall rules

What does a host-based firewall on an endpoint do?

⬜ Encrypts data written to the local disk
⬜ Allows or blocks the endpoint’s traffic by rule
⬜ Blocks USB drives from mounting
⬜ Correlates logs from all of the firewalls in the company

A laptop with full-disk encryption is stolen while powered off. What does the encryption protect?

⬜ The user’s cloud apps from phishing
⬜ The laptop from being physically taken
⬜ The network from lateral movement
⬜ The confidentiality of data on the disk

What does application control (allow listing) enforce on an endpoint?

⬜ Only approved websites can be visited
⬜ Only approved applications are allowed to run
⬜ Only approved USB devices can connect
⬜ Only approved users can sign in

What is a host-based intrusion prevention system (HIPS)?

⬜ A tool that backs up endpoint data
⬜ An inline appliance that inspects traffic for a whole network segment
⬜ An agent that blocks malicious activity on its own host
⬜ A cloud service that scans email attachments

A VPN gateway should allow only endpoints whose security patches are current. Which mechanism checks this before granting access?

⬜ DNS sinkholing of malicious domains
⬜ HIP checks on patch status
⬜ URL filtering on the endpoint’s browser
⬜ Disk encryption visibility reports alone

What distinguishes threat hunting from alert triage?

⬜ Hunting proactively looks for hidden threats before any alert
⬜ Hunting only reviews alerts that tools have already raised
⬜ Hunting only happens after a breach has been confirmed by an outside party
⬜ Hunting is fully automated with no analyst involvement

During incident response, an infected host is isolated from the network to stop spread. Which phase is this?

⬜ Eradication
⬜ Containment
⬜ Lessons learned
⬜ Preparation

Which statement correctly contrasts SIEM and SOAR?

⬜ SIEM runs playbooks; SOAR only stores logs
⬜ SOAR replaces the need for any detection source or log collection platform
⬜ Both are endpoint agents installed on laptops
⬜ SIEM correlates logs to detect; SOAR automates response

What is a SOAR playbook?

⬜ A printed manual describing the company network
⬜ A predefined workflow that runs when a condition is met
⬜ A list of malware hashes and domains received from threat intelligence
⬜ A firewall rule that blocks a country

What does attack surface management (ASM), such as Cortex Xpanse, provide?

⬜ Continuous discovery of exposed internet-facing assets
⬜ Scanning internal laptops for USB devices
⬜ Recording privileged administrator sessions for later compliance audits
⬜ Filtering outbound web traffic by category

What is Cortex XSIAM?

⬜ A CNAPP for cloud workloads, code and posture only, with no SOC tools
⬜ A privileged access vault
⬜ An AI-driven SOC platform unifying SIEM, SOAR and XDR
⬜ A secure enterprise browser for contractors

Which services does Unit 42 provide? (Choose two.)

⬜ Software licensing for Prisma Access
⬜ Incident response for active breaches
⬜ SD-WAN appliance installation at branches
⬜ Proactive assessments and threat intelligence

Domain 7: Identity Security (10%)

What is a core capability of privileged access management (PAM)?

⬜ Vaulting credentials and recording privileged sessions
⬜ Scanning container images for vulnerabilities in the CI/CD pipeline
⬜ Blocking phishing emails at the mail gateway
⬜ Routing traffic across SD-WAN links

What does just-in-time (JIT) access reduce?

⬜ Standing privileges that attackers could abuse
⬜ The number of MFA prompts users see
⬜ The size of the audit log
⬜ Network latency for cloud apps

Why do non-human identities (machine identities) need special handling?

⬜ Their API keys and tokens must be vaulted and rotated
⬜ They are exempt from Zero Trust policies
⬜ They always have fewer rights than the human users who created them
⬜ They cannot authenticate to any cloud service

What does identity threat detection and response (ITDR) focus on?

⬜ Issuing new passwords at account creation
⬜ Encrypting identity data at rest
⬜ Detecting misuse of identities after sign-in
⬜ Assigning roles to new employees in the HR system of record

An employee leaves the company, but their accounts stay active for weeks. Which identity process failed?

⬜ Behavioral threat protection on endpoints
⬜ Deprovisioning in identity lifecycle management
⬜ Multi-factor authentication enrollment
⬜ URL filtering policy updates

What is the purpose of an access certification campaign in identity governance (IGA)?

⬜ The firewall decrypts traffic for inspection
⬜ Users request new access to an application through a self-service portal
⬜ Administrators issue TLS certificates to servers
⬜ Reviewers confirm or revoke existing access

What is Idira?

⬜ An identity security platform built on CyberArk
⬜ A secure enterprise browser for unmanaged contractor devices
⬜ A SASE networking product for branches
⬜ A Unit 42 incident response retainer
