Disclaimer: CompTIA is a protected Brand. These exam questions are neither endorsed by nor affiliated with CompTIA. These are not the official CompTIA exam questions/dumps. These questions are created from the CompTIA Cloud+ (CV0-004) exam objectives, NIST cloud publications, Kubernetes documentation and cloud provider documentation. They cover all six exam domains, and once you go through these questions and their concepts, you are more than ready to crack the exam in first attempt.

Note: Cloud+ is vendor-neutral. Where an example needs a concrete service, the questions use widely documented AWS and Kubernetes behavior, and the concepts apply equally to other providers.

Free CompTIA Cloud+ (CV0-004) Online Practice Exam

Overview

  1. The CompTIA Cloud+ (CV0-004) certification validates the skills to design, deploy, secure, operate and troubleshoot cloud environments.
  2. The exam has up to 90 questions (multiple-choice and performance-based) in 90 minutes, with a passing score of 750 on a 100–900 scale.
  3. The six domains are weighted 23%, 19%, 19%, 17%, 12% and 10%, so this test has 60 questions split 14 / 11 / 11 / 10 / 8 / 6.
  4. Topics include service and deployment models, high availability and DR (RPO/RTO, pilot light, warm standby), storage types, migration strategies, blue-green and canary releases, Kubernetes workloads, secrets and key management, network ACLs and security groups, scaling and cost optimization, observability, troubleshooting, CI/CD, GitOps and infrastructure as code.
  5. Exam objectives for more details.

Domain 1: Cloud Architecture (23%)

A customer-facing web tier must survive the loss of an entire availability zone with no manual intervention. Which pattern fits best?

⬜ A single VM with a daily snapshot copied to another zone
⬜ An active/passive pair in the same availability zone
⬜ A single large VM with a replicated block volume
⬜ An auto-scaling group spread across multiple availability zones behind a regional load balancer

A SaaS provider needs the lowest possible data loss (RPO) for an OLTP database at reasonable cost. Which replication approach fits?

⬜ Synchronous replication to a standby in another availability zone
⬜ Nightly full backups to object storage
⬜ Asynchronous replication every four hours
⬜ RAID 6 on the storage array

Which statement about the shared responsibility model is correct?

⬜ In IaaS the customer patches the hypervisor
⬜ In SaaS the provider runs the application down to the infrastructure; the customer mainly handles its data, users and access
⬜ In PaaS the customer patches the underlying OS
⬜ The provider classifies customer data in every model

Match the storage: (a) low-latency volumes for a database VM, (b) a shared POSIX file system for 20 render nodes, (c) cheap, durable storage for billions of images over HTTP.

⬜ (a) object, (b) block, (c) file
⬜ (a) file, (b) object, (c) block
⬜ (a) block, (b) file, (c) object
⬜ (a) block, (b) object, (c) file

A secondary workload can tolerate 4 hours of downtime and must have the lowest standby cost. Which DR approach fits?

⬜ Multi-site active/active
⬜ Warm standby
⬜ A hot site in a second region
⬜ Backup and restore (a cold approach), rebuilding infrastructure at recovery time

Users on other continents get slow image and video loads, while API calls are fine. What most directly fixes this?

⬜ Larger origin web servers
⬜ A database read replica per continent
⬜ A content delivery network caching the media at edge locations
⬜ Gzip on API responses

Which statement describes a hybrid cloud deployment model?

⬜ Two or more distinct cloud infrastructures (such as private and public) bound together to allow data and application portability
⬜ A cloud used only by one organization
⬜ A cloud shared by organizations with common concerns
⬜ A single public provider’s services

A web shop’s capacity automatically grows during sales and shrinks afterward, appearing unlimited to the business. Which essential cloud characteristic is this?

⬜ Broad network access
⬜ Rapid elasticity
⬜ Resource pooling
⬜ Measured service

Developers want to deploy code without managing servers, operating systems or runtimes. Which service model fits?

⬜ Infrastructure as a Service (IaaS)
⬜ On-premises virtualization
⬜ Platform as a Service (PaaS)
⬜ Colocation

Which hypervisor type runs directly on the hardware rather than on a host operating system?

⬜ Type 1 (bare-metal) hypervisor
⬜ Type 2 (hosted) hypervisor
⬜ A container runtime
⬜ An emulator

A DR design replicates data continuously to the recovery region and keeps core services ready, but application servers stay switched off until failover. Which strategy is this?

⬜ Backup and restore
⬜ Warm standby
⬜ Multi-site active/active
⬜ Pilot light

A DR copy of the workload runs at reduced capacity in a second region and can take traffic immediately, needing only to scale up. Which strategy is this?

⬜ Pilot light
⬜ Warm standby
⬜ Backup and restore
⬜ Cold site

What does the recovery point objective (RPO) describe?

⬜ The maximum acceptable downtime
⬜ The maximum acceptable amount of data loss, measured as time since the last recovery point
⬜ The time to detect an outage
⬜ The cost of the DR site

A team wants code that runs in response to events, scales automatically and is billed only while it runs, with no servers to manage. What should be used?

⬜ A reserved VM
⬜ A dedicated host
⬜ A serverless function service (FaaS)
⬜ A bare-metal server

Domain 2: Deployment (19%)

A data center must close in 90 days, and one legacy app is moved to cloud VMs as-is. Which migration strategy is this?

⬜ Rehost (lift and shift)
⬜ Refactor
⬜ Retire
⬜ Repurchase

A database is moved to a managed database service during migration, with minor optimization but no re-architecture. Which strategy is this?

⬜ Rehost
⬜ Refactor
⬜ Retain
⬜ Replatform (lift, tinker and shift)

An application is rewritten to use cloud-native services for agility and scale. Which migration strategy is this?

⬜ Rehost
⬜ Relocate
⬜ Replatform
⬜ Refactor (re-architect)

The new version runs beside the old one, is smoke-tested in production, then all traffic switches at once with instant rollback by switching back. Which strategy is this?

⬜ Blue-green deployment
⬜ Canary deployment
⬜ Rolling update
⬜ Feature flagging

A release goes to a small percentage of users first, and traffic increases gradually while metrics are watched. Which strategy is this?

⬜ Blue-green deployment
⬜ Big-bang deployment
⬜ Canary deployment
⬜ Recreate deployment

A stateful app’s database tier is moving to Kubernetes. Which approach fits the database?

⬜ A Deployment relying on its ReplicaSet for persistence
⬜ A StatefulSet with stable network identities and PersistentVolumeClaims
⬜ A DaemonSet on every node
⬜ Database files baked into the image

By default, how does a Kubernetes Deployment roll out a new pod template?

⬜ Recreate, stopping all old pods first
⬜ A rolling update, replacing pods gradually
⬜ Blue-green with two Services
⬜ Canary with a traffic split

A log-collection agent must run exactly one pod on every node, including nodes added later. Which Kubernetes object fits?

⬜ A DaemonSet
⬜ A StatefulSet
⬜ A Job
⬜ A Deployment with replicas set to the node count

An application needs non-confidential settings such as a feature URL injected without rebuilding its image. What should be used?

⬜ A Secret
⬜ A PersistentVolume
⬜ A DaemonSet
⬜ A ConfigMap

What is true of Kubernetes Secrets by default?

⬜ They are always encrypted with a hardware module
⬜ They can’t be read by anyone with API access
⬜ They are stored unencrypted in etcd unless encryption at rest is configured, and their values are only base64-encoded
⬜ They are automatically rotated every day

An enterprise wants to use its existing perpetual database licenses on cloud VMs. What is this model, and what must be checked?

⬜ License-included pricing; check the hourly surcharge
⬜ Open-source relicensing
⬜ Bring your own license (BYOL); check the vendor’s terms allow cloud use and how virtual cores are counted
⬜ Automatic seat transfer

Domain 3: Security (19%)

Developers must get database credentials at run time without storing them in code, images or committed environment files. What fits best?

⬜ Retrieve short-lived secrets from a managed secrets manager using the workload’s identity
⬜ An encrypted file in the image with a shared passphrase
⬜ Pushing credentials with configuration management
⬜ A private Git repository

Audit logs in object storage must not be altered or deleted by anyone, including administrators, for seven years. Which control does this?

⬜ Server-side encryption
⬜ Bucket versioning alone
⬜ A lifecycle rule to cold storage
⬜ Object Lock in compliance mode with a seven-year retention period

A regulator requires cardholder data and analytics workloads on segregated networks with controlled egress. Which design fits?

⬜ One flat VPC with host firewalls
⬜ Separate VPCs (or accounts/projects) per trust zone, connected through a hub with explicit egress controls
⬜ A PCI tag on resources
⬜ Serverless with no network controls

A security group allows inbound HTTPS to an instance. What happens to the response traffic?

⬜ It needs an explicit outbound rule
⬜ It is always dropped
⬜ It needs a NACL rule only
⬜ It is allowed automatically, because security groups are stateful

A network ACL allows inbound HTTPS to a subnet, but responses don’t get back to clients. Why?

⬜ NACLs block all outbound traffic by default in every case
⬜ The security group is stateless
⬜ Network ACLs are stateless, so return traffic (ephemeral ports) must be allowed explicitly
⬜ HTTPS isn’t supported by NACLs

In what order are network ACL rules evaluated?

⬜ From the lowest rule number upward; the first match decides
⬜ From the highest number downward
⬜ All rules are combined and the most permissive wins
⬜ Deny rules are always checked first

A company wants control over its encryption key’s policy and rotation, while still using the provider’s managed key service. Which key type fits?

⬜ A provider-owned key
⬜ A customer managed key in the provider’s key management service
⬜ A hardcoded key in the application
⬜ No encryption

Large data is encrypted with a data key, and that data key is itself encrypted with a master key held in a key service. What is this technique?

⬜ Envelope encryption
⬜ Hashing
⬜ Tokenization
⬜ Steganography

Applications on cloud VMs need access to storage. What is the recommended way to give them credentials?

⬜ Long-term access keys embedded in code
⬜ The root account’s keys
⬜ Use roles that provide temporary credentials, granting least privilege
⬜ A shared admin user

What should be required for privileged cloud console users, according to provider IAM best practices?

⬜ Password-only sign-in
⬜ Multi-factor authentication
⬜ Shared accounts
⬜ Disabling logging

A team wants continuous checks that flag misconfigurations such as public buckets and open security groups across cloud accounts. Which tool category fits?

⬜ A host IDS
⬜ A password manager
⬜ A CDN
⬜ Cloud security posture management (CSPM)

Domain 4: Operations (17%)

A web tier’s CPU hits 100% every weekday at 09:00. What is the best first response?

⬜ Manually resize the instances every Monday
⬜ Scheduled or predictive scaling that adds capacity before 09:00
⬜ Lengthen the scaling cooldown
⬜ Disable health checks

Workloads run 24x7 for at least a year. Which purchasing option cuts steady-state compute cost without architecture changes?

⬜ Reserved instances or a one-year savings-plan commitment
⬜ Spot instances
⬜ On-demand
⬜ Dedicated hosts

Finance can’t tell which departments drive the bill, and untagged resources keep appearing. What establishes reliable cost allocation?

⬜ One account for all teams
⬜ Manual spreadsheet allocation
⬜ A tagging standard (cost center, owner, environment) enforced by policy and activated for cost allocation
⬜ Reserved instances everywhere

Nightly full backups no longer fit the backup window, and restores must stay simple. Which approach fits?

⬜ Weekly full plus daily incrementals with long restore chains
⬜ Hourly snapshots and no application backups
⬜ Harder compression of the nightly full
⬜ Weekly full backups plus daily differentials

VMs average 6% CPU and 20% memory with no spikes. Which action does this support?

⬜ Scaling out further
⬜ Right-sizing to smaller instance types
⬜ Moving to dedicated hosts
⬜ Buying a 3-year reservation at the current size

A batch job can restart from checkpoints and tolerate interruptions. Which pricing model minimizes its cost?

⬜ On-demand instances
⬜ Dedicated hosts
⬜ Spot instances
⬜ Reserved instances for a short job

An auto-scaling group should keep average CPU near 50%, adding or removing instances as load changes. Which policy type fits?

⬜ Target tracking scaling
⬜ Scheduled scaling
⬜ Manual scaling
⬜ Simple step scaling with fixed times

Logs must stay in standard storage for 30 days and then move to a cheaper archive tier automatically. What should be configured?

⬜ Object Lock
⬜ Versioning
⬜ A CDN
⬜ An object lifecycle rule that transitions objects after 30 days

Which three telemetry signals together form the basis of observability for cloud applications?

⬜ Tickets, emails and chats
⬜ Backups, snapshots and replicas
⬜ CPU, RAM and disk only
⬜ Metrics, logs and traces

Which statement describes FinOps?

⬜ A tool that automatically halves cloud bills
⬜ An operational practice where engineering, finance and business share accountability for cloud spend to maximize value
⬜ A finance-only budgeting process
⬜ A security framework

Domain 5: Troubleshooting (12%)

An app is reachable from one virtual network but not from a third network reached through a peered one. Routes and security groups look correct. What should be checked?

⬜ Reissue the TLS certificate
⬜ Raise the MTU
⬜ Peering is non-transitive, so the third network needs its own direct peering
⬜ Disable source/destination checks

After a deployment, a microservice’s P95 latency tripled, while errors and CPU are normal. With distributed tracing in place, where should the team look first?

⬜ The trace spans for the slowest downstream call
⬜ Restart every pod
⬜ Turn off tracing
⬜ Fail over the region

A batch job gets intermittent HTTP 429 responses from a SaaS API at peak. What is the right client behavior?

⬜ Fail the batch
⬜ Send requests faster
⬜ Honor Retry-After and retry with exponential backoff and jitter
⬜ Switch to raw sockets

An Application Load Balancer returns HTTP 503 for every request. What is a likely cause?

⬜ The target group has no registered targets, or none in a usable state
⬜ The client sent malformed headers
⬜ The certificate expired on the client
⬜ The DNS TTL is too long

An Application Load Balancer returns HTTP 504 intermittently after a NACL change on the target subnet. What is a likely cause?

⬜ The certificate is wrong
⬜ The NACL doesn’t allow traffic from the targets back to the load balancer on ephemeral ports
⬜ The targets returned 404
⬜ Too many requests from clients

A new pod stays Pending and never starts. What is a common cause?

⬜ The image name is wrong
⬜ The container crashes after starting
⬜ The Service selector is wrong
⬜ Not enough CPU or memory on any node to schedule it

A pod is scheduled but shows ImagePullBackOff. What should be checked first?

⬜ The image name and tag, and the registry credentials
⬜ Node CPU capacity
⬜ The Service type
⬜ The PersistentVolumeClaim size

After moving a site to a new IP and updating DNS, some users still reach the old server for hours. Why?

⬜ The new server is down
⬜ Resolvers keep cached answers until the record’s TTL expires
⬜ The certificate changed
⬜ Peering isn’t transitive

Domain 6: DevOps Fundamentals (10%)

Every production environment must be built identically, versioned in Git and reproducible for blue/green releases. Which practice fits?

⬜ Manual builds from a runbook
⬜ Ad hoc SSH scripts
⬜ Declarative infrastructure as code applied through a CI/CD pipeline
⬜ Hand-cloned golden images

What does continuous integration mean?

⬜ Code is released to production on every commit
⬜ Builds happen once a quarter
⬜ Testing is done manually before release
⬜ Developers merge code changes into a shared repository frequently, and each change is built and tested automatically

What is the difference between continuous delivery and continuous deployment?

⬜ They are identical
⬜ Continuous delivery has no automated tests
⬜ Continuous deployment requires manual approval
⬜ Continuous delivery keeps every change ready for release with a manual approval to production; continuous deployment releases automatically

In GitOps, how is the running system kept in line with the desired configuration?

⬜ Administrators SSH in to apply changes
⬜ Changes are made in the console and then documented
⬜ Desired state is declared and versioned in Git, and software agents continuously reconcile the system to it
⬜ A nightly script overwrites Git from production

Before applying Terraform changes, a team wants to preview exactly what will be created, changed or destroyed. Which command does this?

⬜ terraform plan
⬜ terraform apply -auto-approve
⬜ terraform destroy
⬜ terraform fmt

A team never patches running servers; instead it builds a new image and replaces the servers. What is this approach?

⬜ Mutable infrastructure
⬜ Immutable infrastructure
⬜ Configuration drift
⬜ Snowflake servers
