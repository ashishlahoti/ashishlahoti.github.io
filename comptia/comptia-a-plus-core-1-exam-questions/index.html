Overview

  1. CompTIA A+ (V15, launched March 25, 2025) is the entry-level IT support certification. You need to pass two exams, Core 1 (220-1201) and Core 2 (220-1202), to earn it.
  2. Core 1 has a maximum of 90 questions (multiple choice and performance-based) in 90 minutes.
  3. The passing score is 675 on a 100–900 scale; this practice test uses 75% as the target.
  4. The five domains are weighted 13%, 23%, 25%, 11% and 28%, so this test has 90 questions split 12 / 21 / 22 / 10 / 25.
  5. Topics include laptop and mobile hardware, ports and protocols, Wi-Fi, SOHO networking, cables, RAM, storage and RAID, motherboards and power supplies, printers, virtualization, cloud models, and hardware and network troubleshooting.
  6. CompTIA A+ Core 1 and Core 2 (V15) page for exam objectives and more details.

Domain 1: Mobile Devices (13%)

A technician is upgrading the memory in a thin laptop. Which memory module form factor will the laptop most likely use?

⬜ DIMM
⬜ ECC registered DIMM
⬜ SODIMM
⬜ SIMM

A user wants to unlock a company laptop by touching a sensor instead of typing a password. Which component should the technician check or replace if this stops working?

⬜ The NFC antenna
⬜ The Wi-Fi antenna
⬜ The digitizer
⬜ The fingerprint reader (biometric sensor)

A laptop’s internal wireless card has failed. The replacement card plugs into a small slot on the motherboard and is held with one screw. Which form factor is the card most likely?

⬜ M.2
⬜ mSATA
⬜ SODIMM
⬜ PCIe x16

A user with an older laptop wants faster boot and application load times. The laptop has a 2.5-inch SATA hard drive. What’s the most effective upgrade?

⬜ Replace the hard drive with a 3.5-inch 7,200 RPM drive
⬜ Replace the hard drive with a 2.5-inch SATA SSD
⬜ Add a faster Wi-Fi card
⬜ Replace the battery with a higher-capacity one

A user wants to connect a laptop to two monitors, a wired network, a keyboard and a mouse at their desk using one connection, and also charge the laptop. Which accessory fits best?

⬜ A docking station
⬜ A Bluetooth headset
⬜ A stylus
⬜ A USB flash drive

Which connector type is reversible and can carry data, video and power to a laptop over one cable?

⬜ Micro-USB
⬜ Mini-USB
⬜ USB-C
⬜ DB9

A shop wants customers to pay by holding their phones within a few centimeters of the card reader. Which technology is used?

⬜ Bluetooth
⬜ Infrared
⬜ Wi-Fi Direct
⬜ NFC

A salesperson’s laptop has no internet access at a client site, but their smartphone has a strong 5G signal. What’s the quickest way to get the laptop online?

⬜ Pair the laptop’s keyboard with the phone
⬜ Turn on the phone’s hotspot (tethering) and connect the laptop to it
⬜ Install a second Wi-Fi card in the laptop
⬜ Enable airplane mode on the phone

A user’s new phone has no physical SIM tray. How is the carrier’s subscription added to the device?

⬜ By inserting a microSD card
⬜ By pairing it with a Bluetooth headset
⬜ By downloading an eSIM profile from the carrier
⬜ By enabling NFC

A user can’t connect a new Bluetooth headset to a phone. Bluetooth is turned on. What should the technician do next?

⬜ Turn on the phone’s hotspot
⬜ Reset the phone to factory settings
⬜ Disable Wi-Fi on the phone
⬜ Put the headset into pairing (discoverable) mode, select it on the phone, and enter the PIN if prompted

Employees use their own phones for work email. The company wants to remotely wipe only company data if a phone is lost. What should it use?

⬜ A full factory reset policy for all personal data
⬜ Mobile device management (MDM) with a separate corporate profile or container
⬜ A shared Wi-Fi password
⬜ Bluetooth pairing restrictions only

A user’s phone navigation app can’t find their location, even though cellular data works. What setting should the technician check first?

⬜ Location services (GPS) are enabled and the app has permission to use them
⬜ Bluetooth tethering is turned on
⬜ NFC is turned on
⬜ Screen rotation is unlocked

⬜ The PC couldn’t reach a DHCP server and assigned itself an APIPA address
⬜ The PC has a static address in a private range

⬜ 172.20.10.5

Domain 4: Virtualization and Cloud Computing (11%)

Which type of hypervisor runs directly on the host’s hardware, without a general-purpose operating system underneath?

⬜ Type 2 (hosted)
⬜ A container engine
⬜ A VDI client
⬜ Type 1 (bare-metal)

A developer installs a Type 2 hypervisor on a Windows laptop, but 64-bit virtual machines won’t start. What should the technician check in the firmware settings?

⬜ Secure Boot is disabled
⬜ The boot order lists USB first
⬜ Hardware virtualization support (Intel VT-x or AMD-V) is enabled
⬜ Wake-on-LAN is enabled

What’s a key difference between containers and virtual machines?

⬜ Containers each need their own hypervisor
⬜ Containers share the host operating system kernel, while each VM runs its own guest OS
⬜ VMs share the host kernel, while containers have full guest operating systems
⬜ Containers can run only on physical hardware

A security analyst wants to open a suspicious attachment safely without risking the corporate network. What’s the best use of virtualization here?

⬜ Open it on the domain controller
⬜ Open it on their main workstation with antivirus disabled
⬜ Email it to colleagues for review
⬜ Open it in an isolated virtual machine used as a sandbox

A company wants users to reach a standard Windows desktop that runs in the data center from any thin client. What is this called?

⬜ Virtual desktop infrastructure (VDI)
⬜ Software as a service
⬜ A Type 2 hypervisor on each thin client
⬜ Dual booting

A company uses a web-based email and office suite. The provider manages the application, servers and storage, and users just sign in. Which cloud service model is this?

⬜ Infrastructure as a service (IaaS)
⬜ Software as a service (SaaS)
⬜ Platform as a service (PaaS)
⬜ On-premises hosting

Developers want to deploy their own web application code without managing servers, operating systems or storage. Which cloud service model fits?

⬜ Platform as a service (PaaS)
⬜ Infrastructure as a service (IaaS)
⬜ Software as a service (SaaS)
⬜ Desktop as a service

A company keeps sensitive databases in its own data center but runs its public website on a cloud provider, with the two connected. Which deployment model is this?

⬜ Community cloud
⬜ Public cloud only
⬜ Hybrid cloud
⬜ Private cloud only

An online store’s cloud resources grow automatically during a holiday sale and shrink afterward. Which cloud characteristic is this?

⬜ Measured service
⬜ Broad network access
⬜ Community deployment
⬜ Rapid elasticity

A cloud bill charges separately for storage used and data transferred out of the provider’s network. Which cloud characteristic does this reflect?

⬜ Measured service (metered utilization)
⬜ Rapid elasticity
⬜ Resource pooling
⬜ On-demand self-service

Domain 5: Hardware and Network Troubleshooting (28%)

A PC powers on, shows nothing on screen and gives a series of beeps. What do the beeps represent?

⬜ A normal startup sound
⬜ An operating system error message
⬜ A network cable fault
⬜ A POST error code that identifies the failing component, which the technician can look up for that firmware

An office PC keeps showing the wrong date and time after it’s unplugged overnight, and its BIOS settings reset. What’s the most likely cause?

⬜ A failing power supply
⬜ A corrupted operating system
⬜ A failing CMOS (RTC) battery
⬜ A loose SATA cable

A technician opens an unstable PC that randomly reboots and sees capacitors near the CPU with bulging or leaking tops. What should they do?

⬜ Replace the motherboard, because failing capacitors cause instability
⬜ Apply new thermal paste
⬜ Update the BIOS
⬜ Reinstall the operating system

A three-year-old PC shuts down after running heavy workloads for a while. The fans spin, and the CPU temperature in UEFI is very high. What should the technician check first?

⬜ Replace the RAM
⬜ Replace the hard drive
⬜ Change the boot order
⬜ Clean dust from the heat sink and fans, and replace the old thermal paste between the CPU and heat sink

After a powerful new graphics card is installed, a PC reboots whenever a game starts. It’s stable at the desktop. What’s the most likely cause?

⬜ The monitor’s refresh rate is too high
⬜ The power supply doesn’t have enough wattage for the new card under load
⬜ The CMOS battery is failing
⬜ The network driver is outdated

A user’s desktop hard drive is making repeated clicking sounds and files are taking a long time to open. What should the technician do first?

⬜ Run a disk defragmenter for several hours
⬜ Ignore it because clicking is normal
⬜ Back up the user’s data immediately, then replace the drive
⬜ Update the graphics driver

A monitoring tool warns that a laptop drive’s S.M.A.R.T. attributes show a growing number of reallocated sectors. What does this mean?

⬜ The drive may be failing, so data should be backed up and the drive replaced soon
⬜ The drive is new and calibrating
⬜ The drive needs a firmware password
⬜ The operating system needs reinstalling

A RAID 5 array’s controller reports a degraded state after one drive fails. The server still runs. What should the technician do?

⬜ Delete and recreate the array
⬜ Remove another drive to test the controller
⬜ Replace the failed drive so the array can rebuild, and confirm backups are current
⬜ Ignore it because RAID 5 has redundancy

After a new hard drive is added, a PC shows “No bootable device found” at startup. The original Windows drive is still installed. What should the technician check first?

⬜ The monitor’s input source
⬜ The network cable
⬜ The printer driver
⬜ The UEFI boot order, to make sure the Windows drive’s boot entry comes first

A conference room projector shows “No signal” while a laptop is connected by HDMI and the laptop is mirroring its display. What should the technician check first?

⬜ The projector’s bulb
⬜ That the projector is set to the correct input source
⬜ The laptop’s battery
⬜ The Wi-Fi password

A digital sign with an OLED panel shows a faint image of a logo even when other content is displayed. What’s the cause?

⬜ A wrong input source
⬜ Dead pixels
⬜ A loose power cable
⬜ Burn-in from showing the same static image for long periods

A user replaced their LCD monitor and the text looks fuzzy. What should the technician check?

⬜ That the monitor is plugged into a surge protector
⬜ That the CMOS battery is new
⬜ That the computer’s display resolution matches the monitor’s native resolution
⬜ That the keyboard driver is updated

A laptop’s screen is very dim, but the image is barely visible when a flashlight shines on it. Which component is most likely failing?

⬜ The backlight (or its inverter on CCFL displays)
⬜ The digitizer
⬜ The graphics driver
⬜ The hard drive

A user’s smartphone case is bulging and the screen is lifting from the frame. What should the technician advise?

⬜ Keep charging it overnight to calibrate the battery
⬜ Stop using and charging the phone and have the swollen battery replaced and disposed of safely
⬜ Press the screen back into place
⬜ Put it in a freezer to cool the battery

A tablet’s display shows images correctly, but touches in one area don’t register after it was dropped. Which component should be replaced?

⬜ The backlight
⬜ The battery
⬜ The Wi-Fi card
⬜ The digitizer (touch layer)

A phone charges very slowly from an old 5 W USB-A charger. What’s the best fix?

⬜ Turn on NFC while charging
⬜ Use a USB-C charger and cable that support USB Power Delivery at a higher wattage the phone accepts
⬜ Replace the SIM card
⬜ Enable developer mode

Remote workers’ VoIP calls sound choppy when large file uploads run on the same office internet connection. What should the administrator configure?

⬜ A longer DHCP lease
⬜ A new SSID
⬜ Quality of service (QoS) on the router to prioritize voice traffic
⬜ Port forwarding for file uploads

Users near the break room lose 2.4 GHz Wi-Fi connectivity whenever the microwave oven runs. What’s the best fix?

⬜ Move those users to the 5 GHz band or move the access point away from the microwave
⬜ Change the SSID
⬜ Increase the DHCP scope
⬜ Replace the users’ network cables

Laptop users in one office report slow, intermittent Wi-Fi. A Wi-Fi analyzer shows several neighboring networks on the same 2.4 GHz channel as the office access point. What should the technician do?

⬜ Turn off SSID broadcast
⬜ Shorten the DHCP lease time
⬜ Move the access point to the least-used of the non-overlapping channels 1, 6 and 11
⬜ Replace the laptops’ Ethernet cables

Users can ping a web server by its IP address but can’t open the site by name. Which service is most likely failing?

⬜ DHCP
⬜ NTP
⬜ SMTP
⬜ DNS

A technician suspects a desktop’s built-in Ethernet port has failed. Which tool can test the port without connecting to the network?

⬜ A loopback plug
⬜ A toner probe
⬜ A punchdown tool
⬜ A crimper

A factory’s Ethernet connections drop intermittently. The unshielded cables run next to large motors. What should the technician recommend?

⬜ Changing the Wi-Fi channel
⬜ Rerouting the cables or replacing them with shielded twisted pair (STP)
⬜ Assigning static IP addresses
⬜ Upgrading the switch firmware

Pages from a laser printer come out with toner that smudges or rubs off when touched. Which component is most likely failing?

⬜ The pickup roller
⬜ The toner cartridge chip
⬜ The fuser
⬜ The network card

A laser printer’s pages show a fainter repeat of the image farther down the page. Which part of the imaging process is the likely cause?

⬜ The paper tray is set to the wrong size
⬜ The charge roller or drum isn’t being fully reset between revolutions
⬜ The print queue is stuck
⬜ The printer has an incorrect IP address

Several users can’t print because a corrupted job is stuck at the top of the Windows print queue. What should the technician do?

⬜ Replace the printer’s toner
⬜ Reinstall Windows on the print server
