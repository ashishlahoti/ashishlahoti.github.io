Free CompTIA A+ Core 2 (220-1202) Online Practice Exam

Overview

  1. CompTIA A+ (V15, launched March 25, 2025) is the entry-level IT support certification. You need to pass two exams, Core 1 (220-1201) and Core 2 (220-1202), to earn it.
  2. Core 2 has a maximum of 90 questions (multiple choice and performance-based) in 90 minutes.
  3. The passing score is 700 on a 100–900 scale; this practice test uses 78% as the target.
  4. The four domains are weighted 28%, 28%, 23% and 21%, so this test has 90 questions split 25 / 25 / 21 / 19.
  5. Topics include Windows editions, tools, commands and settings, macOS and Linux, security controls, malware and social engineering, the malware removal procedure, data destruction, Windows and mobile troubleshooting, documentation, change management, backups, safety, licensing and incident response, scripting, remote access and AI basics.
  6. CompTIA A+ Core 1 and Core 2 (V15) page for exam objectives and more details.

Domain 1: Operating Systems (28%)

A user needs a USB drive that can store files larger than 4 GB and be read and written on both Windows and macOS without extra software. Which file system should the drive use?

⬜ exFAT
⬜ FAT32
⬜ ext4
⬜ APFS

A company still runs an operating system version that has reached its vendor’s end of life. What’s the main risk?

⬜ It stops booting on the end-of-life date
⬜ Its license key becomes invalid immediately
⬜ It can no longer connect to Wi-Fi
⬜ It no longer receives security updates, so new vulnerabilities stay unpatched

A technician is installing Windows on a new 4 TB drive and wants to use all of its space for one partition. Which partition style should be used?

⬜ MBR
⬜ GPT
⬜ FAT32
⬜ Extended partition on MBR

An IT team wants to install Windows on 50 new PCs over the network without using USB drives. Which boot method should the PCs use?

⬜ Booting from an internal recovery partition
⬜ Booting from an optical drive
⬜ PXE (network boot)
⬜ Booting into Safe Mode

A user’s Windows PC is very slow and full of unwanted software. They have a backup and want a fresh system with nothing kept from the old installation. Which installation type fits?

⬜ An in-place upgrade
⬜ A repair installation that keeps apps
⬜ A clean install
⬜ Restoring the same system image taken last week

A small business wants to join its PCs to an Active Directory domain. The new laptops came with Windows 11 Home. What should the technician do?

⬜ Join the domain from the Settings app in Home
⬜ Install the Remote Server Administration Tools on Home
⬜ Create a workgroup with the same name as the domain
⬜ Upgrade the laptops to Windows 11 Pro, which supports joining a domain

An organization requires BitLocker on all laptops. Which Windows editions support BitLocker?

⬜ Pro, Enterprise and Education
⬜ Home only
⬜ Home and Pro only
⬜ All editions, including Home, with full BitLocker management

A PC with an older CPU, 8 GB of RAM and no TPM fails the Windows 11 upgrade check. Which requirement is it missing?

⬜ At least 32 GB of RAM
⬜ TPM 2.0 (Windows 11 also needs UEFI with Secure Boot capability)
⬜ A dedicated graphics card with 8 GB of VRAM
⬜ An NVMe SSD

A PC takes several minutes to become usable after sign-in. Which tool lets the technician quickly see and disable applications that start automatically?

⬜ The Startup apps tab in Task Manager
⬜ Disk Cleanup
⬜ Device Manager
⬜ Disk Management

A server rebooted unexpectedly overnight. Where should the technician look to find out what happened before the restart?

⬜ Disk Management
⬜ Task Scheduler’s history only
⬜ Certificate Manager
⬜ Event Viewer’s System log

After a graphics driver update, a PC’s display flickers. Which tool should the technician use to remove the faulty driver and install the previous version?

⬜ Event Viewer
⬜ Device Manager
⬜ Local Users and Groups
⬜ Performance Monitor

A technician needs to track a server’s CPU, memory and disk counters over several days to find a performance pattern. Which tool fits?

⬜ Task Manager
⬜ System Information (msinfo32)
⬜ Performance Monitor
⬜ Disk Cleanup

Windows system files may be corrupted after a failed update. Which command checks and repairs protected system files?

⬜ chkdsk /f
⬜ sfc /scannow
⬜ gpupdate /force
⬜ diskpart

An administrator changed a Group Policy setting and wants a user’s PC to apply it now instead of waiting. Which command should be run on the PC?

⬜ gpresult /r
⬜ ipconfig /renew
⬜ sfc /scannow
⬜ gpupdate /force

A technician must copy a large folder tree to a new file server, keeping file attributes and timestamps, and resume if the network drops. Which command fits best?

⬜ copy
⬜ md
⬜ robocopy
⬜ rmdir

Users can reach websites by IP address but not by name. Which command helps check what a DNS server returns for a name?

⬜ nslookup
⬜ netstat
⬜ hostname
⬜ whoami

A user wants the finance shared folder on server FS01 to appear as drive F: on their PC, using the command line. Which command should they use?

⬜ net use
⬜ net user
⬜ ipconfig
⬜ tracert

Laptop users complain that a full shutdown doesn’t seem to clear problems, but a restart does. Which Windows power setting explains this?

⬜ USB selective suspend
⬜ The lid close action
⬜ Fast startup, which hibernates the computer at shutdown instead of fully shutting it down
⬜ Sleep after 15 minutes

A Mac user wants the entire startup disk encrypted so data is protected if the laptop is stolen. Which macOS feature should be turned on?

⬜ Keychain
⬜ FileVault
⬜ Spotlight
⬜ Mission Control

Where does macOS store a user’s saved website and Wi-Fi passwords?

⬜ FileVault
⬜ Time Machine
⬜ Finder
⬜ Keychain

A Linux script file needs execute permission for its owner. Which command should the administrator run?

⬜ chmod u+x script.sh
⬜ chown u+x script.sh
⬜ grep x script.sh
⬜ df -h script.sh

A Linux user needs to install a package that requires administrator rights, without signing in as root. What should they use?

⬜ chmod 777 on the package
⬜ su with no password
⬜ ps -ef
⬜ sudo, for example sudo apt install followed by the package name

An administrator wants to find every line containing “error” in /var/log/syslog. Which command should they use?

⬜ find error /var/log/syslog
⬜ mv error /var/log/syslog
⬜ grep error /var/log/syslog
⬜ du error /var/log/syslog

A company is moving from 32-bit to 64-bit Windows. Will its older 32-bit accounting application most likely still run?

⬜ No, 32-bit applications never run on a 64-bit OS
⬜ Yes, most 32-bit applications run on a 64-bit OS in a compatibility mode
⬜ Only if the PC has less than 4 GB of RAM
⬜ Only after the app is recompiled by the user

A new employee can sign in to the company’s cloud productivity suite but can’t open the desktop email and office apps. What should the administrator check first?

⬜ That the user’s monitor resolution is correct
⬜ That the PC has a TPM
⬜ That the user has been assigned a license that includes those apps
⬜ That the user’s mailbox is set to read-only

Domain 2: Security (28%)

A data center wants to stop unauthorized people from following an employee through a secure door. Which physical control fits best?

⬜ A motion-activated light
⬜ A security camera only
⬜ A bollard
⬜ An access control vestibule (mantrap)

A help desk technician has full domain administrator rights but only needs to reset passwords. Which principle does this violate?

⬜ Least privilege
⬜ Separation of duties
⬜ Defense in depth
⬜ Zero-day mitigation

A company’s VPN asks for a password and then a code from an authenticator app on the user’s phone. What is this?

⬜ Single sign-on
⬜ Multifactor authentication: something you know and something you have
⬜ Two passwords (single factor)
⬜ Biometric authentication only

A folder is shared with Everyone: Full Control, but its NTFS permissions give the Sales group Read only. What access does a Sales user have when connecting over the network?

⬜ Full Control, because share permissions override NTFS
⬜ Read, because the more restrictive of the share and NTFS permissions applies
⬜ Modify, because the two are added together
⬜ No access, because the permissions conflict

A user is signed in as a standard user and tries to install software. Windows asks for administrator credentials. Which feature is doing this?

⬜ Windows Defender Firewall
⬜ BitLocker
⬜ Encrypting File System
⬜ User Account Control (UAC)

Employees carry sensitive files on USB flash drives. Which feature encrypts the removable drives?

⬜ BitLocker To Go
⬜ Encrypting File System on the local disk
⬜ Windows Hello
⬜ Windows Defender SmartScreen

A company is buying new access points and wants the strongest current Wi-Fi security for staff with a shared passphrase. Which should it choose?

⬜ WPA2 with TKIP
⬜ WEP
⬜ WPA3-Personal with SAE
⬜ Open network with MAC filtering

An enterprise wants each employee to sign in to Wi-Fi with their own directory credentials, checked by a central server. Which should it deploy?

⬜ WPA2-Personal with one shared passphrase
⬜ WPS PIN authentication
⬜ A hidden SSID
⬜ WPA2/WPA3-Enterprise with a RADIUS server

A user’s files suddenly have unfamiliar extensions and a message demands cryptocurrency to unlock them. Which type of malware is this?

⬜ Ransomware
⬜ Spyware
⬜ Adware
⬜ Keylogger

Antivirus scans in Windows find nothing, but network monitoring shows the PC sending data to an unknown server. The technician suspects malware that hides itself at a deep level of the OS. What is it most likely?

⬜ Adware
⬜ A potentially unwanted program toolbar
⬜ A rootkit
⬜ A cryptominer only

A user’s online banking password was stolen even though it was never written down or reused. Which malware most likely captured it?

⬜ A boot sector virus
⬜ A keylogger
⬜ Adware
⬜ A cryptominer

The CFO receives a convincing email, apparently from the CEO, asking for an urgent wire transfer. Which attack is this?

⬜ Vishing
⬜ Smishing
⬜ Shoulder surfing
⬜ Whaling

⬜ Brute-force attack

⬜ Evil twin
⬜ Dumpster diving

⬜ Disable System Restore in Windows Home

What’s the first step in CompTIA’s malware removal procedure?

⬜ Quarantine the infected system
⬜ Reimage the PC
⬜ Investigate and verify malware symptoms
⬜ Update the anti-malware software

⬜ Enable the guest account
⬜ Turn off screen locks
⬜ Allow administrator rights for all users
⬜ Disable AutoRun/AutoPlay

⬜ Password hints
⬜ Account lockout after a set number of failed sign-in attempts

⬜ Disabling screen savers

A company phone with sensitive email is lost on a train. What should the administrator do through MDM?

⬜ Remotely lock the device and wipe its data
⬜ Turn off the user’s email account permanently

⬜ Change the Wi-Fi password in the office

⬜ Degaussing leaves all data readable
⬜ Degaussing works only on SSDs
⬜ Degaussing destroys the drives’ servo data, making the drives unusable

⬜ A certificate of destruction
⬜ A EULA
⬜ An SLA

A technician sets up a new SOHO wireless router. Which change should be made first to secure it?

⬜ Enable WPS for easy pairing
⬜ Turn on UPnP for every device
⬜ Leave the firmware at the factory version
⬜ Change the default administrator username and password

A user downloads an installer from a vendor’s site and wants to make sure it wasn’t altered. What should they do?

⬜ Check the file’s size only
⬜ Compare the file’s hash with the hash published by the vendor
⬜ Rename the file

Domain 3: Software Troubleshooting (23%)

After a new network driver is installed, Windows shows a blue screen every time it starts. What should the technician do?

⬜ Replace the motherboard
⬜ Start Windows in Safe Mode, which loads a minimal set of drivers, and remove or replace the new driver
⬜ Reinstall Windows immediately
⬜ Run gpupdate /force

A PC became unstable right after a utility was installed yesterday. The user’s documents must be kept. Which tool can undo the system changes?

⬜ A full factory reset
⬜ Disk Cleanup
⬜ Formatting the system drive
⬜ System Restore, to roll back to a restore point from before the install

Domain users get sign-in errors on one PC, and its clock is several minutes off from the domain controller. Which command resynchronizes the clock?

⬜ ipconfig /flushdns
⬜ chkdsk /r
⬜ w32tm /resync
⬜ netstat -an

Users with roaming profiles say sign-in takes several minutes on any PC. Profiles include large media files saved to the desktop. What’s the cause?

⬜ The large profiles must be copied over the network at each sign-in
⬜ The PCs’ monitors are set to a low refresh rate
⬜ The users’ passwords are too complex
⬜ The DHCP lease is too long

A PC slows down over the day until apps crash with low-memory warnings, and a restart fixes it. What should the technician check first?

⬜ Disk Management, to extend the system partition
⬜ Device Manager, to update the keyboard driver
⬜ Event Viewer’s Setup log only
⬜ Task Manager, to find a process whose memory use keeps growing

A smartphone app freezes on its splash screen after an update. Other apps work. What should the technician try first?

⬜ Factory reset the phone
⬜ Force stop the app, clear its cache, and check for another app update
⬜ Replace the battery
⬜ Remove the SIM card

A user says their phone’s battery now drains by midday, although it used to last all day. What should the technician check first?

⬜ The phone’s IMEI number
⬜ The battery usage screen, to find an app using unusual power in the background
⬜ The screen protector
⬜ The ringtone volume

A tablet’s screen no longer rotates when the user turns it sideways. What should be checked first?

⬜ Whether Bluetooth is enabled
⬜ Whether the device is encrypted

⬜ Whether rotation lock is turned on

A user’s phone no longer connects to their car’s Bluetooth after an OS update. Other Bluetooth devices work. What should the technician try?

⬜ Factory reset the phone
⬜ Turn on NFC
⬜ Enable developer mode

A user installed a game from a website link instead of the official app store, and now the phone shows constant ads. What’s the likely cause?

⬜ The phone’s screen is failing
⬜ The cellular network is congested
⬜ The app came from an untrusted source (sideloaded) and is adware or other malware
⬜ The phone needs a new SIM card

A company’s MDM blocks a phone from accessing email because it reports the device as rooted. Why is rooting a security concern?

⬜ Rooting gives apps privileged access and can bypass the OS security protections the company relies on
⬜ Rooting makes the battery drain faster
⬜ Rooting disables the camera
⬜ Rooting changes the phone number

A user’s phone data usage alert fires early in the month, and the user hasn’t changed their habits. Which issue should the technician suspect?

⬜ A cracked screen protector
⬜ A low ringtone volume
⬜ An expired Wi-Fi password at home
⬜ A malicious app sending data in the background

A pop-up on a phone says it’s infected and urges the user to install a cleaning app. What should the user do?

⬜ Install the app to remove the virus
⬜ Close the page without tapping the pop-up and don’t install the app
⬜ Enter payment details to fix it
⬜ Call the number shown in the pop-up

A developer enabled developer options and USB debugging on a company phone and left them on. Why should these be turned off?

⬜ They reduce screen brightness
⬜ They block phone calls
⬜ They make it easier to install untrusted apps and access the device, which increases security risk

Whenever a user types their bank’s address, the browser opens a look-alike site. Other PCs on the network are fine. Which file should the technician check?

⬜ The pagefile
⬜ The user’s desktop.ini
⬜ The hosts file, for entries that redirect the bank’s name to another IP address
⬜ The boot.ini file

A PC shows certificate errors on almost every HTTPS site, and its clock shows a date two years in the past. What’s the most likely cause?

⬜ The wrong system date makes valid certificates appear outside their validity period
⬜ Every website’s certificate has been revoked
⬜ The network cable is faulty
⬜ The browser’s pop-up blocker is on

⬜ A legitimate Windows Defender alert
⬜ A Windows Update notice
⬜ A certificate warning
⬜ Rogue security software (a fake antivirus alert)

⬜ Restart the PC repeatedly

⬜ A failing monitor
⬜ A low-toner printer

⬜ Increase the screen resolution

Which practice follows the 3-2-1 backup rule?

⬜ Keep the PC plugged in and powered on

⬜ Bend at the waist and lift with the back
⬜ Lift quickly with arms extended
⬜ Bend at the knees, keep the back straight and lift with the legs, getting help if it’s too heavy
⬜ Drag it across the floor by its cables

⬜ The product’s safety data sheet (SDS)
⬜ The printer’s warranty card
⬜ The acceptable use policy

⬜ A surge suppressor
⬜ A power strip
⬜ A larger power supply unit

⬜ The laptop’s warranty status

⬜ The user’s password

During an incident, which evidence should be collected first, according to the order of volatility?

⬜ Archival backup tapes
⬜ Data on the hard drive

⬜ The PCs’ screen sizes
⬜ The network speed
⬜ The color of the PCs
⬜ The software’s license terms (EULA), which define how many installations are allowed
