Overview

  1. This is a foundations-level certification from Anthropic for developers who build, integrate and ship production applications and agents on Claude: the Claude API (Messages, streaming, tool use, structured outputs, prompt caching, batches, files and skills), the Claude Agent SDK and Claude Managed Agents, Claude Code, custom tools and Model Context Protocol (MCP) servers.
  2. It suits software developers, backend and full-stack engineers and AI engineers. Hands-on experience calling the Claude API from an official SDK, handling tool use and streaming, and working with Claude Code and MCP is strongly recommended.
  3. Exam code is CCDV-F, and passing it earns the Claude Certified Developer - Foundations credential with a Credly badge. The exam is proctored through Pearson VUE and lists at US$125 (partner discounts may apply).
  4. The exam has 53 scenario-based questions (multiple choice and multiple response; each item says how many answers to choose) in 120 minutes. Many questions include a short code snippet or a JSON request or response to read.
  5. The passing score is 720 on a scaled score of 100–1,000.
  6. The exam covers 8 domains (see the weighting table below), with Applications and Integration carrying about a third of the weight. The credential is valid for 12 months. The Claude API changes often: Claude 4.6 and later reject assistant prefill, Claude Opus 4.7 and later reject non-default temperature, top_p and top_k, and Claude Opus 5.5 and Sonnet 5.5 reject forced tool use. The questions follow the current docs, so check them for the latest behavior.
  7. Anthropic announcement, Claude API documentation, Claude Code documentation and Model Context Protocol for more details.
