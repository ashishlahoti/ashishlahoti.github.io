Overview

  1. This is a foundations-level certification from Anthropic for solution architects who design and build production applications with Claude: agentic architecture and multi-agent orchestration with the Claude Agent SDK, tool design and Model Context Protocol (MCP) integration, Claude Code configuration and workflows, prompt engineering and structured output with the Claude API, and context management and reliability.
  2. It suits solution architects, senior developers and AI engineers. Hands-on experience with the Claude API (tool use, structured outputs, Message Batches), the Claude Agent SDK, Claude Code and MCP servers is strongly recommended.
  3. Exam code is CCAR-F (also written CCA-F), and passing it earns the Claude Certified Architect - Foundations credential with a Credly badge. The exam is proctored, online or at a Pearson VUE test center, and lists at US$125 (partner discounts may apply).
  4. The exam has 60 scenario-based questions (multiple choice and multiple response; each item says how many answers to choose) in 120 minutes. Each scenario describes a system, such as a multi-agent research system, a customer support agent, a structured data extraction pipeline, Claude Code in CI/CD or a developer productivity agent.
  5. The passing score is 720 on a scaled score of 100–1,000.
  6. The exam covers 5 domains (see the weighting table below). The credential is valid for 12 months and can be renewed with a free online renewal assessment. Claude’s APIs and Claude Code change often; for example, Claude Opus 5.5 and Sonnet 5.5 reject forced tool use (tool_choice “any” or “tool”), so the questions that rely on it say the model supports forced tool use. Check the docs for the latest behavior.
  7. Anthropic announcement, Credly badge, Claude Code documentation and Claude API documentation for more details.
