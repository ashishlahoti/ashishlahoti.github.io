Overview

  1. This is the professional-level architect certification from Anthropic. It validates that you can design, integrate, govern and run enterprise-scale solutions on Claude: choosing between workflows and agents, prompt and context engineering, retrieval, tool and Model Context Protocol (MCP) integration, evaluation and A/B testing, safety and compliance controls, stakeholder communication and lifecycle management, and Claude Code rollout for engineering teams.
  2. It suits solution architects, AI and ML engineers, technical consultants and engineering leads who take Claude solutions from discovery to production for customers. Several years of experience building production AI systems, and the Claude Certified Architect - Foundations (CCAR-F) knowledge, are strongly recommended.
  3. Exam code is CCAR-P, and passing it earns the Claude Certified Architect - Professional credential with a Credly badge. The exam is open to members of the Claude Partner Network (membership is free), is proctored and identity-verified through Pearson VUE (test center or online), and lists at US$175 (partner discounts may apply).
  4. The exam has 63 scenario-based questions (multiple choice and multiple response; each item says how many answers to choose, up to three) in 120 minutes. Most questions describe an enterprise scenario and ask for the best architectural decision, so read the constraints carefully.
  5. The passing score is 720 on a scaled score of 100–1,000.
  6. The exam covers 7 domains (see the weighting table below), with Integration and Solution Design carrying the most weight. The credential is valid for 12 months. Claude features change often (for example, recent models reject assistant prefill and non-default sampling parameters, and data retention differs by feature), so the questions follow the current docs; check them for the latest behavior.
  7. Anthropic announcement, Claude API documentation, Claude Code documentation and Model Context Protocol for more details.
