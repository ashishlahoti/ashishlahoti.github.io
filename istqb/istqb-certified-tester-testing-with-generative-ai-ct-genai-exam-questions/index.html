Overview

  1. CT-GenAI (Certified Tester – Testing with Generative AI) is an ISTQB® Specialist Level certification on using LLMs and generative AI across the whole test process.
  2. You need the ISTQB® Certified Tester Foundation Level (CTFL) certificate before you can take it.
  3. The exam has 40 multiple-choice questions in 60 minutes (75 minutes for candidates taking it in a non-native language).
  4. Questions are worth 46 points in total (the six K3 “apply” questions are worth 2 points each), and 30 points (65%) passes.
  5. The exam follows syllabus v1.1, and each learning objective has a set number of questions. This test follows the same split: 7 / 11 / 10 / 5 / 7 questions across the five chapters.
  6. Exams are run by ISTQB® member boards and exam providers, so the fee depends on your country.
  7. CT-GenAI page and syllabus for more details.

Domain 1: Introduction to Generative AI for Software Testing (17.5%)

Which type of AI represents knowledge with symbols and logical rules to mimic human decision-making?

⬜ Symbolic AI
⬜ Deep learning
⬜ Classical machine learning
⬜ Generative AI

A tester notices that “login”, “sign-in” and “authenticate” behave similarly when an LLM processes requirements. Which concept explains this?

⬜ Embeddings, which turn tokens into vectors where tokens with similar meanings sit close together
⬜ The context window, which merges similar words to save space
⬜ Tokenization, which assigns the same token to all words with similar meanings
⬜ Temperature, which groups similar words before inference

A test team wants an LLM to analyze very large test logs in one request. What should they know about using a model with a larger context window?

⬜ It removes non-deterministic behavior from the output
⬜ It reduces the cost of each request because the logs are processed at once
⬜ It guarantees that the analysis is correct
⬜ It can keep coherence across longer inputs, but more tokens increase computational complexity and processing time

A test manager needs help prioritizing 120 test cases with many dependencies, risk levels and resource limits. Which type of LLM fits this task best?

⬜ A foundation LLM, because it hasn’t been adapted to any specific task
⬜ An instruction-tuned LLM, because it is the only type that can follow instructions
⬜ A reasoning LLM, because it is trained for multi-step problem-solving and high-cognitive-load tasks
⬜ A small language model, because fewer parameters improve logical inference

A tester gives a multimodal LLM a defect report and a screenshot of the failing screen. What can the model help with?

⬜ Replacing the need for the tester to review the defect report
⬜ Identifying discrepancies between the expected results described in the text and the actual visual elements in the screenshot
⬜ Proving that the defect is fixed without running any tests
⬜ Converting the screenshot into executable source code for the application

Which example shows the LLM capability of test oracle generation?

⬜ Asking the LLM to propose the expected results for a set of test inputs
⬜ Asking the LLM to find ambiguities in a requirement
⬜ Asking the LLM to summarize test results and classify anomalies
⬜ Asking the LLM to convert test case descriptions into test scripts

An organization wants defect analysis to run automatically in its test framework every time a test run finishes. Which way of using GenAI fits best?

⬜ An AI chatbot that a tester opens manually after each run
⬜ A vision-language model used without any integration
⬜ A symbolic AI rule engine
⬜ An LLM-powered testing application that integrates the LLM through an API

Domain 2: Prompt Engineering for Effective Software Testing (27.5%)

A prompt says: “You are a test analyst. The app is a mobile banking app; we’re testing the transfer feature. Generate test cases for the user story below. [user story] Use only boundary value analysis.” Which of the six prompt components is missing?

⬜ Role
⬜ Input data
⬜ Output format
⬜ Constraints

In a structured prompt, which component tells the LLM how to apply the instructions to the input data, such as “exclude performance tests”?

⬜ Output format
⬜ Constraints
⬜ Role
⬜ Context

A tester isn’t sure how to write a good prompt for analyzing test reports. They ask the LLM to draft the prompt, then review and refine it together. Which technique is this?

⬜ Meta prompting
⬜ Prompt chaining
⬜ Few-shot prompting
⬜ Zero-shot prompting

Which statement about system prompts and user prompts is correct?

⬜ The system prompt stays constant through the session and sets the LLM’s overall behavior, while the user prompt changes with each interaction
⬜ The system prompt is normally typed by the chatbot user for every question
⬜ The user prompt sets the rules for the entire conversation
⬜ The LLM ignores the system prompt once a user prompt is sent

A tester must write acceptance criteria for a user story about a new registration screen. A GUI wireframe and field validation rules are available. What’s the best way to use GenAI?

⬜ Ask the LLM to write the criteria from its general knowledge of registration screens, with no inputs
⬜ Send the wireframe image alone and accept the first answer without review
⬜ Write a structured multimodal prompt that includes the user story, the wireframe image and the validation rules as input data, plus a role, instruction, constraints and output format, then review the results
⬜ Send only the title of the user story so the LLM isn’t biased by too much detail

A team writes test cases in Gherkin (Given-When-Then) in a strict house style. They want GenAI to produce new cases for many user stories in the same style. Which approach should they apply?

⬜ Zero-shot prompting with the instruction “write Gherkin”
⬜ Few-shot prompting with several examples, each showing a user story, its test conditions and the expected Gherkin test cases
⬜ Meta prompting, then accepting the generated prompt without examples
⬜ Raising the temperature so the output is more varied

A regression suite has 4,000 automated tests, but the nightly window allows only about 800. How can GenAI best help?

⬜ Analyze the code changes to find high-risk areas and target regression testing there, with the output reviewed according to risk
⬜ Skip regression testing until the window is longer
⬜ Randomly select 800 tests each night
⬜ Generate 4,000 new tests to replace the suite

Halfway through a test cycle, only 30% of planned tests have run and the payment module keeps failing. How can GenAI support test control?

⬜ Approve the release without involving stakeholders
⬜ Stop test monitoring because GenAI has replaced it
⬜ Automatically close the open defects so the progress metrics improve
⬜ Provide insights for reprioritizing the remaining tests, adjusting the schedule and reallocating resources, for the test manager to decide on

A tester must turn a complex, safety-related requirement into test conditions, and each intermediate result must be checked by a person before the next step. Which prompting technique fits best?

⬜ Zero-shot prompting
⬜ A single long prompt with all steps combined
⬜ Few-shot prompting
⬜ Prompt chaining

Which metric measures the proportion of GenAI-generated test scripts that run in the test environment without syntax or format errors?

⬜ Recall
⬜ Execution success rate
⬜ Time efficiency
⬜ Diversity

A tester writes two versions of a prompt for generating test data and compares their outputs against predefined metrics to choose the better one. Which technique is this?

⬜ A/B testing of prompts
⬜ Output analysis
⬜ Integrating user feedback
⬜ Adjusting prompt length

Domain 3: Managing Risks of Generative AI in Software Testing (25%)

Where do biases in an LLM’s output originate?

⬜ Only in the user’s prompt wording
⬜ Only in the temperature setting used at inference
⬜ In the size of the context window
⬜ In the data the model was trained on, which can make outputs favor certain information, approaches or assumptions

A user story has three acceptance criteria about password reset. The LLM’s test cases include one that checks “the account locks after five failed attempts”, which appears nowhere in the story or the specifications. What kind of error is this, and how should it be detected?

⬜ A reasoning error, detected by running the test case
⬜ A bias, detected by checking whether non-functional tests are underrepresented
⬜ A hallucination, detected by cross-verifying the output against the requirements and known system behavior
⬜ Non-deterministic behavior, fixed by setting a random seed

Which technique helps detect an LLM’s reasoning errors early during a complex test planning task?

⬜ Removing context from the prompt so the model reasons independently
⬜ Splitting the task into smaller steps with prompt chaining and verifying each output before moving on
⬜ Using an ambiguous data format so the model must think harder
⬜ Asking for the full plan in one prompt to keep context together

Which actions help reduce the non-deterministic behavior of an LLM?

⬜ Lowering the temperature and, where supported, setting a random seed
⬜ Switching to a multimodal model
⬜ Raising the temperature and increasing the context window
⬜ Making the prompt longer

A tester pastes real customer records from production into a public AI chatbot to generate test data. Which risk does this create?

⬜ Only the risk that the test data will be too varied
⬜ No risk, because chatbots never retain input
⬜ Only the risk of higher token costs
⬜ The tool may store and process the sensitive data without control or consent, which can also breach data protection rules such as GDPR

An attacker manipulates an LLM used for test automation so that a generated test script opens a communication channel to a specific external IP address. Which attack vector is this?

⬜ Data poisoning
⬜ Context manipulation
⬜ Malicious code generation
⬜ Request manipulation

Someone submits fake ratings when users evaluate the quality of AI-generated test reports, so the model learns from false feedback. Which attack vector is this?

⬜ Prompt chaining
⬜ Data poisoning
⬜ Context manipulation
⬜ Malicious code generation

A bank wants to use GenAI on test data that contains customer details. Which measure follows the syllabus’s mitigation strategies?

⬜ Skip review of generated output because the data is internal
⬜ Avoid encryption so the LLM can read data faster
⬜ Send full production data to any free public chatbot
⬜ Use only the data needed and anonymize or pseudonymize sensitive fields, in a secure environment such as an in-house or secure cloud deployment

Which statement about the energy impact of using GenAI in testing is correct?

⬜ The energy use of a single request is so small that it never matters at scale
⬜ Text generation always uses more energy than image generation
⬜ Energy use is the same for every task and model
⬜ Energy use depends on task complexity and computing resources, for example generating an image uses far more than generating text, so unnecessary interactions should be limited

Which standard specifies requirements for managing AI systems within an organization?

⬜ ISO/IEC 23053:2022
⬜ EU AI Act
⬜ ISO/IEC 42001:2023
⬜ NIST AI Risk Management Framework

Domain 4: LLM-Powered Test Infrastructure for Software Testing (12.5%)

In an LLM-powered test infrastructure, which component handles authentication, data retrieval, prompt preparation and post-processing of the LLM’s output?

⬜ The front end
⬜ The back end
⬜ The vector database
⬜ The LLM itself

How does Retrieval-Augmented Generation (RAG) produce a response to a tester’s query?

⬜ It retrieves document chunks whose embeddings are semantically similar to the query, then gives them to the LLM as context to generate a grounded answer
⬜ It retrains the LLM on the company’s documents before every query
⬜ It increases the temperature so the model recalls more facts
⬜ It returns the stored documents without using an LLM

What lets an LLM-powered agent do more than a traditional AI chatbot in a test process?

⬜ It can act by invoking a predefined set of functions, or tools, to interact with external systems
⬜ It doesn’t use an LLM
⬜ It never hallucinates
⬜ It always works without any human oversight

An organization fine-tunes an SLM on its own user stories and test cases. The model does well on those but poorly on new user stories. Which fine-tuning challenge is this?

⬜ Too little computing power at inference
⬜ Non-deterministic behavior
⬜ Overfitting, where the model becomes too specialized to the training data
⬜ Opacity in the model’s reasoning

An organization plans to develop its own GenAI-based test tool in-house. What does this approach especially emphasize from an LLMOps view?

⬜ Avoiding all use of RAG and fine-tuning
⬜ Full control of data privacy and security risks, plus planning for compute, data storage and staff training, and processes to validate and maintain the solution
⬜ Relying entirely on a vendor’s assurances
⬜ No need for any expertise in deploying LLMs

Domain 5: Deploying and Integrating Generative AI in Test Organizations (17.5%)

Which is a risk of shadow AI in a test organization?

⬜ Using AI tools with unclear licensing, which can lead to intellectual property disputes
⬜ Lower energy consumption
⬜ Faster approval of AI tools
⬜ Better compliance with regulations

What should a GenAI strategy for software testing start with?

⬜ Removing review of generated testware
⬜ Letting each tester pick tools freely
⬜ Buying the largest available LLM
⬜ Defining measurable test objectives for GenAI, such as higher test productivity, shorter test cycles or better test quality

Why should an organization evaluate candidate LLMs against its own benchmarks for its target test tasks?

⬜ Because community support is the only criterion
⬜ Because recurring cost doesn’t matter
⬜ Because few public benchmarks focus on software testing tasks, so model performance must be checked on the organization’s own tasks
⬜ Because public benchmarks are illegal to use

In which phase of GenAI adoption are practical use cases identified and prioritized, and LLM-powered test infrastructure evaluated?

⬜ Discovery
⬜ Initiation and usage definition
⬜ Decommissioning
⬜ Utilization and iteration

Before sharing testware with an LLM, what should a tester do to protect data?

⬜ Sanitize the data by removing or masking sensitive, personal or confidential information
⬜ Encrypt the prompt so the LLM can’t read it
⬜ Add more personal data so the output is realistic
⬜ Share everything, because LLM providers never store input

Which practice helps build GenAI skills across test teams?

⬜ Banning GenAI use until everyone is certified
⬜ Relying only on vendor marketing material
⬜ Training only one expert and keeping the knowledge with them
⬜ Internal communities of practice that share prompt pattern libraries and lessons learned

How do test managers’ responsibilities change when an organization adopts GenAI?

⬜ They no longer need traditional testing skills
⬜ They stop monitoring and controlling testing
⬜ They expand to include an AI-based test strategy, AI-based risk management, and coordinating hybrid teams of people and GenAI-powered test agents
⬜ They hand all test decisions to AI agents
