Free ISC2 Certified Secure Software Lifecycle Professional (CSSLP) Online Practice Exam

Overview

  1. CSSLP (Certified Secure Software Lifecycle Professional) is ISC2’s credential for software professionals who build security (authentication, authorization and auditing) into every phase of the software development lifecycle.
  2. The exam has 125 items in 3 hours; items are multiple choice and advanced item types, delivered at Pearson VUE test centers in English.
  3. The passing grade is 700 out of 1000 points; this practice test uses 70% as the target.
  4. Candidates need four years of cumulative, full-time experience in one or more CSSLP domains (a relevant degree can count for one year). Passing without the experience makes you an Associate of ISC2.
  5. The eight domains are weighted 12%, 11%, 13%, 15%, 14%, 14%, 11% and 10% (outline effective September 15, 2023), so this test has 125 questions split 15 / 14 / 16 / 19 / 17 / 18 / 14 / 12, with 8 multiple-select questions.
  6. Exam outline and certification page for more details.
