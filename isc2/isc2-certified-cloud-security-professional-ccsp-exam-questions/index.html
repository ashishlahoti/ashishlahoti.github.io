Free ISC2 Certified Cloud Security Professional (CCSP) Online Practice Exam

Overview

  1. CCSP (Certified Cloud Security Professional) is ISC2’s credential for experienced professionals who design, manage and secure data, applications and infrastructure in the cloud.
  2. The exam uses Computerized Adaptive Testing (CAT) with 100–150 items in 3 hours; this test has 125 questions in 180 minutes.
  3. The passing grade is 700 out of 1000 points; this practice test uses 70% as the target.
  4. Items are multiple choice and advanced item types, delivered at Pearson VUE test centers in English, Chinese, Japanese and German.
  5. Candidates need five years of IT experience, including three in cybersecurity and one in a CCSP domain (an active CISSP covers the whole requirement). Passing without the experience makes you an Associate of ISC2.
  6. The six domains are weighted 17%, 20%, 17%, 16%, 17% and 13%, so this test has 125 questions split 22 / 25 / 21 / 20 / 21 / 16, with 6 multiple-select questions.
  7. Exam outline and certification page for more details.
