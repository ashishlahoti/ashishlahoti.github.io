Overview

  1. CISSP (Certified Information Systems Security Professional) is ISC2’s flagship credential for experienced security practitioners, managers and executives.
  2. The English exam uses Computerized Adaptive Testing (CAT) with 100–150 items in 3 hours; this test has 125 questions in 180 minutes.
  3. The passing grade is 700 out of 1000 points; this practice test uses 70% as the target.
  4. Items are multiple choice and advanced item types. The exam is delivered at ISC2-authorized Pearson VUE test centers in Chinese, English, German, Japanese and Spanish.
  5. The current exam outline took effect 15 April 2024, and ISC2 says AI security topics are woven into all eight domains.
  6. The eight domains are weighted 16%, 10%, 13%, 13%, 13%, 12%, 13% and 10%, so this test splits 125 questions in the same proportion.
