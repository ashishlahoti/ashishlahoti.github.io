Overview

  1. This is the developer certification from Confluent for developers and solution architects who build applications on Apache Kafka: producers and consumers, delivery guarantees (acks, idempotence, transactions), Schema Registry and schema evolution, Kafka Streams, Kafka Connect, and testing and monitoring Kafka applications.
  2. It suits Java and JVM developers, data engineers and solution architects. Hands-on experience writing Kafka producers, consumers and Kafka Streams applications is strongly recommended.
  3. Exam code is CCDAK, and passing it earns the Confluent Certified Developer for Apache Kafka credential with a digital badge. The exam costs US$150, is taken online with a remote proctor (Honorlock, in Google Chrome with a webcam), and is available in English.
  4. Exam duration is 90 minutes, with about 60 questions. Question types include multiple choice, multiple response, matching and list ordering.
  5. Confluent doesn’t publish the passing score. Results are shown on screen as soon as you finish, and our practice tests use 70% as the target.
  6. The exam covers 6 domains (see the weighting table below). The credential is valid for 2 years. Apache Kafka 4.x runs only in KRaft mode (ZooKeeper was removed in Kafka 4.0), so the questions use KRaft and --bootstrap-server, never ZooKeeper.
  7. Confluent Certification, CCDAK exam preparation guide and Apache Kafka documentation for more details.
