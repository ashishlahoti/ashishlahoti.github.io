Overview

  1. This is the administrator certification from Confluent for engineers who deploy, configure, secure and operate Apache Kafka clusters: KRaft controllers and brokers, replication and topic configuration, security (TLS, SASL, ACLs), Kafka Connect and MirrorMaker 2, monitoring with JMX metrics, and troubleshooting.
  2. It suits platform engineers, DevOps and SRE engineers, and Kafka administrators. Hands-on experience running a Kafka cluster and using the Kafka command-line tools is strongly recommended.
  3. Exam code is CCAAK, and passing it earns the Confluent Certified Administrator for Apache Kafka credential with a digital badge. The exam costs US$150, is taken online with a remote proctor (Honorlock, in Google Chrome with a webcam), and is available in English.
  4. Exam duration is 90 minutes, with about 60 questions. Question types include multiple choice, multiple response, matching and list ordering.
  5. Confluent doesn’t publish the passing score. Results are shown on screen as soon as you finish, and our practice tests use 70% as the target.
  6. The exam covers 7 domains (see the weighting table below), with Cluster Configuration carrying the most weight. The credential is valid for 2 years. Apache Kafka 4.x runs only in KRaft mode (ZooKeeper was removed in Kafka 4.0), so the questions use KRaft controllers, kafka-storage.sh, kafka-metadata-quorum.sh and --bootstrap-server, never ZooKeeper.
  7. Confluent Certification, CCAAK exam preparation guide and Apache Kafka operations documentation for more details.

Why is combined mode (process.roles=broker,controller) not recommended for critical production clusters?

⬜ Combined nodes can’t store data.
⬜ Controllers can’t be isolated from broker load, and they can’t be scaled or restarted separately from the brokers.

Producers using acks=all fail with NotEnoughReplicasException on one topic, while consumers still read it. What is the likely cause?
