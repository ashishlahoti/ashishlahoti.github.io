Free Salesforce Agentforce Specialist Online Practice Exam

Overview

  1. The Salesforce Certified Agentforce Specialist credential is for admins, developers and consultants who build, ground, test, deploy and monitor AI agents and prompt templates on the Salesforce Platform.
  2. It covers Prompt Builder and the Einstein Trust Layer, Data 360 grounding (Data Libraries, search indexes, retrievers), building agents with Agent Script and Agentforce Builder, channels and Agent API, Testing Center and deployment, observability, and multi-agent orchestration with MCP and A2A.
  3. Exam code AI-201. There are no prerequisites. The registration fee is US$200 and the retake fee US$100 (plus tax where applicable).
  4. Exam duration is 105 minutes with 60 scored multiple choice questions (plus up to 5 unscored), taken online-proctored or at a test center.
  5. The passing score is 72%.
  6. The exam guide has six sections weighted at 20%, 20%, 35%, 10%, 10% and 5%, so this test has 60 questions split in the same proportion.
  7. Keep the credential current by completing the annual maintenance module on Trailhead.
  8. Exam guide for more details.

⬜ As a | prompt line asking the LLM for the session ID
⬜ As a mutable string with a default value of the session ID
⬜ As a custom field on the Contact object

⬜ A new subagent named isCreditIssued
⬜ A | line telling the LLM to remember whether it issued a credit
