Free ISACA Advanced in AI Security Management (AAISM) Online Practice Exam

Overview

  1. AAISM (Advanced in AI Security Management) is ISACA’s advanced credential for security professionals who secure enterprise AI and use AI to improve security operations.
  2. It’s designed for holders of an active CISM or CISSP.
  3. The exam has 90 multiple-choice questions in 2.5 hours (150 minutes), in English, Spanish and Japanese.
  4. Scores are scaled from 200 to 800, and 450 or higher passes; this practice test uses 70% as the target.
  5. The exam costs US$459 for ISACA members and US$599 for non-members.
  6. The three domains are weighted 31%, 31% and 38%, so this test has 90 questions split 28 / 28 / 34.
  7. Exam content outline and AAISM page for more details.

⬜ Measure
⬜ Govern

⬜ Map
⬜ Measure

⬜ Lower the threshold to make the risk fit

Why does OWASP recommend “complete mediation” for LLM-driven actions?

⬜ Model drift
⬜ Unbounded consumption

⬜ Data poisoning

⬜ Input size limits, rate limiting, user quotas, timeouts and resource monitoring
⬜ Disabling logging
