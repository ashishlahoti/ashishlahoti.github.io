Overview

  1. This is a fundamentals-level certification validating core knowledge of Git and GitHub: repositories, collaboration with issues and pull requests, GitHub Actions, GitHub Copilot and Codespaces, GitHub Projects, security and administration, and the GitHub community.
  2. There are no prerequisites. It suits developers, students, project managers and anyone new to GitHub.
  3. Exam code is GH-900. The exam is delivered through Microsoft Learn (Pearson VUE), online proctored or at a test center, in English, Spanish, Portuguese (Brazil), Korean and Japanese. The price depends on your country or region.
  4. Exam duration is 100 minutes, with about 65 questions (multiple choice and multiple select; the exam may include interactive components).
  5. The passing score is 700 (on a scale of 1–1000).
  6. The exam covers 7 skill domains (see the weighting table below). The skills outline was significantly revised in January 2026 (Copilot agents and Agent Mode, passkeys, Enterprise Managed Users, InnerSource and more), so older study material may not match.
  7. Like other fundamentals certifications, GitHub Foundations doesn’t expire and needs no renewal.
  8. Official certification page, GH-900 study guide and GitHub documentation for more details.
