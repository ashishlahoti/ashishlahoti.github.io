Free UiPath Agentic Automation Associate (UiPath-AAAv1) Online Practice Exam

Overview

  1. The UiPath Certified Professional Agentic Automation Associate certification validates foundational skills for working with AI agents in process automation: designing agents, grounding them in enterprise knowledge, keeping humans in the loop and orchestrating agents, robots and people with UiPath Maestro.
  2. The exam (UiPath-AAAv1) is 90 minutes with a passing score of 70%. It costs US$150, has no prerequisites, and the credential is valid for 3 years.
  3. The products in scope are UiPath Studio Web, UiPath Maestro and Autopilot for Everyone.
  4. The exam description lists ten sections without weights. This test has 60 questions spread across all ten (7 / 6 / 6 / 6 / 6 / 6 / 6 / 7 / 7 / 3).
  5. Exam description for more details.

Domain 1: Agentic AI and agentic automation concepts

A spam filter learns to spot junk mail from thousands of example emails instead of from rules someone wrote. Which term describes this approach?

⬜ Robotic process automation
⬜ Machine learning
⬜ Business Process Model and Notation
⬜ Human-in-the-loop

A UiPath agent relies on an LLM to read a support ticket and plan its next step. What kind of technology is the LLM?

⬜ A database of embeddings for searching documents by meaning
⬜ A model pretrained on vast text that generates language token by token
⬜ A rule engine matching emails against hand-written keywords
⬜ A robot that clicks through application screens in the same order every time it runs

A team asks how agentic AI differs from generative AI. Which answer is MOST accurate?

⬜ Agentic AI uses generative models to pursue a goal, calling tools and then acting on the results
⬜ Agentic AI makes images; generative AI makes text
⬜ They are the same; agentic AI is just a name for any LLM
⬜ Agentic AI follows fixed if-then rules, while generative AI learns its behavior from training data

According to UiPath, how do agents differ from RPA robots?

⬜ Agents are deterministic and rule-based; robots are probabilistic and learn from data
⬜ Agents can only be scheduled; robots can only be started by a user who asks a question
⬜ Agents replace robots completely, so robots are no longer used in agentic automation
⬜ Agents are probabilistic and adaptive; robots are deterministic and follow fixed, structured rules

Which process is the WEAKEST fit for automation done only with robots and people, and the strongest candidate for an agent?

⬜ Archiving files with a known naming pattern weekly
⬜ Triaging free-text complaints that arrive in many formats
⬜ Running a nightly report that exports the same database query to a shared folder
⬜ Copying invoice totals from a fixed form into the ERP

What does UiPath mean by agentic orchestration?

⬜ Running many copies of one robot in parallel
⬜ Letting one agent replace every robot and person in a business process
⬜ Scheduling robots in Orchestrator so they start at fixed times each day
⬜ Coordinating agents, robots and people in one governed process

Which are benefits of agentic automation over automation done only with robots? (Choose two.)

⬜ No need for any human oversight or governance
⬜ Decisions that adapt to unstructured, changing inputs
⬜ Goal-oriented execution that plans its own steps
⬜ Identical outputs guaranteed for identical inputs

Domain 2: Agentic discovery

When assessing a business process for agentic automation potential, what should the team consider according to the exam outline?

⬜ Only which LLM vendor offers the lowest price per thousand tokens
⬜ Roles, knowledge context, technology landscape and as-is state
⬜ Only how many clicks each step needs
⬜ Only whether the process owner already has a UiPath Studio license

Which are among the five characteristics used to describe an agent story? (Choose two.)

⬜ Robot license type
⬜ Screen resolution
⬜ Trigger
⬜ Human in the loop

A discovery workshop found 12 possible agent use cases. How should the team decide which to build first?

⬜ Prioritize by feasibility and business impact
⬜ Build the one with the longest process description
⬜ Build them all at once in a single multi-role agent
⬜ Pick the one that needs the largest number of tools

In an existing claims process, which step is the BEST candidate to hand to an agent?

⬜ Copying the approved payout amount into the payments system using the same screen each time
⬜ Reading a free-text claim description and deciding which category and team it belongs to
⬜ Calculating the payout with a fixed formula from the policy table once the claim is approved
⬜ Sending the standard confirmation email template once the payment has been made

An analyst proposes one agent that extracts invoices, answers HR questions and approves travel. What does UiPath guidance recommend instead?

⬜ Scope each agent narrowly to a single responsibility
⬜ Add more tools so the one agent can handle every role
⬜ Remove escalations to finish faster
⬜ Write the whole process as one long prompt with no tools

A process has long, deterministic steps governed by hard business rules. Where should that logic live?

⬜ In an escalation, so a human applies every rule by hand each time
⬜ In standard automation or BPMN orchestration, not inside the agent itself
⬜ In a Context Grounding index, so the agent looks the rules up as text
⬜ Inside the agent’s system prompt as a very detailed list of rules

Domain 3: Agent blueprint design

During blueprint design, what is the FIRST step for turning a business process into an agent design?

⬜ Map the process steps to agent tasks
⬜ Choose the agent’s colour theme in Studio Web
⬜ Publish the agent to a shared Orchestrator folder
⬜ Write evaluation results before defining any task

Which content belongs in an agent’s system prompt?

⬜ The list of users who are licensed to run the agent in the tenant
⬜ Role, goal, constraints and when to use tools or escalations
⬜ The Orchestrator folder path where the agent package will be deployed
⬜ Only this run’s input argument values

What is the main purpose of the user prompt in a UiPath agent?

⬜ To list the Action apps that receive the agent’s escalations at runtime
⬜ To define the agent’s persona and rules
⬜ To store the agent’s evaluators
⬜ To structure how runtime inputs are passed to the agent

An agent’s arguments are defined, but at runtime it ignores one of them. What is the MOST likely cause?

⬜ It is not referenced in the user prompt, so the agent never sees it
⬜ The argument type is String, which agents cannot read as an input value
⬜ The argument was created in the Data Manager instead of in Orchestrator
⬜ The argument has a description, which hides it from the agent at runtime

Why should the evaluation criteria be identified during blueprint design, not after deployment?

⬜ Agents cannot be given a system prompt until their evaluators have been written
⬜ Evaluation criteria decide which Orchestrator folder the agent is deployed into
⬜ Evaluation criteria replace the need for escalations to humans during the run
⬜ Measurable success criteria are needed to judge whether the agent is reliable

A procurement agent must check a supplier’s contract terms stored in hundreds of PDFs and then create a purchase order in the ERP. Which design is MOST appropriate?

⬜ Give it only an order tool and let it guess the terms
⬜ Paste every contract into the system prompt and ask the agent to describe the purchase order
⬜ Escalate every order so a human does the work
⬜ Ground it on a contracts index and give it a tool to create the order

Domain 4: Context Grounding

What is Context Grounding in the UiPath Platform?

⬜ A feature that fine-tunes the agent’s LLM on company documents every night
⬜ A BPMN gateway that routes a process based on the content of a document
⬜ A RAG service in the AI Trust Layer that indexes business data for retrieval
⬜ A connector that copies company documents into each user’s email inbox

Which are supported data sources for a Context Grounding index? (Choose two.)

⬜ SharePoint or Google Drive through Integration Service connectors
⬜ Screenshots taken by an attended robot
⬜ The agent’s own evaluation results
⬜ Orchestrator storage buckets

An agent’s answers include passages that have little to do with the question. Which Context Grounding setting should be raised to improve precision?

⬜ Relevance score threshold
⬜ Agent temperature
⬜ Folder path prefix
⬜ Max results generated

An agent run fails with a ’tokens exceeded’ error after retrieving context. What is the recommended fix?

⬜ Return fewer results or shorten the user input
⬜ Rename the index without a version number in its name
⬜ Switch the index from Basic to Advanced ingestion mode
⬜ Raise the number of results so the agent has more context

A knowledge base contains scanned PDFs and infographics that mix text and images. Which ingestion mode should be chosen for the index?

⬜ Deterministic mode
⬜ Advanced mode
⬜ Basic mode
⬜ Static mode

HR updates its policy documents every month, but the agent keeps quoting last year’s rules. What should the team do?

⬜ Sync the index regularly from Orchestrator
⬜ Delete the system prompt so the agent relies on the LLM alone
⬜ Return one chunk per query
⬜ Increase the agent’s temperature so it writes fresher answers

Domain 5: Escalations

Why is human-in-the-loop (HITL) important in agentic automation?

⬜ It lets the agent skip testing because a person checks every output anyway
⬜ It replaces the need for tools, because a person performs every action
⬜ It balances agent autonomy with human oversight for exceptions
⬜ It makes the agent deterministic

What powers escalations in UiPath agents?

⬜ Context Grounding indexes
⬜ Integration Service triggers
⬜ BPMN exclusive gateways
⬜ Action apps in UiPath Action Center

How does a developer tell the agent WHEN to raise a particular escalation?

⬜ Add an exact match evaluator to it
⬜ Give the escalation a prompt that acts as its trigger condition
⬜ Put the escalation on a daily schedule
⬜ Lower the Context Grounding threshold so the agent escalates when nothing is found

Escalations should go to whichever member of the claims team has the fewest open tasks. Which assignment criterion fits?

⬜ User
⬜ Workload
⬜ Round Robin
⬜ All users in group

A reviewer rejects an agent’s proposed refund, and the agent should stop rather than continue. How is this configured?

⬜ Set the Outcome behavior for the rejection outcome to Continue
⬜ Delete the escalation so that the agent cannot run the tool
⬜ Set the Outcome behavior for the rejection outcome to End
⬜ Raise the relevance threshold on the agent’s context index

A support agent escalates the same type of warranty question every day, and humans always give the same answer. Which capability can stop this repeat escalation?

⬜ A larger language model, which removes the need for any human escalations at all
⬜ Agent memory, which reuses past escalation resolutions
⬜ A shared Integration Service connection
⬜ A parallel gateway in Maestro

Domain 6: Agentic evaluations

In UiPath agents, what is an evaluation?

⬜ A BPMN diagram that shows each step the agent is allowed to take
⬜ An input paired with an evaluator that checks the output
⬜ A human approval task that the agent raises before calling a tool
⬜ A monthly report on how many tokens the agent used in production

An agent must return true or false for whether an invoice is a duplicate. Which evaluator type fits BEST?

⬜ LLM as a judge faithfulness
⬜ LLM as a judge semantic similarity
⬜ Deterministic exact match
⬜ Trajectory

How do model-graded (LLM as a judge) evaluators differ from deterministic evaluators?

⬜ They need no prompt or model
⬜ They always produce the same score for the same input because they use fixed rules
⬜ They use an LLM to judge meaning, tolerating varied wording
⬜ They can only compare CSV columns

A team wants to check not just the agent’s final answer but whether it called the right tools in a sensible order. Which evaluator should they use?

⬜ Trajectory
⬜ Exact match
⬜ CSV column exact match
⬜ JSON similarity

A team wants to test its agent safely without calling the real ERP system. What does UiPath provide for this?

⬜ Deleting the ERP tool before testing
⬜ Setting escalation outcomes to End
⬜ Simulated tools, where an LLM mocks the tool responses
⬜ Running every test in production and reversing changes in the ERP afterwards

Users flag several bad answers from a deployed agent with a thumbs-down. How can these cases improve the design?

⬜ Raise the escalation assignment to every user in the tenant
⬜ Delete the traces so the agent’s evaluation score is not lowered
⬜ Copy the bad answers into the system prompt as the expected output
⬜ Add the flagged runtime traces to an evaluation set

Domain 7: Prompt engineering

A user asks an LLM, with no examples, to ‘Classify this email as Complaint, Inquiry or Praise.’ What kind of prompt is this?

⬜ A system-only prompt
⬜ A zero-shot prompt
⬜ A chain of escalations
⬜ A few-shot prompt

An agent formats its extracted data inconsistently. Which prompting change is MOST likely to make the output consistent?

⬜ Add a few input/output examples showing the exact expected format
⬜ Let the agent use as many words as it likes
⬜ Remove all instructions
⬜ Add every possible edge case as an example inside the prompt

Which set of elements does the exam outline say a well-crafted prompt should include?

⬜ Gateway type, task marker, lane and pool for the process
⬜ Folder path, license type, machine name and schedule
⬜ Context, instructions, output format and constraints
⬜ Embedding model, vector database, index and threshold

Which prompt BEST applies clarity and specificity?

⬜ ‘Read the document very carefully, and then think about it, and then write something good.’
⬜ ‘You are a compliance analyst. Summarize each policy section in two sentences and flag any gaps.’
⬜ ‘Please take a look at this document and do whatever you think would be most useful here.’
⬜ ‘Summarize it.’

A user prompt lists only {{email_to}}, {{customer_email}} and {{reply_email_id}} with no labels. What is the risk?

⬜ The agent receives only raw values and has to infer which value belongs to which field
⬜ The placeholders are sent to an escalation instead of to the agent at runtime
⬜ The values are stored in Context Grounding and are no longer passed to the LLM
⬜ The agent will refuse to run because placeholders must be written in capital letters

Why does UiPath advise AGAINST hard-coding many edge-case examples in an agent’s prompt?

⬜ Evaluation sets cover edge cases better and keep the prompt focused
⬜ Prompts may not contain any examples
⬜ Prompt examples are ignored at runtime
⬜ Edge cases are automatically handled by escalations, so the agent never needs to see them

Domain 8: UiPath Platform components and integrations

How does an agent decide WHICH tool to call?

⬜ From the folder the tool is published in
⬜ From a random selection, after which it retries until one of the tools succeeds
⬜ It always calls the first tool listed
⬜ From the tool’s name, description and system prompt context

⬜ They are left without descriptions so the agent infers their purpose from the name alone
⬜ They use supported types and have clear descriptions

Which tool name follows UiPath’s naming guidance for agent tools?

⬜ invoice_lookup
⬜ tool #1
⬜ Invoice Lookup Tool!
⬜ Look-up_INVOICES (new)

What are the three components of UiPath Integration Service?

⬜ Gateways, tasks and events

⬜ Indexes, embeddings and vector databases
⬜ Connectors, connections and server-side triggers

A connection to Salesforce authenticates with a personal user account. Where does UiPath recommend creating it?

⬜ In a Context Grounding index
⬜ Inside the agent’s system prompt
⬜ In a shared team folder, so every developer can reuse the personal credentials
⬜ In the user’s Personal Workspace, not a shared folder

An Integration Service activity is added as an agent tool. The ‘Priority’ field must always be ‘Normal’. Which input method should be used for it?

⬜ Static Value
⬜ Argument
⬜ Prompt
⬜ LLM inferred

A connector activity the team needs is not yet available directly as an agent tool. What is the recommended workaround?

⬜ Wrap it in a published Studio Web workflow and add that as a tool
⬜ Raise an escalation so a human calls the connector each time it is needed
⬜ Ask the agent in its prompt to call the connector’s API using its own credentials
⬜ Add the connector as a context source so the agent can retrieve its actions

Domain 9: Agentic orchestration with UiPath Maestro

What is UiPath Maestro?

⬜ A desktop recorder that captures user clicks and turns them into RPA workflows
⬜ A cloud platform that orchestrates agents, robots and people in processes
⬜ A vector database that stores embeddings of company documents for retrieval
⬜ A licensing portal for runtimes

Which modeling standard does Maestro use to model business processes and map tasks to robots, agents and humans?

⬜ UML class diagrams
⬜ Entity-relationship diagrams
⬜ BPMN 2.0
⬜ Gantt charts

In a Maestro process, a step must run a deployed UiPath agent and pause the process until the agent finishes. How is this configured?

⬜ A send task to the agent
⬜ An event-based gateway
⬜ A user task assigned to the agent through the Task Inbox
⬜ A service task set to type ‘Start and wait for agent’

A Maestro step must run an RPA workflow published in Orchestrator and continue only when it completes. Which service task type is used?

⬜ Start agentic process
⬜ Create action app task
⬜ Start and wait for RPA workflow (deployed)
⬜ Create queue item for the workflow

In a BPMN model, a manager must approve the agent’s recommendation. Which task type represents this step?

⬜ Business rule task
⬜ Script task
⬜ User task
⬜ Service task

After an agent classifies a claim as Approved, Rejected or Needs info, the process must follow exactly one matching path. Which BPMN element fits?

⬜ Parallel gateway
⬜ Inclusive gateway
⬜ Call activity
⬜ Exclusive (XOR) gateway

After approval, the process must send a confirmation AND generate a report at the same time, then wait for both to finish. Which gateway is required to split and to join?

⬜ An event-based gateway
⬜ No gateway is needed to join
⬜ An exclusive gateway
⬜ A parallel gateway

Domain 10: Autopilot for Everyone

Who is Autopilot for Everyone primarily designed for?

⬜ Developers building BPMN processes in Maestro
⬜ Infrastructure engineers installing Automation Suite
⬜ Business users needing help with daily tasks
⬜ Data scientists training custom embedding models

A business user wants to ask Autopilot for Everyone a question about company travel policy. What lets it answer from the policy documents?

⬜ Searching a Context Grounding index of the policies
⬜ Fine-tuning the model per question
⬜ Starting a Maestro BPMN process that reads the policy for the user
⬜ Running a UiPath agent with escalations configured for HR

When is Autopilot for Everyone the WRONG choice?

⬜ When a user wants to run an existing RPA process on demand
⬜ When a user wants answers grounded in company documents
⬜ When the task must run a UiPath agent or a Maestro BPMN workflow
⬜ When a user wants help drafting content from a short prompt
