Free NVIDIA Agentic AI (NCP-AAI) Online Practice Exam

Overview

  1. This is a Professional (intermediate) level certification for engineers who design, build, evaluate and run production agentic AI systems on NVIDIA solutions.
  2. It covers agent architecture and design, agent development, evaluation and tuning, deployment and scaling, cognition, planning and memory, knowledge integration, NVIDIA platform implementation, operations, safety and compliance, and human oversight.
  3. NVIDIA recommends 1–2 years of AI/ML experience with hands-on production agentic AI work. The exam fee is US$200, delivered online and remotely proctored through Certiverse, in English.
  4. Exam duration is 120 minutes with 60–70 questions; this test has 65.
  5. NVIDIA doesn’t publish a pass mark; this practice test uses 70% as the target.
  6. The ten domains are weighted 15%, 15%, 13%, 13%, 10%, 10%, 7%, 5%, 5% and 5%, so this test splits 65 questions in the same proportion.
  7. The certification is valid for 2 years; recertify by retaking the exam.
  8. Exam page with blueprint and study guide for more details.

Domain 1: Agent Architecture and Design (15%)

A team is designing an LLM system. In one design, code calls the LLM and tools along fixed paths. In the other, the LLM decides for itself which tools to use and in what order. What are these two designs called?

⬜ Both are agents; the only difference is the model size
⬜ Both are workflows, because both use tools
⬜ The first is a workflow and the second is an agent

⬜ Orchestrator-workers
⬜ Routing
⬜ Prompt chaining
⬜ Parallelization by voting

⬜ Orchestrator-workers
⬜ Routing
⬜ Prompt chaining
⬜ Evaluator-optimizer

One model answers a user’s query while a separate model screens the same input for inappropriate content at the same time. What’s this pattern called?

⬜ Routing
⬜ Evaluator-optimizer
⬜ Parallelization by sectioning
⬜ Voting

A literary translation agent produces a draft, and a second LLM critiques it against clear quality criteria until the draft is good enough. When does this pattern work best?

⬜ When the steps are fully known and fixed in advance
⬜ When latency has to be as low as possible
⬜ When the task has no way to judge quality
⬜ When there are clear evaluation criteria and the feedback measurably improves the result

⬜ A2A is for agent-to-agent communication, and MCP is for agent-to-tool communication
⬜ MCP is for agent-to-agent communication, and A2A is for agent-to-tool communication

⬜ Use the agent to grade its own answers with no checks
⬜ Rely only on exact-match string comparison
⬜ Stop evaluating open-ended answers
⬜ Use a strong LLM as a judge, which reached over 80% agreement with human preferences in the study
