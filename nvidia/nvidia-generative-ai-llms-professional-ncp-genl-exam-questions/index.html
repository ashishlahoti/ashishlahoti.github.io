Free NVIDIA Generative AI LLMs Professional (NCP-GENL) Online Practice Exam

Overview

  1. This is a Professional (intermediate) level certification for engineers who build, optimize, deploy and run LLMs on NVIDIA platforms.
  2. NVIDIA recommends 2–3 years of practical AI/ML experience with LLMs, including Transformers, prompt engineering, distributed parallelism, parameter-efficient fine-tuning, RAG, evaluation and performance profiling.
  3. The exam fee is US$200, delivered online and remotely proctored, in English.
  4. Exam duration is 120 minutes with 60–70 questions; this test has 65.
  5. NVIDIA doesn’t publish a pass mark; this practice test uses 70% as the target.
  6. The ten domains are weighted 6%, 13%, 9%, 17%, 13%, 7%, 14%, 9%, 7% and 5%, so this test splits 65 questions in the same proportion.
  7. The certification is valid for 2 years; recertify by retaking the exam.
  8. Exam page with blueprint and recommended training for more details.

Domain 1: LLM Architecture (6%)

How does Rotary Position Embedding (RoPE) represent token positions in a Transformer?

⬜ It encodes absolute position with a rotation matrix, which builds relative position dependency into self-attention
⬜ It stores positions in the KV cache instead of the embeddings
⬜ It adds a learned position vector that only works up to the training length
⬜ It removes position information to save memory

A model has a huge number of parameters, but each token uses only a fraction of them, so the compute per token stays roughly constant. Which architecture is this?

⬜ A sparsely activated mixture-of-experts (MoE) model, which selects different parameters for each input
⬜ A dense decoder-only model
⬜ A model with grouped-query attention
⬜ A model trained with LoRA

Long-context inference is limited by KV cache memory. Which attention design reduces the KV cache by sharing keys and values across groups of query heads?

⬜ Multi-head attention with more heads
⬜ Grouped-query attention (GQA)
⬜ Pipeline parallelism
⬜ Absolute position embeddings

Using the formula KV cache per token = 2 × layers × (heads × head dimension) × bytes per value, what happens if the KV cache moves from FP16 to FP8?

⬜ It doubles
⬜ It stays the same, because precision isn’t in the formula
⬜ It drops to zero
⬜ The KV cache per token is halved, because each value uses half the bytes

⬜ Greedy decoding

A team tries chain-of-thought exemplars on a small model and sees little benefit. What does the original chain-of-thought research suggest?

⬜ Chain-of-thought reasoning abilities emerge naturally in sufficiently large language models, so smaller models may not benefit
⬜ Chain of thought works the same on every model size
⬜ Chain of thought only works with zero examples
⬜ Chain of thought requires fine-tuning

A RAG prompt places 20 retrieved passages in the context, and the answer is often in passage 10. Accuracy is poor. What change does long-context research suggest?

⬜ Remove the question from the prompt
⬜ Put the most relevant passages at the beginning or end of the context, because models use information in the middle less well
⬜ Add more irrelevant passages
⬜ Always put the most relevant passage in the exact middle

⬜ Remove all instructions
⬜ Increase the context window
⬜ Pretrain a new model

⬜ Few-shot classification

Users want answers they can verify. How does retrieval-augmented generation help compared with relying only on the model’s training?

⬜ It grounds answers in retrieved sources the model can cite, so users can check the claims
⬜ It removes the need for a knowledge base
⬜ It retrains the model on every query

A RAG system retrieves 100 candidate passages quickly with embeddings, but the top results are often only loosely related. What improves precision?

⬜ Send all 100 passages to the LLM

A support bot must follow predefined conversation flows, for example always asking for an order number before discussing a refund. Which NeMo Guardrails feature fits?

⬜ GPU time-slicing
⬜ Retrieval reranking
⬜ Output rails only
⬜ Dialog rails written in Colang, which predefine conversational flows

Why does a byte-level BPE tokenizer, as used by GPT-2, never produce unknown tokens?

⬜ It uses a dictionary of every word in every language
⬜ It only supports English
⬜ Its base vocabulary is the 256 byte values, so any text can be represented as bytes
⬜ It maps all rare words to a single unknown token

How does a BPE tokenizer build its vocabulary during training?

⬜ It starts from individual symbols and repeatedly merges the most frequent adjacent pair until the target vocabulary size is reached
⬜ It keeps only whole words seen more than once
⬜ It picks random substrings
⬜ It splits text into fixed four-character chunks

A pretraining corpus contains many near-duplicate web pages. What benefits does deduplication bring, according to research?

⬜ It has no effect on training efficiency
⬜ Models emit memorized text about ten times less often and reach similar or better accuracy with fewer training steps
⬜ It always increases memorization
⬜ It removes the need for a validation set

A team’s benchmark scores look unusually high. It finds some benchmark questions also appear in the training data. What’s the issue, and what should it do?

⬜ Nothing, because overlap improves the model
⬜ Add more benchmark data to training
⬜ Train-test overlap inflates evaluation, so the overlapping examples should be removed (decontamination) before evaluating
⬜ Increase the learning rate

Which capabilities does NVIDIA NeMo Curator provide for preparing text data for LLM training?

⬜ Only model serving
⬜ Only GPU driver installation
⬜ Exact, fuzzy and semantic deduplication, heuristic and classifier-based quality filtering, and language detection
⬜ Only prompt templates

A multilingual web crawl must be split by language before building language-specific training sets. Which NeMo Curator capability helps?

⬜ Language detection

⬜ Dynamic batching

Domain 4: Model Optimization (17%)

Token generation (decode) is memory-bandwidth-bound. Which optimization most directly reduces the data moved per decode step?

⬜ Using FP32 everywhere
⬜ Quantizing the model weights to lower precision, so fewer bytes are read from memory
⬜ Increasing the prompt length
⬜ Disabling the KV cache

In TensorRT-LLM, what does a W4A16 AWQ recipe mean?

⬜ The model is pruned to 4 layers
⬜ Both weights and activations use 4 bits
⬜ Weights use 16 bits and activations use 4 bits
⬜ Weights are quantized to 4 bits while activations stay at 16 bits

A team plans FP8 weight and activation quantization with TensorRT-LLM. Which GPU generation can’t run the FP8 recipes?

⬜ Hopper
⬜ Ada Lovelace (FP8 per tensor)
⬜ Blackwell
⬜ Ampere

A long-context service is limited by KV cache memory, and the checkpoint doesn’t enable an FP8 KV cache by default. What does TensorRT-LLM allow?

⬜ Enabling an FP8 KV cache manually, which reduces KV cache memory
⬜ Only removing the KV cache
⬜ Nothing, because the KV cache precision can’t change
⬜ Only NVFP4 KV cache without any quantization step

A team wants a much smaller model that behaves like its large production model, to cut serving cost. Which technique fits?

⬜ Self-consistency
⬜ Knowledge distillation, training a smaller student model to mimic the larger teacher
⬜ Data deduplication
⬜ Pipeline parallelism

A Triton model uses the dynamic batcher, and throughput is lower than hoped. What does raising max_queue_delay_microseconds trade off?

⬜ Lower latency and lower throughput
⬜ More GPU memory for less accuracy
⬜ Nothing, because the setting has no effect
⬜ Higher latency for higher throughput, since requests wait briefly so fuller batches can form

A stateful model needs all requests in a sequence to go to the same model instance. Which Triton scheduler fits?

⬜ The default scheduler with preferred batch sizes
⬜ The dynamic batcher
⬜ The sequence batcher
⬜ Time-slicing

A team wants to know how much GPU memory several models need under different batching and instance settings before deciding how to share one GPU. Which tool helps?

⬜ Triton Model Analyzer, which uses Perf Analyzer to measure GPU memory and compute use
⬜ NCCL
⬜ NeMo Curator
⬜ Nsight Systems NVTX ranges only

Users complain that responses take too long to start appearing. Which metric captures this, and what does it include?

⬜ Total tokens per second across all users
⬜ Time to first token (TTFT), which includes request queuing, prefill and network latency
⬜ Requests per second
⬜ Inter-token latency, which only measures decode speed

How does NVIDIA’s benchmarking guide calculate inter-token latency (ITL)?

⬜ Requests per second × output tokens
⬜ TTFT ÷ output tokens
⬜ End-to-end latency ÷ input tokens
⬜ (End-to-end latency − TTFT) ÷ (output tokens − 1), so it excludes the time to first token

As a team raises concurrency in a load test, total tokens per second rises. What typically happens to per-user experience?

⬜ Per-user speed always rises with concurrency
⬜ Latency stays constant at any load
⬜ Per-user tokens per second falls as latency rises, and past saturation total throughput can also decrease
⬜ Throughput rises forever

Domain 5: Fine-Tuning (13%)

A team must fine-tune a 65B-parameter model but has a single 48 GB GPU. Which method was shown to make this possible while keeping 16-bit fine-tuning quality?

⬜ QLoRA, which backpropagates through a frozen 4-bit quantized model into low-rank adapters
⬜ Full fine-tuning in FP32
⬜ Pipeline parallelism on one GPU
⬜ Prompt engineering

Which QLoRA techniques reduce memory?

⬜ Removing the adapters
⬜ Doubling the batch size
⬜ 4-bit NormalFloat (NF4), double quantization of the quantization constants, and paged optimizers for memory spikes
⬜ FP32 master weights for every layer

Why can LoRA be deployed without extra inference latency?

⬜ LoRA removes attention layers
⬜ LoRA always runs a second model at inference
⬜ LoRA lowers the model’s precision to 1 bit
⬜ The trained low-rank matrices can be merged into the frozen weights, so no extra layers run at inference

A team has prompts with chosen and rejected responses and wants to align its model without training a separate reward model or running RL sampling. Which method fits?

⬜ Self-consistency decoding
⬜ PPO-based RLHF
⬜ Direct Preference Optimization (DPO)
⬜ Supervised pretraining from scratch

A company serves many customer-specific variants of one base model. Why is LoRA a good fit?

⬜ Each variant stores only small adapter matrices on a shared frozen base, which cuts storage and allows quick task switching
⬜ LoRA can’t share a base model
⬜ Each variant needs a full copy of all weights
⬜ LoRA requires retraining the base model per customer

Fine-tuning runs out of GPU memory at a per-device batch size of 4, but the target is an effective batch of 64. What helps?

⬜ Disable mixed precision
⬜ Gradient accumulation with 16 steps, accepting slower training from the extra passes
⬜ Remove the validation set
⬜ Raise the per-device batch to 64

Activation memory is the bottleneck when fine-tuning on long sequences. Which technique trades compute for memory, and what’s the typical cost?

⬜ Gradient accumulation, which stores all activations
⬜ Gradient checkpointing, which recomputes some activations in the backward pass, typically about 20% slower
⬜ Raising the learning rate
⬜ Increasing the vocabulary size

During QLoRA fine-tuning, occasional memory spikes cause out-of-memory errors. Which QLoRA component addresses this?

⬜ Removing the frozen base model
⬜ Double quantization of activations
⬜ Paged optimizers
⬜ Increasing the LoRA rank

A team enables FP16 mixed precision for a small-batch fine-tune and sees GPU memory go up, not down. Why can this happen?

⬜ Mixed precision can keep both FP16 and FP32 copies of the model, so with small batches memory may not drop
⬜ Mixed precision disables Tensor Cores
⬜ FP16 always uses more memory than FP32 for activations
⬜ Mixed precision removes gradient computation

A team evaluates a summarization model against human-written reference summaries using n-gram overlap. Which metric family fits?

⬜ Requests per second
⬜ ROUGE
⬜ Perplexity
⬜ Tokens per second

Which ROUGE variants does the original ROUGE package define?

⬜ TTFT and ITL
⬜ BLEU-1 to BLEU-4
⬜ F1 and AUC
⬜ ROUGE-N, ROUGE-L, ROUGE-W and ROUGE-S

A team uses a strong LLM as a judge to compare two answers and notices it tends to prefer whichever answer comes first and longer answers. What does the research call these issues?

⬜ Pipeline bubbles
⬜ Overfitting and underfitting
⬜ Data drift and concept drift
⬜ Position bias and verbosity bias, along with self-enhancement bias

How well does a strong LLM judge such as GPT-4 agree with human preferences, according to the MT-Bench study?

⬜ Over 80% agreement, about the same level as agreement between humans
⬜ Exactly 100%
⬜ It can’t be measured
⬜ About 20%

A team benchmarks an LLM endpoint for a capacity report. What should it measure to show the latency-throughput trade-off?

⬜ Only training loss
⬜ TTFT, inter-token latency and total tokens per second at several concurrency levels
⬜ Only the average prompt length
⬜ Only the model’s parameter count

Domain 7: GPU Acceleration and Optimization (14%)

A team uses tensor parallelism, but LayerNorm and Dropout activations still use a lot of memory. Which NeMo feature splits these along the sequence dimension, and what does it require?

⬜ Data parallelism, which copies the full model
⬜ Pipeline parallelism with one stage
⬜ Expert parallelism, which requires MoE layers
⬜ Sequence parallelism, which requires tensor parallelism greater than 1

A team trains with 128K-token sequences, and activation memory across all layers is too large. Which parallelism partitions the input along the sequence dimension for long-context training?

⬜ Tensor parallelism only
⬜ Data parallelism only
⬜ Context parallelism
⬜ Interleaved pipeline schedule only

A mixture-of-experts model has too many experts to fit on each GPU. Which parallelism fits?

⬜ Context parallelism
⬜ Sequence parallelism
⬜ Expert parallelism, which distributes the experts across GPUs
⬜ Gradient accumulation

Pipeline-parallel training shows large idle “bubbles” on GPUs. Which NeMo option reduces them?

⬜ Time-slicing the GPUs
⬜ The interleaved (virtual) pipeline schedule, which gives each GPU several smaller model chunks
⬜ Larger vocabulary
⬜ Turning off the KV cache

In data-parallel training, optimizer states and FP32 master weights use too much memory on each GPU. Which NeMo feature helps?

⬜ FP8 KV cache
⬜ Speculative decoding
⬜ Context parallelism only
⬜ The distributed optimizer, which shards optimizer states and high-precision master parameters across data-parallel GPUs

In NeMo’s default distributed data parallel (DDP) training, how are gradients from model replicas combined?

⬜ By copying the weights over email
⬜ With pipeline bubbles
⬜ With an all-reduce collective that sums the gradients across replicas before each update
⬜ Each GPU updates independently and never syncs

Which interconnects and topologies does NCCL support for GPU collectives?

⬜ PCIe, NVLink, InfiniBand Verbs and IP sockets, within and across nodes
⬜ Only PCIe within one node
⬜ Only shared memory on CPUs
⬜ Only Ethernet across nodes

A training step is slow, and the team wants a system-wide timeline of CPU threads and GPU activity with named ranges for data loading and the forward pass. What should it use?

⬜ Triton Model Analyzer
⬜ NeMo Curator
⬜ ROUGE
⬜ Nsight Systems with NVTX ranges

A team wants to profile only steps 100 to 110 of a long training run with Nsight Systems, without changing the training logic. What does Nsight Systems support?

⬜ It only works on CPUs
⬜ It requires rewriting the model in C++
⬜ It can only profile the entire run
⬜ It needs no application changes to profile, and capture can be limited with cudaProfilerStart() and cudaProfilerStop()

Domain 9: Production Monitoring and Reliability (7%)

Triton metrics show cumulative queue time rising sharply while compute time per request stays flat. What does this suggest?

⬜ The model got slower at computing
⬜ Requests are waiting for capacity, so more model instances or replicas, or batching tuning, are needed
⬜ The tokenizer is broken
⬜ Accuracy has dropped

An LLM classifier’s accuracy drops because the relationship between inputs and the correct label has changed, even though input distributions look similar. What is this?

⬜ Quantization error
⬜ Pipeline bubbles
⬜ Data drift (covariate shift)
⬜ Concept drift

How should a team detect and respond to drift in a production model?

⬜ Ignore it, because models never degrade
⬜ Delete the training data
⬜ Monitor continuously with statistical tests such as Kolmogorov-Smirnov or PSI, alert on thresholds, and retrain on recent data, or build a new model if retraining doesn’t fix it
⬜ Check once a year by hand

In load tests, an LLM service’s total throughput starts to fall once concurrency goes past a certain level. What should the reliability plan do?

⬜ Cap concurrency per replica near the saturation point and scale out replicas, since TPS can fall past saturation
⬜ Keep raising concurrency on one replica
⬜ Reduce the number of replicas
⬜ Turn off monitoring
