Free NVIDIA-Certified Professional: AI Infrastructure (NCP-AII) Online Practice Exam

Overview

  1. The NVIDIA-Certified Professional: AI Infrastructure (NCP-AII) validates intermediate skills for deploying and validating NVIDIA AI data center infrastructure: bringing up GPU servers, BMCs and firmware, configuring BlueField and MIG, installing Base Command Manager, Slurm and container tooling, testing clusters with HPL, NCCL and ClusterKit, and troubleshooting hardware.
  2. The exam has about 70 questions in 120 minutes, costs US$400, and is delivered online with remote proctoring. The certification is valid for 2 years.
  3. NVIDIA doesn’t publish a pass mark, so this practice test uses 70% as the target.
  4. NVIDIA recommends two to three years of experience working in a data center with NVIDIA hardware.
  5. The five domains are weighted 31%, 5%, 19%, 33% and 12%, so this test has 70 questions split 22 / 4 / 13 / 23 / 8, in 120 minutes.
  6. NCP-AII certification page for more details.

Domain 1: Systems and Server Bring-Up (31%)

Which order best describes bringing up a new GPU cluster?

⬜ Install the operating system and Slurm first, run multi-node NCCL burn-in to find weak nodes, then rack, cable and update firmware only on nodes that passed
⬜ Rack and cable, configure BMC/OOB, update firmware, install the OS and control plane, then single-node tests, multi-node tests and burn-in
⬜ Run NCCL burn-in first, then update firmware, then configure the BMC and finally cable the network fabric
⬜ Install workloads straight away and only validate hardware if users report slow training jobs

Why is a dedicated out-of-band (OOB) management network used in AI clusters?

⬜ To carry GPU-to-GPU training traffic at the highest available bandwidth between nodes
⬜ To store training datasets close to the compute nodes for faster reads
⬜ To replace the InfiniBand compute fabric in smaller deployments
⬜ To reach BMCs and switch management ports even when the host OS is down

In a DGX SuperPOD-style design, which network carries the east-west traffic between GPUs during distributed training?

⬜ The compute fabric, typically rail-optimized InfiniBand
⬜ The in-band management Ethernet network used for provisioning and SSH
⬜ The out-of-band BMC network
⬜ The storage network used only for checkpoints

What is the main benefit of a rail-optimized compute fabric?

⬜ It removes the need for any spine switches in the fabric
⬜ It lets every GPU connect directly to the storage system
⬜ GPUs with the same index on different nodes reach each other through one leaf switch, cutting hops for collectives
⬜ It allows passive copper cables to be used for every link in the data center, regardless of the distance between racks

During initial setup, an administrator needs to give a server’s BMC a static IP address from the host’s command line. Which tool is commonly used?

⬜ nvidia-smi -pm
⬜ ipmitool lan set
⬜ mlxconfig set
⬜ dcgmi config

What is the role of the TPM during server bring-up?

⬜ It accelerates matrix multiplication for AI training
⬜ It manages fan speeds automatically based on GPU and CPU temperature readings
⬜ It balances power draw between redundant supplies
⬜ It stores keys and measurements that support secure and measured boot

Which tool does NVIDIA’s DGX H100 firmware guide use to compare installed and available firmware and to update components through the BMC?

⬜ nvfwupd
⬜ mlxlink
⬜ ibdiagnet
⬜ nvidia-ctk

According to the DGX H100 firmware update procedure, what must be done after the BIOS and BMC updates are committed?

⬜ Nothing further; the new BIOS and BMC firmware become active immediately after the commit
⬜ Reinstall the operating system
⬜ A full AC power cycle, with all power supplies unplugged for several minutes
⬜ Replace the TPM module

In the DGX H100 firmware guide, which tool updates the ConnectX-7 network adapter firmware?

⬜ nvfwupd update_fw with the HGX_0 target
⬜ mlxfwmanager
⬜ nvidia-smi –gpu-reset
⬜ ipmitool chassis power cycle

What is Power Usage Effectiveness (PUE)?

⬜ GPU power draw divided by GPU utilization
⬜ The percentage of power supplies that are redundant
⬜ IT equipment power divided by cooling power
⬜ Total facility power divided by the power delivered to IT equipment

Before running workloads on a newly installed GPU server, which check validates power and cooling?

⬜ Check GPU temperatures, power draw and fan speeds under load against specifications
⬜ Confirm the OS hostname matches the DNS record
⬜ Run docker images on the node to list the containers available for the first workloads
⬜ Check that every user has an account on the node

After installing a GPU server, which command quickly confirms that the OS sees every GPU?

⬜ ibstat
⬜ sinfo -N
⬜ nvidia-smi -L
⬜ lspci -t

Which command shows how GPUs and NICs connect to each other (NVLink, PCIe switch, CPU socket) on a server?

⬜ nvidia-smi -q -d ECC
⬜ nvidia-smi topo -m
⬜ ibv_devinfo
⬜ nvsm show health

Which cable type suits a short in-rack link of about 2 meters between a server NIC and its leaf switch?

⬜ Single-mode fiber with long-reach transceivers
⬜ An active optical cable rated for 100 meters
⬜ Category 6 Ethernet cable
⬜ A passive direct-attach copper (DAC) cable

Why must the cables and transceivers in a fabric be validated against NVIDIA’s supported list?

⬜ Unqualified parts can cause link errors or failures that are hard to diagnose
⬜ Unsupported cables and transceivers are always physically incompatible with NVIDIA switch ports
⬜ Validation is only needed for warranty paperwork
⬜ Supported cables are required only on storage networks

Before physically installing a GPU in a server, what should the technician do?

⬜ Leave the server running so the GPU is detected immediately
⬜ Remove the BMC battery to reset its settings
⬜ Power down, disconnect AC power and use ESD protection
⬜ Update the GPU firmware while the card is still in its packaging

After hardware installation, which tool provides a quick health summary of a DGX system’s components?

⬜ nvidia-ctk runtime configure
⬜ nvsm show health
⬜ srun hostname
⬜ ngc config set

Which simple container test confirms a server’s GPUs work end to end with Docker?

⬜ docker run –rm ubuntu ls /dev
⬜ docker ps -a
⬜ docker network ls
⬜ docker run –rm –gpus all ubuntu nvidia-smi

When connecting third-party NFS storage to an AI cluster, which setting commonly improves throughput?

⬜ Using multiple TCP connections per mount (nconnect) and jumbo frames
⬜ Mounting the share read-only on the head node only
⬜ Disabling all client-side caching and reducing the MTU to 576 to avoid packet fragmentation
⬜ Placing storage traffic on the BMC network

Which command shows the link state and rate of InfiniBand ports on a host?

⬜ nvidia-smi -L
⬜ dcgmi discovery -l
⬜ ibstat
⬜ sinfo

On an HGX system with NVSwitch, which service must be running for multi-GPU NVLink communication on A100-generation systems?

⬜ nvidia-persistenced only
⬜ nvidia-fabricmanager
⬜ slurmd
⬜ cmd (CMDaemon)

Which hardware-level check confirms a server can sustain real AI workloads before handing it to users?

⬜ Checking that the login banner displays correctly
⬜ Pinging the node’s management IP address from the head node and checking the reply time
⬜ Confirming that the node appears in DNS
⬜ Running DCGM diagnostics and a short HPL or NCCL test on the node

Domain 2: Physical Layer Management (5%)

What is the default mode of operation for a BlueField DPU?

⬜ DPU mode, where the Arm subsystem controls the NIC resources and data path
⬜ NIC mode
⬜ Separated host mode
⬜ Zero-trust mode

Which mlxconfig setting switches a BlueField-3 to NIC mode?

⬜ INTERNAL_CPU_MODEL=0
⬜ LINK_TYPE_P1=1
⬜ INTERNAL_CPU_OFFLOAD_ENGINE=1
⬜ SRIOV_EN=0

An administrator wants to give seven researchers isolated GPU slices on one H100 80GB. Which MIG profile fits?

⬜ Two 4g.40gb instances
⬜ Seven 1g.10gb instances
⬜ One 7g.80gb instance
⬜ Eight 1g.10gb instances

After enabling MIG mode, what is required before users can run workloads on MIG slices?

⬜ Nothing further; the GPU automatically splits into seven equal slices when MIG mode is on
⬜ Reinstalling the NVIDIA driver
⬜ Disabling ECC on the GPU
⬜ Creating GPU instances and compute instances with nvidia-smi mig

Domain 3: Control Plane Installation and Configuration (19%)

What does high availability (HA) for Base Command Manager provide?

⬜ A second head node that takes over cluster management if the active one fails
⬜ Two compute nodes that share one GPU
⬜ Automatic replacement of failed GPUs
⬜ Duplicate copies of every running training job, so a job keeps running if one compute node fails

In BCM, what does assigning nodes to a category achieve?

⬜ Each node in the category is given its own unique software image and independent settings
⬜ It moves nodes to another cluster
⬜ Nodes in the category share settings such as the software image and roles
⬜ It reserves the nodes for one user

What does Pyxis add to a Slurm cluster?

⬜ A web portal where users can submit and monitor jobs without writing any Slurm batch scripts
⬜ Container support in srun and sbatch through Enroot, for example –container-image
⬜ GPU firmware updates
⬜ InfiniBand subnet management

What does Enroot do?

⬜ It schedules jobs across GPU nodes
⬜ It monitors GPU temperatures
⬜ It provisions operating systems onto bare-metal compute nodes over PXE during cluster installation
⬜ It turns container images into unprivileged sandboxes that HPC users can run

With Pyxis installed, which command runs a job inside an NGC PyTorch container on Slurm?

⬜ srun –container-image=nvcr.io#nvidia/pytorch:24.10-py3 python train.py
⬜ srun –gres=gpu:8 docker run –rm –gpus all nvcr.io/nvidia/pytorch:24.10-py3 python train.py
⬜ sbatch –image pytorch train.py
⬜ enroot start –slurm train.py

Which package installs the NVIDIA networking drivers and tools on hosts, replacing MLNX_OFED?

⬜ The CUDA Toolkit
⬜ The NVIDIA Container Toolkit
⬜ DOCA-Host
⬜ NVSM

Before upgrading the NVIDIA GPU driver on a node, what should the administrator do?

⬜ Upgrade the driver while training jobs keep running, then reboot the node once the jobs finish
⬜ Drain the node and stop GPU processes and services such as DCGM and Fabric Manager
⬜ Uninstall Docker permanently
⬜ Disable the BMC network

After installing the NVIDIA Container Toolkit, which command configures Docker to use it?

⬜ nvidia-smi –docker
⬜ systemctl enable nvidia-fabricmanager
⬜ ngc config set
⬜ sudo nvidia-ctk runtime configure –runtime=docker

Which Docker option gives a container access to only GPUs 0 and 1?

⬜ –gpus ‘“device=0,1”’
⬜ –gpus 2
⬜ –device=/dev/nvidia*
⬜ –runtime=runc

How is the NGC CLI configured with an API key on a host?

⬜ docker login nvcr.io
⬜ nvidia-ctk config
⬜ ngc config set
⬜ export NGC=1

What is the purpose of the NVIDIA Container Toolkit’s sample workload test?

⬜ To benchmark FP64 performance of the cluster
⬜ To confirm that a container can see the GPUs, by running nvidia-smi inside it
⬜ To update GPU firmware through the container
⬜ To configure InfiniBand partitions

In BCM, how are network interfaces for nodes in the cluster typically defined?

⬜ By editing each node’s network files by hand over SSH after it has been provisioned
⬜ Through the GPU driver’s configuration file
⬜ In the Slurm job script
⬜ In BCM’s node or category configuration, so provisioning sets them up

Which BCM-managed workload manager is used with Pyxis and Enroot in a typical DGX SuperPOD?

⬜ Slurm
⬜ Apache Airflow
⬜ Jenkins
⬜ cron

Domain 4: Cluster Test and Verification (33%)

What does High-Performance Linpack (HPL) measure?

⬜ Network latency between two hosts
⬜ Storage read throughput
⬜ Sustained double-precision floating-point performance by solving a dense linear system
⬜ Token generation speed of an LLM

Where do administrators typically get an optimized HPL build for NVIDIA GPUs?

⬜ By compiling HPL from source with default CPU settings
⬜ The NVIDIA HPC-Benchmarks container from NGC
⬜ The NVIDIA driver package
⬜ The DOCA-Host package

A single-node NCCL test on an 8-GPU HGX system shows much lower bus bandwidth than expected. What does this most likely point to?

⬜ A problem with the InfiniBand fabric between racks, such as a faulty spine switch or uplink cable
⬜ Slow storage
⬜ A DNS misconfiguration
⬜ An NVLink or NVSwitch problem inside the node, such as Fabric Manager or a degraded link

Which NCCL test is most commonly run to measure collective bandwidth?

⬜ all_reduce_perf
⬜ ib_write_lat
⬜ gdsio
⬜ stream

Which environment variable makes NCCL print which transports (NVLink, InfiniBand) it is using?

⬜ CUDA_VISIBLE_DEVICES=0
⬜ OMP_NUM_THREADS=1
⬜ NCCL_DEBUG=INFO
⬜ NCCL_IB_DISABLE=1

Which tool measures RDMA bandwidth between two hosts over InfiniBand?

⬜ nvidia-smi
⬜ ib_write_bw
⬜ fio
⬜ dcgmi diag

Which utility checks a link’s signal quality, including bit error rate and eye opening, on NVIDIA network adapters and switches?

⬜ nvfwupd
⬜ ngc
⬜ nvidia-ctk
⬜ mlxlink

A cable shows a rising number of symbol errors and occasional link-down events. What is the most likely conclusion?

⬜ The cable or transceiver is marginal and should be reseated or replaced
⬜ The GPU driver is outdated and needs upgrading to the latest production branch release
⬜ Slurm is misconfigured
⬜ The storage system is full

How can an administrator confirm that cables are connected to the intended switch ports across an InfiniBand fabric?

⬜ Ping each node’s hostname
⬜ Run nvidia-smi on each node
⬜ Compare the discovered fabric topology (for example from ibdiagnet or iblinkinfo) against the cabling plan
⬜ Check the BMC event log

Why should switch and BlueField-3 firmware and software versions be confirmed during validation?

⬜ Different versions never affect performance
⬜ Mismatched or outdated versions can cause instability, missing features or incompatibility
⬜ Only the GPU firmware matters in AI clusters, because network devices are validated by the vendor at the factory
⬜ Versions are checked only for licensing

Which tool queries and updates firmware on NVIDIA ConnectX adapters?

⬜ nvidia-smi
⬜ ipmitool
⬜ nvsm
⬜ mlxfwmanager

What is ClusterKit?

⬜ A multifaceted node assessment tool that tests latency, bandwidth, memory and GPU performance across a cluster
⬜ A Slurm plugin for containers
⬜ A GPU firmware update utility
⬜ A Kubernetes operator for storage

Why run ClusterKit before multi-node burn-in?

⬜ It replaces the need for any burn-in
⬜ It updates the firmware on every switch, NIC and GPU in the cluster automatically before testing starts
⬜ It quickly finds outlier nodes or links with poor latency, bandwidth or GPU performance
⬜ It installs Slurm on every node

A multi-node all_reduce_perf run reports low bus bandwidth only when certain nodes take part. What is the best next step?

⬜ Increase the batch size of the training job
⬜ Test smaller groups of nodes to isolate the slow node or link, then check its NICs and cables
⬜ Reinstall the operating system on every node
⬜ Ignore it, because NCCL automatically routes around slow links and averages out their effect on bandwidth

What is the purpose of burn-in testing with NCCL, HPL or NeMo on a new cluster?

⬜ To measure the cluster’s peak performance once, so the result can be published for marketing and benchmarking
⬜ To install the operating system on the nodes
⬜ To verify DNS records
⬜ To run sustained heavy load for hours or days and expose early-life hardware failures

Why include a NeMo training run in burn-in, in addition to HPL and NCCL?

⬜ It exercises the cluster with a realistic LLM training workload, combining compute, communication and I/O
⬜ NeMo is the only tool that can test storage, because HPL and NCCL never read from or write to the file system at all
⬜ It updates the GPU drivers
⬜ It replaces DCGM diagnostics

During HPL burn-in, one node’s performance drops over time while others stay steady. What should be investigated first?

⬜ The HPL source code
⬜ The Slurm partition name
⬜ Thermal throttling or power issues on that node, using nvidia-smi or DCGM clock and temperature data
⬜ The DNS server

Which nvidia-smi query shows why a GPU is running below its maximum clocks?

⬜ nvidia-smi -L
⬜ nvidia-smi -q -d PERFORMANCE
⬜ nvidia-smi topo -m
⬜ nvidia-smi mig -lgi

Which tool benchmarks storage throughput into GPU memory with GPUDirect Storage?

⬜ ib_write_bw
⬜ all_reduce_perf
⬜ nvsm show health
⬜ gdsio

Which general-purpose tool is commonly used to test the storage performance of an AI cluster through the normal CPU path?

⬜ fio
⬜ nvidia-smi
⬜ ibstat
⬜ mlxconfig

Which DCGM diagnostic level is appropriate for a thorough single-node stress test including NCCL and power tests?

⬜ dcgmi diag -r 1
⬜ dcgmi diag -r 2
⬜ dcgmi diag -r 3
⬜ dcgmi discovery -l

Which command shows the NVLink status of each GPU’s links?

⬜ ibstat
⬜ nvidia-smi nvlink –status
⬜ mlxlink -d mlx5_0
⬜ dcgmi discovery -l

What does the bus bandwidth (busbw) value in NCCL test output represent?

⬜ The raw size of the message divided by the time taken to complete the collective
⬜ The PCIe generation of the GPU
⬜ The storage bandwidth of the cluster
⬜ A normalized bandwidth comparable to the hardware’s peak link speed

Domain 5: Troubleshooting and Optimization (12%)

dmesg on a GPU node shows ‘NVRM: Xid 79, GPU has fallen off the bus’. What does this indicate?

⬜ The GPU stopped responding on PCIe, pointing to a hardware, power or thermal problem
⬜ A harmless informational driver message that appears during normal GPU operation and can be ignored
⬜ The NCCL version is outdated
⬜ The Slurm controller restarted

An A100 or H100 GPU reports a pending row remap after memory errors. What should be done?

⬜ Nothing; remapping happens instantly in the background without any reset or administrator action
⬜ Replace the GPU immediately
⬜ Reset the GPU (or reboot) so the pending row remapping takes effect
⬜ Disable ECC

Which command collects a comprehensive log bundle to send to NVIDIA support for a GPU issue?

⬜ nvidia-smi -L
⬜ nvidia-bug-report.sh
⬜ docker logs
⬜ sinfo -R

NVSM reports a failed power supply on a DGX system that keeps running. What is the correct action?

⬜ Ignore it, because the system is still running on the remaining power supplies and no workloads have failed
⬜ Replace all power supplies at once
⬜ Reinstall DGX OS
⬜ Replace the failed unit following the service manual, since redundancy is reduced until then

Before replacing a suspected faulty GPU, how should it be identified reliably?

⬜ By the GPU serial number and PCIe bus ID reported by nvidia-smi or NVSM
⬜ By the server’s position in the rack, since that is enough to know which GPU card to pull
⬜ By guessing from fan noise
⬜ By the order of Slurm job IDs

On an AMD EPYC GPU server, which BIOS or OS setting commonly improves AI workload performance?

⬜ Enabling the powersave CPU frequency governor so the CPUs leave more of the power budget to the GPUs
⬜ Disabling all PCIe devices not used at boot
⬜ Using a performance power profile and keeping processes NUMA-local to their GPUs and NICs
⬜ Lowering memory speed to reduce heat

Why is CPU and NUMA affinity important for GPU workloads on dual-socket Intel or AMD servers?

⬜ GPUs run faster when every process is pinned to socket 0, because that socket controls all PCIe lanes
⬜ Data crossing between sockets adds latency and reduces bandwidth to the GPU and NIC
⬜ NUMA affects only storage performance
⬜ Affinity matters only for single-GPU servers

Training jobs on a cluster wait on data loading, and gdsio shows GDS is falling back to compatibility mode. What should be checked?

⬜ The Slurm partition time limit
⬜ The NCCL version installed in the training container, since NCCL handles data loading
⬜ The BMC firmware version
⬜ That the file system and drivers support GDS, using gdscheck -p
