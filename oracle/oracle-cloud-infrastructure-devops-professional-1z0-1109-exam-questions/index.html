Free Oracle Cloud Infrastructure DevOps Professional (1Z0-1109-26) Online Practice Exam

Overview

  1. Passing 1Z0-1109-26 earns the Oracle Cloud Infrastructure Certified DevOps Professional credential, for DevOps engineers and developers who automate build, test and release on OCI.
  2. The exam has 50 multiple-choice questions in 90 minutes, and the passing score is 68%.
  3. Its six topic areas are weighted 15%, 10%, 30%, 30%, 10% and 5%, so this test has 50 questions split 8 / 5 / 15 / 15 / 5 / 2, with 4 choose-two questions.
  4. CI/CD with the OCI DevOps service and Kubernetes Engine (OKE) carry 60% of the exam, followed by containerization, infrastructure as code with Resource Manager and Terraform, DevSecOps and monitoring.
  5. Official exam page and topics for more details.

Domain 1: Understand DevOps Principles and Containerization Services (15%)

Which outcome is the main goal of a CI/CD pipeline?

⬜ Releasing software only once a year after a long code freeze and manual testing
⬜ Frequent, reliable releases with fewer change-driven errors
⬜ Removing all automated tests to ship faster
⬜ Letting each developer deploy by hand from a laptop

A large monolith is hard to change because every small fix needs a full redeploy. Which architecture lets teams release parts independently?

⬜ A bigger single server for the monolith
⬜ One shared database schema for all features
⬜ Microservices, each deployable on its own
⬜ Nightly manual builds of the whole application

Why package an application as a container image?

⬜ So it runs the same way in every environment
⬜ So it can only run on one specific server
⬜ So it never needs security patches
⬜ So it can’t read any configuration from environment variables at run time

A build server must push images to OCI Container Registry without anyone typing a Console password. Which credential should its docker login use?

⬜ The tenancy administrator’s Console password
⬜ An API signing key fingerprint from the user’s profile
⬜ The repository’s OCID
⬜ An auth token for the user

Old, unused images keep piling up in an OCIR repository. How can they be removed automatically?

⬜ An image retention policy
⬜ A Kubernetes CronJob in every cluster
⬜ A lifecycle policy on an Object Storage bucket
⬜ Deleting the whole repository monthly

A team must run a single containerized job without managing servers or a Kubernetes cluster. Which OCI service fits?

⬜ An OKE cluster with managed nodes
⬜ A bare metal compute instance
⬜ Resource Manager
⬜ OCI Container Instances

Which statement about Container Instances is true?

⬜ They require you to create a Kubernetes cluster first
⬜ They can only run one container per instance
⬜ They share a kernel with other customers’ containers
⬜ They provide the same isolation as virtual machines

Which two should be stored in OCI Artifact Registry rather than Container Registry? (Choose two.)

⬜ Docker images for an OKE deployment
⬜ A generic .zip application package
⬜ A versioned configuration file for an instance group deployment
⬜ Container images built by a Managed Build stage

Domain 2: Using Code and Templates for Provisioning and Configuring Infrastructure (10%)

What does an OCI Resource Manager stack represent?

⬜ A single compute instance
⬜ The OCI resources for one Terraform configuration
⬜ A Git branch in a code repository that holds the Terraform files
⬜ A log group for a project

Before an apply, a team wants to review exactly which resources Terraform will create, change or destroy. Which Resource Manager job do they run?

⬜ Apply
⬜ Destroy
⬜ Plan
⬜ Import state

Someone added a tag to a production VCN in the Console, outside Terraform. What can Resource Manager run to find this difference?

⬜ A drift detection report
⬜ A destroy job
⬜ A new private template
⬜ Resource discovery for another region

A compartment was built by hand in the Console. The team now wants it managed with Terraform. Which Resource Manager feature gives a starting configuration and state?

⬜ Drift detection
⬜ A plan job
⬜ A configuration source provider
⬜ Resource discovery

Two engineers start apply jobs on the same Resource Manager stack at the same moment. What happens?

⬜ Both run in parallel and merge their state
⬜ The second job silently overwrites the first
⬜ Only one job at a time can run on a stack
⬜ The stack is deleted to avoid conflicts

Domain 3: Configuring and Managing Continuous Integration and Continuous Delivery (CI/CD) (30%)

Which OCI DevOps resource groups code repositories, build pipelines, deployment pipelines, artifacts and environments?

⬜ A compartment
⬜ A DevOps project
⬜ A Resource Manager stack
⬜ A log group

Where does a Managed Build stage look for its build specification by default?

⬜ In an Object Storage bucket named after the build pipeline
⬜ In the project’s settings page
⬜ build_spec.yaml in the root of the primary build source
⬜ In the Vault secret for the pipeline

A build step needs an API key stored as a secret in OCI, without putting the value in the repository. Where should it be referenced?

⬜ In env.vaultVariables with the secret’s OCID
⬜ In env.variables, with the plaintext value of the key
⬜ In the commit message
⬜ In outputArtifacts

Which stage must come before a Deliver Artifacts stage in a build pipeline?

⬜ A Wait stage
⬜ A Trigger Deployment stage
⬜ No stage; it can be first
⬜ A Managed Build stage

Which two are predefined stages in an OCI DevOps build pipeline? (Choose two.)

⬜ Managed Build
⬜ Traffic Shift
⬜ Trigger Deployment
⬜ Manual Approval

Builds should start automatically when developers push to the main branch, but not when they only change docs files. What should be configured?

⬜ A Wait stage at the start of the build
⬜ A manual approval stage
⬜ A cron job on a compute instance
⬜ A push trigger with file exclusions

A team’s source code lives in GitHub, but it wants a copy in an OCI DevOps code repository kept in sync. What’s required first?

⬜ Converting the GitHub repository into a Resource Manager stack first
⬜ A connection using a GitHub PAT stored in an OCI vault
⬜ Making the GitHub repo public
⬜ Copying the files by hand each week

Which target environments does OCI DevOps support for deployments?

⬜ Only OKE clusters
⬜ Only Functions
⬜ OKE clusters, compute instance groups and Functions
⬜ Any on-premises VMware cluster connected through FastConnect

A Kubernetes manifest artifact uses ${imageTag}, and each run must deploy a different tag. What makes this work?

⬜ Editing the manifest by hand in the code repository before every pipeline run
⬜ A Wait stage
⬜ A pipeline parameter, with Allow parameterization enabled on the artifact
⬜ A separate artifact for every tag

A parameter has a default value of v1, and a run is started with the argument v2. Which value is used?

⬜ v2, because the argument takes precedence
⬜ v1, because the default set on the pipeline always wins
⬜ Both, joined together
⬜ Neither; the run fails

With a blue-green deployment to OKE, what must be set up to route traffic between the environments?

⬜ A second OCI region
⬜ A Resource Manager stack
⬜ A Traffic Shift stage alone with no ingress
⬜ An NGINX ingress controller

In a canary deployment pipeline, which stage sends part of the production traffic to the new version?

⬜ Invoke Function
⬜ Shift traffic
⬜ Wait
⬜ Deliver Artifacts

A deployment pipeline has Automatic Rollback enabled, and the deployment stage fails validation. What happens?

⬜ The last successful release version is deployed
⬜ The pipeline waits indefinitely for an operator to fix the failed stage
⬜ The cluster is deleted
⬜ The failed version stays live

Production deployments need sign-off from two release managers. Which feature fits?

⬜ A Wait stage of two hours
⬜ A Shell stage that emails both managers a summary
⬜ A trigger on the main branch
⬜ An Approval stage requiring two approvals

A deployment needs to run OCI CLI commands, such as updating a service mesh, as a pipeline step. Which stage fits?

⬜ Traffic Shift
⬜ Approval
⬜ Shell
⬜ Wait

Domain 4: Managing Containers using Container Orchestration Engine (30%)

Who manages the control plane nodes of an OKE cluster?

⬜ You, on compute instances that you patch in your own tenancy
⬜ Oracle, across availability domains for high availability
⬜ Nobody; OKE has no control plane
⬜ The DevOps service

Which two features need an OKE enhanced cluster rather than a basic cluster? (Choose two.)

⬜ Virtual nodes
⬜ Managed nodes
⬜ Workload identity
⬜ Kubernetes Services of type LoadBalancer

Which statement about OKE virtual nodes is true?

⬜ They’re fully managed by Oracle
⬜ You patch their operating system yourself
⬜ They run on bare metal instances in your tenancy
⬜ They work in basic clusters

Pods in an OKE application need to read objects from Object Storage without storing API keys. What should be used?

⬜ A user’s API key in a ConfigMap
⬜ Workload identity with an IAM policy for the service account
⬜ Root user credentials passed to the pods in an environment variable
⬜ A public bucket

Pods must get IP addresses from the VCN so that they’re directly routable. Which CNI option fits, and can it be changed later?

⬜ Flannel overlay; you can switch to another plugin at any time later
⬜ Calico only; set per node pool
⬜ Host networking for every pod
⬜ VCN-Native Pod Networking; fixed after cluster creation

How do you upgrade the Kubernetes version of an OKE cluster’s control plane?

⬜ SSH to each control plane node and run a kubeadm upgrade there
⬜ Delete and recreate the cluster
⬜ Upgrade the cluster to a newer Kubernetes version
⬜ Upgrade only the node pools

A team wants to upgrade worker nodes by creating a new node pool on the newer version and moving workloads to it. What is this called?

⬜ Out-of-place upgrade
⬜ In-place upgrade
⬜ Control plane upgrade
⬜ Drift remediation

A deployment’s pods should scale out when CPU use rises. What should be configured?

⬜ The Cluster Autoscaler only
⬜ A bigger node shape
⬜ The Horizontal Pod Autoscaler
⬜ A Resource Manager drift report

During a traffic surge, the Horizontal Pod Autoscaler adds pods, but many can’t be scheduled because the nodes are full. What adds node capacity automatically?

⬜ The Kubernetes Cluster Autoscaler
⬜ A second Horizontal Pod Autoscaler on the same deployment
⬜ A ConfigMap
⬜ A traffic shift stage

A stateful application on OKE needs durable storage that survives pod restarts. What should it use?

⬜ The container’s own root file system inside the image
⬜ An emptyDir volume
⬜ A persistent volume claim on Block Volume or File Storage
⬜ A ConfigMap

Only images signed with the company’s key may run in a production OKE cluster. What should be configured?

⬜ A Traffic Shift stage
⬜ An OCIR retention policy on the production repository
⬜ A public repository
⬜ An image verification policy for the cluster

Kubernetes secrets in etcd must be encrypted with a key the company controls. What should be done?

⬜ Base64-encode the secrets
⬜ Use a Vault master encryption key for secrets
⬜ Store the secrets in ConfigMaps instead, so they’re easy to audit
⬜ Disable etcd

What determines the default set of admission controllers in an OKE cluster?

⬜ The node pool shape
⬜ The Kubernetes version chosen for the cluster
⬜ The DevOps project
⬜ The number of availability domains in the region you choose

A Helm stage deploys a chart to OKE, but nothing redeploys because neither the chart nor the stage parameters changed. How can the team force the deployment?

⬜ Delete the cluster and create it again
⬜ Add a Wait stage before the Helm stage
⬜ Move the chart to Artifact Registry and change nothing else in the pipeline
⬜ Set the ENFORCE_HELM_DEPLOYMENT parameter to true

Several HTTP services in one OKE cluster should share a single entry point with routing by host and path. What is commonly set up?

⬜ An ingress controller, such as NGINX, with Ingress rules
⬜ One Service of type LoadBalancer for every pod in every service
⬜ A Resource Manager stack per service
⬜ A separate cluster for every service

Domain 5: Enabling DevSecOps (10%)

A security team wants each image in OCIR checked for known CVEs. What should be enabled?

⬜ Image scanning on the repository
⬜ An image retention policy on the repository
⬜ A Wait stage
⬜ Drift detection

How do signed images in OCIR help security?

⬜ They make images smaller
⬜ They remove the need for scanning
⬜ They verify an image’s source and integrity
⬜ They hide the image from everyone except the person who pushed it

Build and deployment pipelines need permission to read code and manage resources. What is the recommended setup?

⬜ Run every pipeline with an administrator’s personal API key and passphrase
⬜ A dynamic group for DevOps resources, with least-privilege policies
⬜ Give the pipeline the root user’s password
⬜ Grant manage all-resources in the tenancy

Which statement about master encryption keys in OCI Vault is true?

⬜ They can only be software-protected
⬜ They are stored in plaintext in Object Storage
⬜ They can’t be rotated
⬜ They can be protected by an HSM and rotated

Which two practices improve security in an OCI DevOps CI/CD pipeline? (Choose two.)

⬜ Reading credentials from vault secrets at build time
⬜ Committing API keys to the repository for convenience
⬜ Requiring approval before production deployments
⬜ Giving every pipeline tenancy-wide admin rights

Domain 6: Implementing Monitoring and Observability (5%)

An engineer wants an email when a deployment fails in OCI DevOps. Which services fit together?

⬜ Resource Manager stacks and their drift detection reports
⬜ Events rules with a Notifications topic
⬜ OCIR retention policies
⬜ Container Instances

Build run output isn’t showing up in OCI Logging for a DevOps project. What’s the likely reason?

⬜ DevOps can’t send logs anywhere
⬜ Logs are only available in Resource Manager job output
⬜ Logging hasn’t been enabled for the project
⬜ The build spec is in YAML
