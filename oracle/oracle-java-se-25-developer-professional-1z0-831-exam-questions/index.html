What does this switch expression print when day is “SAT”?

⬜ weekend
⬜ weekday
⬜ weekendweekday
⬜ It doesn’t compile, because yield needs a label

⬜ bd
⬜ abcd

Why doesn’t this compile?

    return switch (o) {
        case Number n -> "number";

        default -> "other";

⬜ A default case isn’t allowed in a switch that uses type patterns
⬜ case Integer i is dominated by case Number n
⬜ Pattern variables can’t be unused
