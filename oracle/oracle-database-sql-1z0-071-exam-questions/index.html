Free Oracle Database SQL (1Z0-071) Online Practice Exam

Overview

  1. Passing 1Z0-071 earns the Oracle Database SQL Certified Associate credential, which shows a working knowledge of SQL queries, DML, DDL, DCL and data modeling on Oracle Database.
  2. The exam has 63 multiple-choice questions in 120 minutes, delivered as a proctored online exam, and the passing score is 63%.
  3. It has sixteen topics, from relational concepts and SELECT basics through functions, joins, subqueries, set operators, DML and transactions, DDL and constraints, views, privileges, the data dictionary and time zones.
  4. Oracle doesn’t publish topic weights, so this test spreads its 63 questions by how many objectives each topic has, split 3 / 4 / 4 / 5 / 5 / 5 / 6 / 4 / 4 / 6 / 3 / 6 / 2 / 3 / 1 / 2, with 6 choose-two questions.
  5. Official exam page and topics for more details.
