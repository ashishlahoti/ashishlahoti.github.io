Domain 1: Declaring PL/SQL Variables

Which two are valid unquoted PL/SQL identifiers? (Choose two.)

⬜ v_total$
⬜ 2nd_total
⬜ emp#count
⬜ total-amount
⬜ begin

What is the value of v_count right after this declaration?
DECLARE
  v_count NUMBER;
BEGIN
  ...

⬜ 0
⬜ NULL
⬜ 1
⬜ The declaration fails without a value

Why declare v_sal employees.salary%TYPE rather than NUMBER(8,2)?

⬜ %TYPE makes the variable a constant
⬜ %TYPE always gives better performance
⬜ It uses the column’s type, so code adapts when it changes
⬜ %TYPE copies the column’s current value into the variable at run time

Domain 2: Writing Executable Statements

Which two are lexical units of PL/SQL? (Choose two.)

⬜ Delimiters, such as := and ;
⬜ Tablespaces
⬜ Literals, such as ‘ABC’ and 42
⬜ Cursors
⬜ Packages

Which assignment is invalid in a PL/SQL procedural statement?

⬜ v_len := LENGTH(v_name);
⬜ v_id := emp_seq.NEXTVAL;
⬜ v_up := UPPER(v_name);
⬜ v_max := MAX(v_sal);

v_text is VARCHAR2 and holds ‘42’. What happens with v_num := v_text + 1 when v_num is NUMBER?

⬜ It fails to compile because the two data types differ
⬜ v_num becomes ‘421’
⬜ ‘42’ is converted to a number, so v_num is 43
⬜ v_num becomes NULL

An inner block declares v_x, hiding the outer block’s v_x. The outer block is labeled outer. How does the inner block read the outer v_x?

⬜ PARENT.v_x
⬜ outer.v_x
⬜ v_x@outer
⬜ It can’t; the outer variable is out of scope

Which comment styles does PL/SQL support?

⬜ Only – single-line comments
⬜ Only /* / multi-line comments
⬜ # comments to the end of the line, like shell scripts
⬜ – for single-line and / */ for multi-line comments

⬜ The variables are set to NULL and processing continues
⬜ NO_DATA_FOUND is raised

⬜ Read the cursor’s %ISOPEN attribute

⬜ COMMIT can’t be used inside PL/SQL
⬜ A PL/SQL block always commits when it ends
⬜ COMMIT ends the whole transaction, including earlier changes

Domain 4: Writing Control Structures

A CASE statement has no ELSE clause and no WHEN matches. What happens?

⬜ Nothing; execution continues after END CASE
⬜ The CASE statement returns NULL
⬜ The first WHEN branch runs
⬜ CASE_NOT_FOUND is raised

What does this loop print?
FOR i IN 1..5 LOOP
  CONTINUE WHEN MOD(i, 2) = 0;
  DBMS_OUTPUT.PUT_LINE(i);
END LOOP;

⬜ 1 2 3 4 5
⬜ 2 4
⬜ 1 3 5
⬜ 1

Which statement about a numeric FOR loop index is true?

⬜ It must be declared in the DECLARE section
⬜ It’s declared implicitly and can’t be assigned
⬜ It keeps its last value after the loop ends for later use
⬜ It can be any data type

Which loop runs its body at least once?

⬜ A basic LOOP with EXIT WHEN at the end
⬜ A WHILE loop whose condition starts FALSE
⬜ FOR i IN 5..1 LOOP
⬜ A cursor FOR loop on an empty query

Which collection type is sparse, can be indexed by VARCHAR2, and needs no constructor?

⬜ Nested table of VARCHAR2

What happens when you call EXTEND on a nested table variable that was declared but never initialized?

⬜ One NULL element is added
⬜ COLLECTION_IS_NULL is raised
⬜ The collection is created automatically
⬜ SUBSCRIPT_BEYOND_COUNT is raised

Which declaration creates a record matching every column of DEPARTMENTS?

⬜ v_dept departments%TYPE;
⬜ v_dept RECORD OF departments;
⬜ v_dept TABLE OF departments;
⬜ v_dept departments%ROWTYPE;

An associative array has elements at indexes 1, 5 and 9. What does FOR i IN arr.FIRST..arr.LAST do when it reads arr(i)?

⬜ It reads three elements
⬜ It reads indexes 1, 5 and 9 only
⬜ It raises NO_DATA_FOUND at index 2
⬜ It returns NULL for missing elements

Which two statements about records and collections are true? (Choose two.)

⬜ A record’s fields can have different data types
⬜ A collection’s elements can have different data types
⬜ A collection can hold records as its elements
⬜ A record can’t contain a collection field
⬜ Records must be created with CREATE TYPE

What happens when you FETCH from an explicit cursor that hasn’t been opened?

⬜ The cursor is opened automatically
⬜ NO_DATA_FOUND is raised
⬜ INVALID_CURSOR is raised
⬜ The fetch returns NULLs

What does a cursor FOR loop do for you?

⬜ Locks all rows it reads
⬜ Collects all the rows into a collection in one fetch
⬜ Opens, fetches each row into a record, then closes
⬜ Runs the query once per column

Which cursor declaration takes a department ID when it’s opened?

⬜ CURSOR c_emp (p_dept NUMBER) IS SELECT * FROM employees WHERE department_id = p_dept;
⬜ CURSOR c_emp IS SELECT * FROM employees WHERE department_id = :p_dept;
⬜ CURSOR c_emp (p_dept NUMBER(4)) IS SELECT * FROM employees WHERE department_id = p_dept;
⬜ CURSOR c_emp USING p_dept IS SELECT * FROM employees;

You fetch rows and update each current row. Which two clauses do you use? (Choose two.)

⬜ WHERE CURRENT OF cursor_name in the UPDATE
⬜ WHERE ROWNUM = 1 in the UPDATE
⬜ RETURNING CURRENT in the FETCH

⬜ RAISE_APPLICATION_ERROR(-20001, ‘Bad order’);

How do you give a name to Oracle error ORA-02292 so you can handle it?

⬜ Declare it, then call RAISE_APPLICATION_ERROR with -2292
⬜ Declare an exception and use PRAGMA EXCEPTION_INIT
⬜ Use WHEN ORA_02292 THEN
⬜ Use SQLCODE in the DECLARE section

An exception is raised in an inner block that has no handler for it. What happens?

⬜ The program ends at once
⬜ The exception is ignored
⬜ It propagates to the enclosing block
⬜ The inner block restarts from its first statement

What do SQLCODE and SQLERRM return in a WHEN OTHERS handler?

⬜ The error number and its message
⬜ The line number and the procedure name
⬜ The session ID and user name
⬜ The number of rows affected

Domain 8: Using PL/SQL Subprograms

What is a key difference between an anonymous block and a stored procedure?

⬜ Only anonymous blocks can contain SQL
⬜ A stored procedure is named and stored for reuse
⬜ Anonymous blocks can take parameters
⬜ Stored procedures can’t have their own exception handlers

Which two are benefits of subprograms? (Choose two.)

⬜ Code is reusable from many applications
⬜ They remove the need for privileges
⬜ They’re easier to maintain, since logic lives in one place
⬜ They always run faster than SQL
⬜ They can’t be invalidated

How do you call procedure raise_salary from an anonymous block?

⬜ CALL BLOCK raise_salary(101);
⬜ EXECUTE raise_salary(101) inside BEGIN…END
⬜ BEGIN raise_salary(101); END;
⬜ SELECT raise_salary(101) FROM DUAL;

Which parameter mode lets the caller pass a value in and receive an updated value back?

⬜ IN
⬜ OUT
⬜ IN OUT
⬜ RETURN

Procedure p(a NUMBER, b NUMBER DEFAULT 0, c NUMBER). Which call passes only a and c?

⬜ p(1, , 3);
⬜ p(a => 1, c => 3);
⬜ p(1, 3);
⬜ p(c => 3, a => 1, b => );

Which actual parameter is invalid for an OUT parameter?

⬜ A local variable
⬜ A record field
⬜ A literal
⬜ A collection element

Where can you see the source code of procedures you own?

⬜ USER_OBJECTS.TEXT
⬜ USER_ERRORS
⬜ USER_PROCEDURES.BODY
⬜ USER_SOURCE

Which must a function have that a procedure doesn’t need?

⬜ An exception section
⬜ At least one IN parameter in its header
⬜ A RETURN clause and a RETURN statement
⬜ A DECLARE keyword

Function f updates a table and is called in a SELECT statement. What happens?

⬜ The update runs and is committed
⬜ The query fails, since it can’t change data there
⬜ The update runs only once, for the first row
⬜ The update is ignored

Which statement removes function get_tax?

⬜ DELETE FUNCTION get_tax;
⬜ ALTER FUNCTION get_tax DROP;
⬜ TRUNCATE FUNCTION get_tax;
⬜ DROP FUNCTION get_tax;

Domain 11: Creating Packages

Which part of a package can other programs reference directly?

⬜ Items in the package specification
⬜ Items declared only in the package body
⬜ The initialization section
⬜ Local variables of package subprograms

Two package procedures named log differ only in that one has a parameter of NUMBER and the other INTEGER. What happens?

⬜ It works; PL/SQL picks the closer type
⬜ The second definition silently replaces the first one
⬜ Calls are ambiguous: INTEGER is a NUMBER subtype
⬜ The package can’t have two subprograms

In a package body, procedure a calls procedure b, which is defined later in the body. What lets it compile?

⬜ Nothing; b must always come first
⬜ A forward declaration of b before a
⬜ Declaring b in the specification only
⬜ Using EXECUTE IMMEDIATE to call b

Domain 12: Working with Packages

A package variable is set in one call. What value does it have in a later call in the same session?

⬜ Its default value, because it resets after every call
⬜ The value set earlier; state lasts for the session
⬜ The value set by any other session
⬜ NULL; package variables can’t keep values

When does a package’s initialization section run?

⬜ Every time any subprogram in it is called
⬜ Once per session, on first reference
⬜ When the package is compiled
⬜ When the database starts

Helper package util must be callable only from package payroll. What do you use?

⬜ AUTHID CURRENT_USER on util
⬜ GRANT EXECUTE ON util TO payroll
⬜ ACCESSIBLE BY (PACKAGE payroll)
⬜ PRAGMA SERIALLY_REUSABLE on util

Domain 13: Using Dynamic SQL

Why does this block need dynamic SQL?
BEGIN
  CREATE TABLE tmp_log (msg VARCHAR2(100));
END;

⬜ Because the table name has an underscore
⬜ Static PL/SQL can’t run DDL statements
⬜ Because VARCHAR2 needs a length
⬜ It doesn’t; the block runs as written

Which statement runs a dynamic UPDATE safely with a value from a variable?

⬜ EXECUTE IMMEDIATE ‘UPDATE emp SET sal = ’ || v_sal || ’ WHERE id = ’ || v_id;
⬜ EXECUTE IMMEDIATE ‘UPDATE emp SET sal = :1 WHERE id = :2’ USING v_sal, v_id;
⬜ EXECUTE IMMEDIATE ‘UPDATE emp SET sal = v_sal WHERE id = v_id’;
⬜ EXECUTE IMMEDIATE ‘UPDATE emp SET sal = :1’ INTO v_sal;

What can’t be supplied as a bind variable in dynamic SQL?

⬜ A WHERE clause value
⬜ An inserted value
⬜ A table name
⬜ An updated value

Domain 14: Design Considerations for PL/SQL Code

A procedure must run with the privileges of the user who calls it. Which clause do you use?

⬜ AUTHID DEFINER
⬜ AUTHID CURRENT_USER
⬜ ACCESSIBLE BY CURRENT_USER
⬜ PRAGMA INVOKER

An error-logging procedure must save its log row even if the caller rolls back. What do you use?

⬜ A COMMIT in the caller before the error
⬜ A SAVEPOINT at the start of the logging procedure
⬜ PRAGMA AUTONOMOUS_TRANSACTION with a COMMIT
⬜ A DDL statement in the procedure

What does the NOCOPY hint ask the compiler to do?

⬜ Pass OUT and IN OUT parameters by reference
⬜ Prevent the parameter from being changed
⬜ Stop the function’s result from being cached in the SGA
⬜ Disable bulk binding

Which clause tells the optimizer a function always returns the same result for the same inputs?

⬜ PARALLEL_ENABLE
⬜ PIPELINED
⬜ DETERMINISTIC
⬜ AUTHID DEFINER

You loop over 100,000 rows and run an INSERT for each. Which change reduces context switches the most?

⬜ Commit after every insert
⬜ Use a cursor FOR loop
⬜ Use dynamic SQL for each insert
⬜ Use FORALL with a collection

How do you get the ID generated for a row by an INSERT without a second query?

⬜ SELECT MAX(id) after the insert
⬜ INSERT … RETURNING id INTO v
⬜ SQL%ROWCOUNT
⬜ CURRVAL of the table’s ID column

Domain 15: Creating Compound, DDL, and Event Database Triggers

Why use a compound trigger on a table?

⬜ To fire on both DDL and DML statements in one trigger
⬜ To share state between its timing-point sections
⬜ To fire for several tables at once
⬜ To replace constraints

Which trigger records every CREATE statement run in schema HR?

⬜ CREATE TRIGGER t AFTER CREATE ON hr.SCHEMA BEGIN … END;
⬜ CREATE TRIGGER t AFTER INSERT ON hr.objects BEGIN … END;
⬜ CREATE TRIGGER t AFTER LOGON ON hr.SCHEMA BEGIN … END;
⬜ CREATE TRIGGER t BEFORE DDL ON DUAL BEGIN … END;

Which two are database event triggers? (Choose two.)

⬜ AFTER LOGON ON DATABASE
⬜ BEFORE INSERT ON employees
⬜ AFTER STARTUP ON DATABASE
⬜ INSTEAD OF UPDATE ON emp_view
⬜ AFTER UPDATE OF salary ON employees

Which trigger lets users update a complex view that isn’t otherwise updatable?

⬜ A BEFORE UPDATE trigger on the view
⬜ An AFTER STATEMENT trigger on the base table
⬜ An INSTEAD OF UPDATE trigger on the view
⬜ A LOGON trigger

⬜ PLSQL_CODE_TYPE
⬜ PLSQL_WARNINGS
⬜ PLSQL_OPTIMIZE_LEVEL

What does PLSQL_CODE_TYPE = NATIVE do?

⬜ Compiles units to Java bytecode for the JVM
⬜ Compiles units to native machine code
⬜ Disables compiler optimization
⬜ Stores source in clear text

How do you turn on all compile-time warnings for your session?

⬜ ALTER SESSION SET PLSQL_DEBUG = TRUE;
⬜ SET SERVEROUTPUT ON
⬜ ALTER SESSION SET PLSQL_OPTIMIZE_LEVEL = 3;
⬜ ALTER SESSION SET PLSQL_WARNINGS = ‘ENABLE:ALL’;

⬜ Conditional compilation with $IF

⬜ Restrict which client IP addresses can call a procedure

⬜ Grant a role to a program unit to use while it runs
⬜ Prevent a program from being dropped

What happens when code calls a procedure marked with PRAGMA DEPRECATE?

⬜ The call fails at run time
⬜ The procedure is dropped
⬜ Nothing at all; the pragma is documentation
⬜ The caller gets a compile-time warning

Which two statements about ACCESSIBLE BY are true? (Choose two.)

⬜ It can be used on packages, procedures, functions and types
⬜ It’s checked only at run time
⬜ Units not listed can’t reference the unit
⬜ It grants EXECUTE automatically
