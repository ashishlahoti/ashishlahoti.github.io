These questions are created from the SCS-C03 exam guide and the AWS documentation, and every explanation links to the documentation page it comes from. They cover all six domains of the exam, and once you go through these questions and their concepts, you are more than ready to crack the exam in first attempt.

Note: SCS-C03 replaced SCS-C02 and reorganizes the exam into six domains, adding newer services and features such as Amazon Security Lake, resource control policies (RCPs), centralized root access, IAM Roles Anywhere, Amazon Verified Permissions, AWS Verified Access and GuardDuty Runtime Monitoring. The real exam can also include ordering and matching questions; this test uses multiple choice and multiple response.

Free AWS Certified Security – Specialty (SCS-C03) Online Practice Exam

Overview

  1. This is a Specialty level certification for security professionals. It validates expertise in securing AWS workloads: threat detection and logging, incident response, infrastructure and network security, identity and access management, data protection, and multi-account security governance.
  2. Exam code is SCS-C03; there are no formal prerequisites.
  3. The exam has 65 questions (50 scored and 15 unscored) in 170 minutes. Question types are multiple choice, multiple response, ordering and matching.
  4. Passing score is 750 (out of 1000), with a compensatory scoring model.
  5. The six domains are weighted at 16%, 14%, 18%, 20%, 18% and 14%. This test follows the same split (10/9/12/13/12/9), with 6 multiple-response questions.
  6. The exam costs US$300, and the certification is valid for 3 years.
  7. SCS-C03 exam guide for more details.

Domain 1: Detection (16%)

A company wants to centralize security logs from CloudTrail, VPC Flow Logs, Route 53 Resolver and Security Hub across its organization in a data lake that uses the Open Cybersecurity Schema Framework (OCSF). Which service fits BEST?

⬜ Amazon CloudWatch Logs Insights
⬜ Amazon Security Lake
⬜ AWS Config aggregator
⬜ Amazon Macie

GuardDuty must be enabled for every existing and future account in the organization and managed from the security tooling account. What should be configured?

⬜ Enable GuardDuty manually in each account whenever a new one is created
⬜ Create a GuardDuty detector only in the management account for all accounts
⬜ Use an SCP that turns GuardDuty on in member accounts automatically
⬜ Make the security account GuardDuty delegated admin with auto-enable

The security team must be alerted within minutes whenever the root user signs in to any account. What is an effective approach?

⬜ An EventBridge rule on root ConsoleLogin events that notifies SNS
⬜ A weekly review of the IAM credential report for every account in the organization
⬜ An AWS Config rule that checks whether the root user has an access key every 24 hours
⬜ A CloudWatch dashboard that displays the number of IAM users created each day

A team needs to analyze which IP addresses are connecting to instances in a subnet, including rejected connection attempts. What should be enabled?

⬜ CloudTrail data events for EC2
⬜ VPC Flow Logs on the subnet
⬜ AWS Config recording for security groups
⬜ S3 server access logging

Security wants to detect EC2 instances that resolve domain names associated with malware command-and-control servers. Which log source captures DNS queries made from within a VPC?

⬜ Elastic Load Balancing access logs
⬜ Route 53 Resolver query logs
⬜ CloudFront standard logs
⬜ AWS Config configuration history

An organization trail is configured, but CloudTrail events from a new member account aren’t appearing in the central S3 bucket. What should be checked FIRST?

⬜ The bucket and KMS key policies allow CloudTrail to write the logs
⬜ Whether the member account has detailed EC2 monitoring enabled
⬜ Whether the bucket uses the S3 Intelligent-Tiering storage class by default
⬜ Whether the account’s VPC has an internet gateway attached

A security team wants Config to evaluate every account against a set of CIS-style rules and deploy those rules consistently across the organization. What should be used?

⬜ Amazon Inspector assessment runs
⬜ IAM Access Analyzer archive rules
⬜ AWS Config conformance packs deployed to the organization
⬜ Amazon Detective behavior graphs

An application team needs to search CloudTrail logs stored in S3 with SQL to find all DeleteBucket calls in the past 90 days. Which service fits BEST?

⬜ Amazon Inspector
⬜ AWS Shield Advanced
⬜ Amazon Athena with a CloudTrail table
⬜ Amazon Cognito

Logs from many accounts and applications must be correlated and visualized in near real time with full-text search and dashboards. Which service fits BEST?

⬜ AWS Artifact
⬜ Amazon OpenSearch Service
⬜ AWS Audit Manager
⬜ Amazon S3 Glacier Deep Archive

Security Hub findings show that a GuardDuty integration isn’t sending findings, although GuardDuty is enabled. What should be checked? (Select TWO.)

⬜ That the account has Business Support
⬜ That the GuardDuty product integration is enabled in Security Hub
⬜ That Security Hub is enabled in the same Region as GuardDuty
⬜ That CloudTrail Insights is enabled
⬜ That GuardDuty findings are exported to an S3 bucket before they can be sent

Domain 2: Incident Response (14%)

⬜ Terminate the instance right away to stop the mining activity at once
⬜ Reboot the instance to clear the malicious process
⬜ Isolate it in a restrictive security group and snapshot its volumes
⬜ Delete the instance’s IAM role and its access logs

⬜ Deactivate the access key and revoke active sessions for the user

⬜ Change the account’s AWS Support plan
⬜ Review CloudTrail for the key’s actions and remove unauthorized resources
⬜ Leave the key active so that the attacker can be monitored for a while longer

⬜ Amazon Detective

⬜ An S3 Lifecycle rule on the GuardDuty findings export bucket

The team wants to test its incident response and resilience procedures by injecting realistic failures, such as stopping instances or denying network traffic, in a controlled way. Which service fits BEST?

⬜ Amazon Macie
⬜ AWS Artifact
⬜ AWS Shield Standard
⬜ AWS Fault Injection Service

To be prepared for incidents, the security team needs pre-approved, audited access to production accounts that is used only during an investigation. What should be set up?

⬜ A dedicated, logged incident response role assumable with MFA
⬜ Shared root user credentials stored in a team chat channel for emergencies
⬜ Permanent administrator access for all security engineers in every account
⬜ A single IAM user with long-term access keys shared by the whole team

A web application is under a large DDoS attack, and the company has Shield Advanced. How can it get help from AWS responders during the attack?

⬜ Open a case with AWS Artifact to request the latest DDoS compliance report
⬜ Engage the Shield Response Team (needs Business or Enterprise Support)
⬜ Call Amazon Macie support to classify the attack traffic
⬜ Disable AWS WAF so that Shield can inspect all of the traffic

After containing a compromised instance, the team must analyze its disk without changing the evidence. What is the recommended approach?

⬜ Attach a volume made from the snapshot, read-only, to an isolated forensic instance
⬜ Log in to the compromised instance and run antivirus software on the live disk
⬜ Copy the volume’s files to a public S3 bucket so that external experts can review them
⬜ Resize the original volume to make space for the forensic analysis tools needed

Which service provides findings for software vulnerabilities on EC2 instances so responders can see if an exploited instance had unpatched CVEs?

⬜ Amazon Detective
⬜ AWS CloudTrail
⬜ AWS Config
⬜ Amazon Inspector

A web application on CloudFront must block requests from specific countries and limit any single IP to 2,000 requests per 5 minutes. What should be configured?

⬜ Network ACLs on the origin subnets with country-based deny rules
⬜ Security groups on the origin that allow only the permitted countries
⬜ S3 bucket policies on the origin that check the requester’s country
⬜ AWS WAF on the distribution with geo match and rate-based rules

Users must only reach an S3 website origin through CloudFront, never directly through the S3 endpoint. What should be configured?

⬜ OAC plus a bucket policy allowing only that distribution
⬜ Make the bucket public and rely on CloudFront caching to hide its URL
⬜ Enable S3 Transfer Acceleration on the bucket and remove the bucket policy
⬜ Attach a security group to the S3 bucket that allows only CloudFront IP ranges

Administrators need shell access to private EC2 instances without opening inbound SSH ports or managing bastion hosts, with sessions logged. What should be used?

⬜ AWS Systems Manager Session Manager
⬜ A bastion host with port 22 open to 0.0.0.0/0
⬜ EC2 key pairs shared through email
⬜ A NAT gateway with port forwarding

Applications on EC2 need to call S3 and DynamoDB. How should they get credentials?

⬜ Store an IAM user’s access keys in the AMI
⬜ Attach an IAM role through an instance profile
⬜ Embed the root user’s access keys in code
⬜ Put access keys in instance user data

To reduce the risk of SSRF attacks stealing instance role credentials, what should be enforced on EC2 instances?

⬜ IMDSv1 only, with a lower hop limit of 64
⬜ Public IP addresses on every instance
⬜ IMDSv2 required, with IMDSv1 disabled
⬜ Detailed CloudWatch monitoring on every instance

A VPC needs stateful, centrally managed traffic inspection with intrusion prevention and domain-based filtering for egress traffic. Which service fits BEST?

⬜ Network ACLs
⬜ Security groups
⬜ Route 53 private hosted zones
⬜ AWS Network Firewall

Which statements about security groups and network ACLs are correct? (Select TWO.)

⬜ Network ACLs apply to individual network interfaces rather than to whole subnets
⬜ Security groups evaluate rules in number order
⬜ Security groups support explicit deny rules
⬜ Network ACLs are stateless and support explicit deny rules
⬜ Security groups are stateful, so return traffic is allowed automatically

Container images and Lambda functions must be scanned continuously for known vulnerabilities, and EC2 and EKS runtime threats must be monitored. Which combination fits BEST?

⬜ AWS Config for vulnerabilities and AWS Artifact for runtime threats
⬜ Amazon Macie for vulnerabilities and AWS Audit Manager for threats
⬜ Amazon Inspector plus GuardDuty Runtime Monitoring
⬜ IAM Access Analyzer for vulnerabilities and AWS Backup for threats

A company wants hardened, CIS-aligned AMIs with security agents preinstalled, rebuilt automatically when new patches are released. Which service fits BEST?

⬜ AWS Backup with daily AMI copies
⬜ Amazon Data Lifecycle Manager policies
⬜ AWS Elastic Disaster Recovery
⬜ EC2 Image Builder with hardening components

A security policy requires that instances in private subnets reach S3 only through a specific bucket, without internet access. What should be used?

⬜ A NAT gateway with a security group that allows only S3 IP ranges
⬜ An internet gateway with a route to the S3 public endpoint
⬜ S3 Transfer Acceleration with a custom domain name
⬜ An S3 gateway endpoint with a bucket-restricting policy

Hundreds of accounts must have the same WAF rules on all ALBs and CloudFront distributions, applied automatically to new resources. Which service fits BEST?

⬜ AWS Firewall Manager security policies
⬜ Individual WAF web ACLs created by each team
⬜ AWS Config managed rules only
⬜ Amazon GuardDuty threat lists

A partner’s data center must call an internal API in a VPC privately without exposing it to the internet or peering whole networks. The API is behind a Network Load Balancer. What should be used?

⬜ AWS PrivateLink (an endpoint service backed by the NLB)
⬜ VPC peering with the partner’s VPC
⬜ A public API Gateway endpoint without authorization
⬜ An internet-facing ALB with a security group allowing all IPs

Domain 4: Identity and Access Management (20%)

A mobile app needs user sign-up and sign-in with MFA, and must let signed-in users upload files to their own S3 prefix with temporary credentials. Which combination fits BEST?

⬜ IAM users created for each app user, with long-term access keys for S3
⬜ IAM Identity Center permission sets assigned to each app user
⬜ AWS Directory Service with one shared IAM role and a password
⬜ Cognito user pools for sign-in, identity pools for AWS credentials

An external partner should download one private S3 object for 1 hour without being given AWS credentials. What should be used?

⬜ An S3 presigned URL that expires after 1 hour
⬜ Make the object public for 1 hour
⬜ Create an IAM user for the partner
⬜ Share the bucket’s access point ARN

Servers in an on-premises data center need to call AWS APIs without long-term access keys. What should be used?

⬜ IAM users with access keys rotated once a year
⬜ IAM Roles Anywhere with certificates
⬜ Root user access keys stored in a vault
⬜ Cognito user pools with a shared password

A role in account A must be assumable only by a specific role in account B, and only when MFA was used. Where are these conditions defined?

⬜ In an S3 bucket policy in account B that lists the role from account A as a principal
⬜ In the trust policy of account A’s role, with the principal ARN and an MFA condition
⬜ In a service control policy attached to account B’s root user only
⬜ In the permissions policy attached to the role in account A only

A user is denied access to an S3 bucket despite an identity policy that allows s3:GetObject. Which could explain the denial? (Select TWO.)

⬜ The user signed in with MFA
⬜ A permissions boundary on the user that doesn’t allow s3:GetObject
⬜ The bucket has versioning enabled
⬜ An explicit Deny in the bucket policy or an SCP
⬜ The user’s identity policy also allows the s3:ListBucket action on the bucket

A developer wants to test whether a new IAM policy would allow a specific action on a specific resource before attaching it. Which tool fits BEST?

⬜ AWS Trusted Advisor
⬜ Amazon Detective
⬜ AWS Artifact
⬜ IAM policy simulator

Security wants to find IAM roles and users with permissions they haven’t used in 90 days and generate least-privilege policies from actual activity. Which service fits BEST?

⬜ AWS Shield Advanced
⬜ IAM Access Analyzer
⬜ Amazon Macie
⬜ AWS Firewall Manager

A SaaS application needs fine-grained, application-level authorization (for example, which users can view which documents), defined in policies separate from the code. Which service fits BEST?

⬜ IAM identity-based policies for every app user
⬜ Amazon Verified Permissions
⬜ AWS Organizations SCPs
⬜ S3 Object Ownership settings

A role is assumed by an automation tool that should get only a subset of the role’s permissions for one task. What can restrict permissions for just that session?

⬜ A new IAM user for each task
⬜ A service control policy changed before each task
⬜ A session policy passed in the AssumeRole call
⬜ An S3 Object Lock retention setting

Users sign in to IAM Identity Center but can’t access an account, although they’re in the right group. What should be checked?

⬜ That each user has an IAM user with an access key in the account
⬜ A permission set assigned to the group for that account
⬜ That the account’s root user has MFA disabled
⬜ That the users are added to the account’s default VPC security group

Which statement about IAM permissions boundaries is correct?

⬜ They grant permissions on their own, even without any identity-based policies
⬜ They apply to every account in the organization, like an SCP does
⬜ They cap the permissions an identity-based policy can grant
⬜ They replace resource-based policies on S3 buckets and KMS keys entirely

Applications need to authenticate users against an existing on-premises Microsoft Active Directory, and AWS workloads need AD-joined Windows instances. Which service fits BEST?

⬜ Amazon Cognito identity pools with unauthenticated guest access
⬜ IAM Roles Anywhere with self-signed certificates
⬜ AWS Verified Permissions with Cedar policies
⬜ AWS Directory Service (Managed Microsoft AD or AD Connector)

An S3 bucket must be readable only by principals in the company’s AWS Organization, even if someone adds a broader statement later. What condition helps enforce this?

⬜ A bucket policy Allow for the principal “*” with no conditions at all
⬜ A Deny when aws:PrincipalOrgID doesn’t match the organization ID
⬜ A security group on the bucket that allows only the organization’s IPs
⬜ An S3 Lifecycle rule that deletes objects read from outside the organization

Domain 5: Data Protection (18%)

An S3 bucket must reject any request that isn’t sent over HTTPS. What should be added to the bucket policy?

⬜ An Allow statement for s3:GetObject with no conditions at all
⬜ A Deny when aws:SecureTransport is false
⬜ A Deny statement when s3:x-amz-acl equals private
⬜ An Allow statement for requests from the VPC’s CIDR

An ALB must allow only TLS 1.2 or later with strong ciphers. What should be configured?

⬜ An HTTPS listener with a TLS 1.2+ ELB security policy
⬜ An HTTP listener that redirects every request to port 8080
⬜ A network ACL that blocks old TLS versions
⬜ A security group that inspects cipher suites

⬜ IAM policies alone always grant access to every KMS key in the same account

⬜ S3 Transfer Acceleration
⬜ S3 Inventory reports
⬜ CloudWatch Logs metric filters

⬜ An IAM permissions boundary on each developer
⬜ An S3 Lifecycle configuration

⬜ Centralized root access management for member accounts

⬜ Creating IAM users named root in each member account
