Disclaimer: AWS is a protected Brand. These exam questions are neither endorsed by nor affiliated with Amazon Web Services. These are not the official AWS exam questions/dumps. These questions are created from the SOA-C03 exam guide and the AWS documentation. They cover all five domains of the exam, and once you go through these questions and their concepts, you are more than ready to crack the exam in first attempt.

Note: SOA-C03 replaced the SysOps Administrator – Associate exam (SOA-C02), and the certification is now called CloudOps Engineer – Associate. The exam has no hands-on labs; all questions are multiple choice or multiple response.

Free AWS Certified CloudOps Engineer – Associate (SOA-C03) Online Practice Exam

Overview

  1. The AWS Certified CloudOps Engineer – Associate validates skills in deploying, managing and operating workloads on AWS: monitoring, reliability, automation, security and networking.
  2. The exam has 65 questions (50 scored and 15 unscored) in 130 minutes, multiple choice and multiple response, and costs US$150.
  3. The passing score is 720 on a 100–1,000 scale; this practice test uses 72% as the target.
  4. The five domains are weighted 22%, 22%, 22%, 16% and 18%, so this test has 65 questions split 14 / 14 / 14 / 11 / 12.
  5. Topics include CloudWatch metrics, alarms, logs and the agent, EventBridge and Systems Manager automation, EBS, S3, EFS and RDS performance, Auto Scaling, ELB and Route 53 health checks, AWS Backup and DR strategies, CloudFormation and StackSets, IAM, Organizations, Config and security services, and VPC networking and CloudFront.
  6. SOA-C03 exam guide and certification page for more details.

Domain 1: Monitoring, Logging, Analysis, Remediation, and Performance Optimization (22%)

An operations team wants a CloudWatch alarm when memory use on its Linux EC2 instances goes above 85%, but no memory metric appears in CloudWatch. What should the team do?

⬜ Enable detailed monitoring on the instances
⬜ Install and configure the CloudWatch agent on the instances to publish memory metrics such as mem_used_percent
⬜ Create a CloudTrail trail for the instances
⬜ Turn on VPC Flow Logs

An on-call team is paged by several alarms at once during each incident. It wants one page only when both high CPU and high latency alarms are in ALARM. What should it create?

⬜ A metric math expression on a dashboard
⬜ Two separate SNS topics
⬜ A composite alarm with a rule expression that combines the two alarms with AND
⬜ A CloudWatch Logs metric filter

A central operations team wants one CloudWatch dashboard that shows metrics and alarms from workloads in several accounts and Regions. What should it set up?

⬜ A separate dashboard in each account and Region
⬜ CloudTrail Lake
⬜ An S3 bucket with exported metrics
⬜ CloudWatch cross-account cross-Region observability and a shared dashboard in the monitoring account

An application writes “ERROR” lines to CloudWatch Logs. The team wants an alarm when more than 10 errors occur in 5 minutes. What should it do first?

⬜ Create a metric filter on the log group that counts matching ERROR events, then alarm on that metric
⬜ Enable CloudTrail data events
⬜ Create an EventBridge rule on the log group
⬜ Export the logs to S3 every 5 minutes

An EC2 instance sometimes fails its system status check because of an underlying hardware problem. How can the team bring it back automatically with the same instance ID and IP addresses?

⬜ Create an alarm on StatusCheckFailed_Instance with the terminate action
⬜ Enable termination protection
⬜ Add the instance to a cluster placement group
⬜ Create a CloudWatch alarm on StatusCheckFailed_System with the EC2 recover action

An EventBridge rule should invoke a Lambda function whenever an EC2 instance enters the stopped state, but the function never runs. The rule’s event pattern is correct. What should be checked?

⬜ That the Lambda function has a VPC configured
⬜ That the rule is on the right event bus and Region and that the Lambda function’s resource policy allows EventBridge to invoke it
⬜ That CloudTrail Insights is enabled
⬜ That the EC2 instance has an Elastic IP address

When an AWS Config rule finds an S3 bucket without encryption, the team wants the fix applied automatically using a predefined procedure. What should it use?

⬜ A CloudWatch dashboard
⬜ An IAM Access Analyzer archive rule
⬜ A Systems Manager Automation runbook as the remediation action
⬜ An S3 Lifecycle rule

A 200 GiB gp2 volume can’t sustain the 3,000 IOPS its database needs except during bursts. What’s the most cost-effective fix?

⬜ Change the volume to gp3, which provides a baseline of 3,000 IOPS and 125 MiB/s regardless of size
⬜ Increase the volume to 2 TiB of gp2
⬜ Change the volume to st1
⬜ Enable EBS fast snapshot restore

Users in Asia upload large files to an S3 bucket in us-east-1 and see slow uploads over long distances. What should the team enable?

⬜ S3 Object Lock
⬜ Requester Pays
⬜ S3 Transfer Acceleration on the bucket
⬜ S3 Inventory

An application uploads 2 GB backup files to S3 over an unreliable network, and failed uploads restart from the beginning. What should the developers change?

⬜ Use a single PUT with a longer timeout
⬜ Use multipart upload so parts upload in parallel and only failed parts are retried
⬜ Enable S3 Versioning
⬜ Switch to S3 Glacier Deep Archive

An Amazon EFS file system stores many files that aren’t read after 30 days. How can the team reduce storage cost without changing the application?

⬜ Configure an EFS lifecycle policy to move files to the Infrequent Access storage class
⬜ Convert the file system to Amazon EBS
⬜ Enable S3 Intelligent-Tiering on the file system
⬜ Reduce the provisioned throughput

A serverless application opens thousands of short-lived connections to an RDS for MySQL database, exhausting connections during traffic spikes. What should the team add?

⬜ A larger EBS volume for the DB instance
⬜ RDS Performance Insights only
⬜ A cross-Region read replica
⬜ Amazon RDS Proxy to pool and reuse database connections

An RDS database is slow at peak times, and the DBA wants to find which SQL statements and waits contribute most to database load. Which feature should they use?

⬜ AWS Trusted Advisor cost checks
⬜ RDS Performance Insights
⬜ VPC Flow Logs
⬜ S3 Storage Lens

A tightly coupled HPC job needs the lowest network latency and highest throughput between its EC2 instances. Which placement strategy should be used?

⬜ A cluster placement group
⬜ A spread placement group
⬜ A partition placement group across Regions
⬜ No placement group, with instances in different AZs

Domain 2: Reliability and Business Continuity (22%)

An Auto Scaling group should keep average CPU utilization near 50% by adding or removing instances automatically. Which scaling policy fits best?

⬜ A scheduled scaling action
⬜ A simple scaling policy with a long cooldown
⬜ A target tracking scaling policy on average CPU utilization
⬜ Manually changing desired capacity

Instances behind an Application Load Balancer fail its health checks, but the Auto Scaling group doesn’t replace them. What should be changed?

⬜ Increase the health check grace period to 24 hours
⬜ Disable cross-zone load balancing
⬜ Add more subnets to the load balancer
⬜ Enable Elastic Load Balancing health checks on the Auto Scaling group

A read-heavy product catalog slows its RDS database at peak times, and the same items are read repeatedly. What reduces database load most?

⬜ Enable RDS Multi-AZ
⬜ Add an Amazon ElastiCache cache in front of the database
⬜ Turn on S3 Transfer Acceleration
⬜ Increase the backup retention period

A new DynamoDB table has unpredictable, spiky traffic, and the team doesn’t want to manage capacity. Which capacity mode fits?

⬜ On-demand capacity mode
⬜ Provisioned capacity with fixed RCUs and WCUs
⬜ Reserved capacity for 3 years
⬜ Provisioned capacity with auto scaling disabled

Reporting queries slow down an RDS for PostgreSQL primary. The reports can tolerate slightly stale data. What should the team do?

⬜ Enable Multi-AZ and read from the standby
⬜ Increase the backup window
⬜ Create a manual snapshot every hour
⬜ Create a read replica and point the reporting queries at it

ALB targets show as unhealthy, but the application responds normally when tested directly on port 8080. What should the administrator check?

⬜ That CloudTrail is enabled
⬜ That the ALB has an Elastic IP
⬜ That the target group health check uses the right port and path, and that the targets’ security group allows traffic from the load balancer
⬜ That S3 Versioning is on

A website runs in two Regions. Traffic should go to the primary Region and switch to the secondary only if the primary is unhealthy. What should be configured in Route 53?

⬜ Simple routing with both IP addresses
⬜ Weighted routing 50/50
⬜ Geolocation routing
⬜ Failover routing with a health check on the primary record

A production RDS for MySQL database must keep running if its Availability Zone fails, with automatic failover. What should be enabled?

⬜ A read replica in the same AZ
⬜ A Multi-AZ deployment with a synchronous standby in another Availability Zone
⬜ Automated backups only
⬜ An RDS Proxy

A company wants one central policy to back up EC2 instances, EBS volumes, RDS databases and DynamoDB tables with retention rules. Which service fits?

⬜ S3 Lifecycle rules
⬜ CloudFormation StackSets
⬜ AWS Backup with a backup plan
⬜ Amazon Data Lifecycle Manager for RDS

For disaster recovery, backups must also be stored in a second Region. How can the team do this with AWS Backup?

⬜ Add a cross-Region copy action to the backup plan rule
⬜ Enable S3 Transfer Acceleration
⬜ Use an EventBridge rule to copy the vault
⬜ Create a VPC peering connection

A developer deleted rows from an RDS table by mistake at 10:15. The team wants the database as it was at 10:10 without changing the current instance. What should it do?

⬜ Restore to a point in time, which creates a new DB instance
⬜ Restore the latest snapshot over the existing instance
⬜ Promote a read replica
⬜ Reboot with failover

Users sometimes overwrite or delete important S3 objects by mistake. How can the team recover earlier versions?

⬜ Enable S3 Transfer Acceleration
⬜ Set the bucket to Requester Pays
⬜ Enable S3 Versioning on the bucket
⬜ Use S3 Select

A company needs a DR approach where data is continuously replicated to a second Region and core infrastructure exists there but application servers stay switched off until a disaster. Which strategy is this?

⬜ Backup and restore
⬜ Warm standby
⬜ Multi-site active/active
⬜ Pilot light

A team wants a recovery Region that can serve traffic at reduced capacity immediately, then scale up, without the cost of full active/active. Which strategy fits?

⬜ Pilot light
⬜ Warm standby
⬜ Backup and restore
⬜ Multi-site active/active

Domain 3: Deployment, Provisioning, and Automation (22%)

A company must produce a patched, hardened AMI every month and test it before use, without manual steps. Which service fits?

⬜ AWS Backup
⬜ CloudFormation drift detection
⬜ Amazon Inspector alone
⬜ EC2 Image Builder with an image pipeline

A CloudFormation stack is stuck in UPDATE_ROLLBACK_FAILED because a database it rolls back to was deleted outside CloudFormation. What should the administrator do?

⬜ Delete the AWS account
⬜ Fix the cause if possible, then continue the update rollback, skipping the resource that can’t roll back if needed
⬜ Run drift detection and wait
⬜ Create a new stack with the same name while this one exists

The security team must deploy the same IAM roles and AWS Config rules to 40 accounts in three Regions from one template. What should it use?

⬜ Nested stacks in one account
⬜ AWS RAM
⬜ CloudFormation StackSets
⬜ Manual stack creation in each account

A networking account owns the VPC subnets, and application accounts must launch instances into them. How can the subnets be shared?

⬜ Share the subnets from the networking account with AWS Resource Access Manager
⬜ Copy the VPC into each account
⬜ Create a VPC peering connection to each account
⬜ Use CloudFormation drift detection

Developers want to define infrastructure in TypeScript, using loops and classes, and deploy it with CloudFormation. Which tool fits?

⬜ AWS Systems Manager Run Command
⬜ The AWS Cloud Development Kit (AWS CDK)
⬜ EC2 Image Builder
⬜ AWS Config

An Auto Scaling group can’t launch new instances, and the error says there aren’t enough free IP addresses. The subnet is a /28. What’s the cause and fix?

⬜ A /28 has only 11 usable addresses after AWS reserves 5, so add larger subnets to the group
⬜ The AMI is too large, so use a smaller AMI
⬜ The security group is full, so create a new one
⬜ The IAM role is missing, so add one

A CloudFormation stack contains an RDS DB instance. When the stack is deleted, the team wants a final snapshot kept. What should be set on the resource?

⬜ DeletionPolicy: Delete
⬜ UpdateReplacePolicy: Delete
⬜ DependsOn
⬜ DeletionPolicy: Snapshot

An engineer suspects that someone changed a security group managed by CloudFormation directly in the console. How can the team confirm it?

⬜ Delete and recreate the stack
⬜ Check S3 server access logs
⬜ Run drift detection on the stack
⬜ Enable termination protection

A team deploys a new application version to 100 EC2 instances with CodeDeploy and wants to update 10% of instances at a time. What should it configure?

⬜ A CloudWatch composite alarm
⬜ An S3 Lifecycle rule
⬜ A custom deployment configuration with minimum healthy hosts set to 90%
⬜ An IAM Access Analyzer finding

A company must apply operating system patches to hundreds of EC2 instances during a weekly window and report compliance. Which service fits?

⬜ AWS Backup
⬜ EC2 Image Builder alone
⬜ Amazon GuardDuty
⬜ Systems Manager Patch Manager with a maintenance window

An administrator must run the same shell command on 300 instances without SSH access or bastion hosts. What should they use?

⬜ Systems Manager Run Command
⬜ EC2 Instance Connect to each instance
⬜ CloudFormation StackSets
⬜ AWS RAM

Each time a CSV file lands in an S3 bucket, a Lambda function should process it. What should be configured?

⬜ S3 Transfer Acceleration
⬜ An S3 event notification for object-created events that invokes the Lambda function
⬜ A CloudFormation StackSet
⬜ An S3 Lifecycle rule

Development EC2 instances should stop at 8 PM and start at 7 AM on weekdays to save cost. Which serverless approach fits?

⬜ A CloudWatch composite alarm
⬜ An S3 Lifecycle rule
⬜ AWS Backup
⬜ EventBridge Scheduler schedules that call the EC2 StopInstances and StartInstances APIs

Security policy forbids opening port 22, but administrators need interactive shell access to instances in private subnets. What should they use?

⬜ A bastion host with port 22 open to the internet
⬜ Telnet
⬜ Systems Manager Session Manager
⬜ VPC peering

Domain 4: Security and Compliance (16%)

A developer gets AccessDenied when calling an S3 API, and the administrator wants to test which policy blocks it before changing anything. Which tool fits?

⬜ The IAM policy simulator
⬜ AWS Trusted Advisor
⬜ Amazon Inspector
⬜ S3 Storage Lens

The security team wants to find S3 buckets, IAM roles and KMS keys that are shared with principals outside the organization. Which service fits?

⬜ Amazon GuardDuty
⬜ IAM Access Analyzer
⬜ AWS Config conformance packs only
⬜ CloudWatch Logs Insights

An SCP attached to an OU denies all actions outside eu-west-1, but an administrator in the management account can still use other Regions. Why?

⬜ SCPs only apply to the root user
⬜ SCPs don’t affect users or roles in the management account
⬜ SCPs grant permissions, so the deny is ignored
⬜ SCPs take 30 days to apply

A company with 30 AWS accounts wants employees to sign in once with corporate credentials and get role-based access to several accounts. What should it use?

⬜ An IAM user per employee in every account
⬜ Root user credentials shared by the team
⬜ Access keys stored in a spreadsheet
⬜ IAM Identity Center with permission sets assigned to accounts

Which kind of finding is part of AWS Trusted Advisor’s security checks?

⬜ S3 buckets with open access permissions and root accounts without MFA
⬜ The cheapest EC2 instance type in each Region
⬜ Unused CloudFront distributions only
⬜ Application code vulnerabilities

When AWS Config finds a security group that allows SSH from 0.0.0.0/0, the team wants it fixed automatically. What should it configure?

⬜ A CloudWatch dashboard
⬜ An S3 event notification
⬜ An AWS Config remediation action using a Systems Manager Automation document
⬜ A Route 53 health check

Policy requires every new EBS volume in a Region to be encrypted, even if a user forgets to select encryption. What should the administrator do?

⬜ Enable S3 default encryption
⬜ Enable EBS encryption by default in that Region
⬜ Encrypt only the AMIs
⬜ Turn on CloudTrail log file validation

A public ACM certificate on an Application Load Balancer must renew without manual work. Which validation method enables automatic renewal?

⬜ DNS validation, keeping the validation CNAME record in place
⬜ Email validation with nobody monitoring the mailbox
⬜ Importing a third-party certificate
⬜ Using a self-signed certificate

A database password must be stored securely and rotated every 30 days without application downtime. What should the team use?

⬜ A plain-text value in an EC2 user data script
⬜ An S3 object with public read
⬜ A hardcoded value in the AMI
⬜ AWS Secrets Manager with automatic rotation

The security team wants managed threat detection that analyzes CloudTrail events, VPC Flow Logs and DNS logs for suspicious activity such as crypto-mining. Which service fits?

⬜ AWS Config
⬜ AWS Trusted Advisor
⬜ Amazon GuardDuty
⬜ Amazon Inspector

The team needs continuous scanning of EC2 instances, container images in ECR and Lambda functions for software vulnerabilities. Which service fits?

⬜ Amazon GuardDuty
⬜ AWS Shield
⬜ IAM Access Analyzer
⬜ Amazon Inspector

Domain 5: Networking and Content Delivery (18%)

A security group allows inbound HTTPS, and the network ACL allows inbound TCP 443, but clients still time out. The NACL has no outbound rules except the default deny. What’s wrong?

⬜ Security groups are stateless and need an outbound rule
⬜ The internet gateway must be replaced
⬜ Network ACLs are stateless, so an outbound rule must allow return traffic to the clients’ ephemeral ports
⬜ HTTPS isn’t supported in VPCs

Instances in a private subnet must download operating system updates from the internet but must not be reachable from it. What should be added?

⬜ An internet gateway route in the private subnet
⬜ A NAT gateway in a public subnet, with a route from the private subnet to it
⬜ An egress-only internet gateway for IPv4
⬜ A gateway VPC endpoint

IPv6-enabled instances must reach the internet over IPv6, but the internet must not start connections to them. What should be used?

⬜ An egress-only internet gateway
⬜ A NAT gateway
⬜ An internet gateway with no other controls
⬜ A Transit Gateway

Private-subnet instances copy terabytes to S3 through a NAT gateway, and data processing charges are high. What’s the most cost-effective fix?

⬜ Add a gateway VPC endpoint for S3 to the private subnets’ route tables
⬜ Add a second NAT gateway
⬜ Use S3 Transfer Acceleration
⬜ Move the instances to public subnets with public IPs

A company wants to expose an internal service in its VPC to consumer VPCs in other accounts privately, without VPC peering or overlapping-CIDR problems. What should it use?

⬜ VPC peering with each consumer
⬜ A public Application Load Balancer
⬜ An internet gateway
⬜ AWS PrivateLink with an endpoint service behind a Network Load Balancer

VPC A is peered with VPC B, and VPC B is peered with VPC C. Instances in A can’t reach C. Why?

⬜ Peered VPCs must be in the same AZ
⬜ Security groups can’t reference peered VPCs
⬜ VPC peering doesn’t support transitive routing
⬜ Peering only works for IPv6

On-premises servers must resolve names in a Route 53 private hosted zone over Direct Connect. What should be created?

⬜ A Resolver outbound endpoint only
⬜ A Route 53 Resolver inbound endpoint, with on-premises DNS forwarding those queries to it
⬜ A public hosted zone
⬜ A CloudFront distribution

A team wants to send 10% of users to a new application version behind a separate load balancer, using DNS. Which Route 53 routing policy fits?

⬜ Failover routing
⬜ Geolocation routing
⬜ Simple routing
⬜ Weighted routing

After a fix is deployed to S3, users still see the old JavaScript file through CloudFront until the TTL expires. How can the team remove it from edge caches now?

⬜ Delete the CloudFront distribution
⬜ Create a CloudFront invalidation for the file path
⬜ Enable S3 Versioning
⬜ Change the Route 53 record

A multiplayer game needs two static IP addresses that clients can allow-list, with traffic routed over the AWS global network to healthy endpoints in several Regions. Which service fits?

⬜ Amazon CloudFront
⬜ Route 53 simple routing
⬜ AWS Global Accelerator
⬜ A NAT gateway

An instance can’t connect to a database on port 5432, and the team wants to see whether the traffic is being rejected. What should it enable and check?

⬜ VPC Flow Logs, looking for REJECT records for that traffic
⬜ S3 server access logs
⬜ CloudFront standard logs
⬜ AWS Cost Explorer

Two VPCs are attached to the same transit gateway, but traffic between them fails. Their own route tables point to the transit gateway. What should be checked next?

⬜ The S3 bucket policy
⬜ The ACM certificate
⬜ The transit gateway route table: the attachments must be associated and their routes propagated or added
⬜ The CloudWatch agent configuration
