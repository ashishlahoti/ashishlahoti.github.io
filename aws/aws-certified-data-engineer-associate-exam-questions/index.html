Free AWS Certified Data Engineer – Associate (DEA-C01) Online Practice Exam

Overview

  1. This is an Associate level certification for data engineers. It validates the skills to ingest and transform data, orchestrate pipelines, choose and manage data stores, operate and monitor pipelines, ensure data quality, and secure and govern data on AWS.
  2. Exam code is DEA-C01. AWS recommends 2–3 years of data engineering experience and 1–2 years of hands-on AWS experience; there are no formal prerequisites.
  3. The exam has 65 questions (50 scored and 15 unscored), multiple choice and multiple response, in 130 minutes.
  4. Passing score is 720 (out of 1000), with a compensatory scoring model: you need to pass the exam overall, not each domain.
  5. The four domains are weighted at 34%, 26%, 22% and 18%. This test follows the same split (22/17/14/12), with 3 multiple-response questions.
  6. The exam costs US$150, and the certification is valid for 3 years.
  7. DEA-C01 exam guide for more details.

Domain 1: Data Ingestion and Transformation (34%)

⬜ Amazon S3 with S3 Event Notifications to each consumer
⬜ Kinesis Data Streams with extended retention
⬜ Amazon SQS standard queue with a 7-day visibility timeout
⬜ AWS Glue batch jobs that run every hour

⬜ More shards with shared-throughput GetRecords polling
⬜ A single Lambda function that copies data to every consumer
⬜ Kinesis Data Firehose delivering to each application

A team needs to load streaming data into Amazon S3 in Apache Parquet format with minimal code, buffering records and converting from JSON. Which service fits BEST?

⬜ Amazon Kinesis Data Streams with a custom consumer on EC2
⬜ AWS DMS with an S3 target endpoint
⬜ Amazon SQS with a Lambda function writing Parquet
⬜ Amazon Data Firehose with record format conversion

⬜ AWS Glue crawlers scheduled every 5 minutes against Oracle
⬜ AWS DMS with a full load plus CDC task
⬜ Amazon AppFlow with an Oracle connector
⬜ AWS DataSync copying data files
